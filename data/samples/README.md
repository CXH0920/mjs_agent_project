# data/samples — 全虚构示例数据

本目录内的数据为**展示数据格式用的全虚构示例**：人物、势力、卡牌名称与全部文案
均为自编，**不含任何官方或第三方内容**，与真实采集数据（不入版本库，经
`src/scripts/pull_data.py` 从私有数据仓获取）无关。

- `sample_heroes.json` — 武将 schema 示例（字段与真实 heroes.json 一致）
- `sample_cards.json` — 卡牌 schema 示例（字段与真实 cards.json 一致）

真实数据的来源登记见 [../SOURCES.md](../SOURCES.md)。
