# 《名将杀》刘邦武将解析

---

## 一、武将背景与定位

- **基础属性**：**5 体力上限 / 4 手牌上限**，3 个技能
- **讲者定性**：**非常强势的辅助**——会玩能刷很多牌；内测时期被低估，讲者希望观众看完视频后对刘邦重新改观
- **核心特点**：三个技能**彼此联动**，通过弃牌 → 队友摸牌的链条实现大量刷牌

---

## 二、技能详解

### 技能一：斩蛇起义（限定技 · 销牌 + 弃牌补队友）

**前半段——销毁同名牌：**
- 限定技
- 选择一张**除杀以外**的手牌，**销毁游戏中所有的同名牌**
- **不能销杀**（否则全场玩家无输出）
- 销毁范围包括：手牌区、牌堆、弃牌区、判定区
- **已被移出场外的牌不会被销毁**

**★ 策略选择：**
| 情况 | 选择 |
|------|------|
| 多数情况 | **销闪** → 全场杀在没有闪的情况下都是**强命** |
| 敌方是强势菜刀将 | 不销闪（避免菜刀更猛） |
| 手上无闪 | 只能销自己的一张手牌 |

**后半段——弃牌补队友：**
- 本局游戏中，你**每次弃牌时**，可令**另一名其他角色摸 2 张牌**
- **弃牌触发场景极多**：弃牌阶段弃牌、被破阵卸甲拆牌等
- ⚠️ **不能让刘邦自己摸，只能让队友摸**——队友没了技能就失效

**★ 弃牌联动举例（开局演示）：**
> 刘邦弃 1 张 → 队友摸 2 张；再弃 1 张 → 队友再摸 2 张……
>
> 开局 4 张连环连续弃 → **队友一次摸 8 张牌**

---

### 技能二：大风歌（获得 5 点牌 → 弃牌 + 全场弃牌 + 队友补至上限）

**技能描述：**
- 每回合限一次
- 当你**获得点数为 5 的牌**时：
  - 可将其弃置，立即**重新洗牌**
  - **随机弃置其他角色各一张牌**
  - 可令**另一名其他角色摸牌至手牌上限**

**★ 关键规则：**
| 规则 | 说明 |
|------|------|
| 一次性获得多张 5 | 全部弃掉（"都会把这些点数 5 全部给弃掉"） |
| **开局发牌也算获得牌** | 开局即可触发大风歌，弃一张 5 → 全场角色各被随机弃 1 张 |

**★ 配合手牌上限高的武将收益更大：**
| 队友类型 | 摸牌数 |
|----------|--------|
| 5 血 5 手牌上限角色 | 摸 5 张 |
| 4 血 4 手牌上限角色 | 摸 4 张 |
| 3 血 3 手牌上限（菜刀） | 最多摸 3 张 |

---

### 技能三：约法三章（弃牌判定上一轮行为）

**技能描述：**
- 出牌阶段限一次
- 可弃置一张牌，选择一名其他角色
- 若其在**上一轮**达成以下条件，则实现对应效果（**多个条件可叠加**）：

| 条件 | 效果 |
|------|------|
| 上一轮**击杀**过其他角色 | 体力上限 -1 |
| 上一轮**造成过伤害** | 受到 1 点伤害 |
| 上一轮**获得过其他角色的牌** | 随机销毁 1 张牌 |

**★ 关键规则：**
| 规则 | 说明 |
|------|------|
| 首轮发动无后续 | 因为"上一轮"不存在，无额外收益 |
| 弃牌联动 | 弃牌即可触发一技能的队友摸 2 张 |
| 三技能本身弃牌 + 大风歌弃牌 + 一技能联动 → **弃牌收益叠加** |

---

## 三、技能联动与实战演示

### 开局第一回合打法（讲者实盘）：

| 步骤 | 操作 | 收益 |
|------|------|------|
| ① | 看是否能刷到闪或桃（优先销闪） | 准备斩蛇起义 |
| ② | 若没闪且有5点牌 → 用大风歌弃 1 张 5 | 全场角色各被随机弃 1 张 |
| ③ | **必须发动斩蛇起义**（不发动就缺技能） | 销掉一张非杀牌 |
| ④ | 连续弃连环 4 张 → 每次弃牌队友摸 2 张 | **队友摸 8 张牌** |
| ⑤ | 发动约法三章弃 1 张 | 队友再摸 2 张（首轮无后续效果） |
| **合计** |  | **开局给队友递 10+ 张牌** |

### 第二回合打法：

| 步骤 | 操作 |
|------|------|
| ① | 多多益善拿牌 → 拿到 5 → 发动大风歌弃掉 |
| ② | 触发斩蛇起义弃牌 → 给队友补 2 张 |
| ③ | 大风歌令队友摸至手牌上限 |
| ④ | 发动约法三章弃牌 → 给队友补 2 张 |
| ⑤ | 指定上轮造成伤害的角色 → 造成 1 点伤害 |

## 四、核心总结

| 维度 | 要点 |
|------|------|
| **定位** | 强势辅助，靠弃牌链条刷牌的滚雪球型 |
| **一技能（斩蛇起义）** | 限定技销非杀同名牌 + 每次弃牌令队友摸 2 张 |
| **二技能（大风歌）** | 获点数 5 的牌弃掉 → 全场各弃 1 张 + 队友摸至上限 |
| **三技能（约法三章）** | 弃 1 张判对手上一轮行为：击杀→上限-1 / 造成伤→受 1 伤 / 获牌→销毁 1 张 |
| **核心联动** | 一技能弃牌 → 队友摸 2；大风歌弃牌 → 触发一技能；约法三章弃牌 → 再触发 → 三重弃牌收益 |
| **关键限制** | 弃牌只能让队友摸，不能自己摸 → 队友没了技能失效 |
| **推荐搭配** | **5 手牌上限或 4 手牌上限**的过牌量大武将（手牌上限越高，大风歌收益越大） |
| **不推荐** | 菜刀将（手牌上限低，摸牌收益少） |
