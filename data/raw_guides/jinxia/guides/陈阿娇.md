

# 《名将杀》陈阿娇武将解析总结

## 一、武将定位

陈阿娇是一名**女性武将**，在 **军八（8人局）中特别强势**，在 2v2 中仍具有不错的收益。讲者认为此前她的排名被低估，本次为她正名。核心玩法思路是：**搭配菜刀爆发型武将，实现高额收益**。

---

## 二、技能详解

### 技能一：金屋藏椒

**技能描述：** 其他角色出牌阶段限一次，其可以交给你至少一张牌，你回复等量体力值，并且令其当前阶段出杀次数加一。

**核心联动机制：**

1. **绑定出杀有额外收益的角色**——让队友多出一刀，放大菜刀爆发。
   - 典型搭配：**卫青**（交出"武刚车"刷新技能后，再让卫青多一刀暴击伤害）
   - 其他搭配：黄盖、张辽等"出杀有额外摸牌收益"或"能造成波次伤害"的角色

2. **装备牌双重收益玩法：**
   - 给陈阿娇的牌可以是装备牌
   - 例如：盗骊装时可以摸两张牌，丈八蛇矛装时可以添加两张杀进手牌
   - **操作思路：** 自己先装装备吃到收益（摸牌/获得杀），再把装备牌交给陈阿娇保管，陈阿娇之后自己装时还能再吃一次收益

3. **帮菜刀武将保管手牌：**
   - 菜刀将手牌上限通常只有 3 张
   - 配合陈阿娇可以把应弃掉的牌全交给她保管，至少第一回合不用弃太多牌
   - **牌局后期：** 陈阿娇残血时，队友给她喂牌的同时还能回血，形成双重收益

4. **细节：** 可以交多张牌，不限于一张

### 技能二：千金买赋

**技能描述：** 限定技，其他角色回合结束时，你可以将所有手牌交给该角色，然后获得其本回合打出过的所有牌的复制进你的手牌。

**两种打法：**

| 打法 | 位置 | 思路 |
|------|------|------|
| **第一种** | 队友1号位，陈阿娇4号位 | 队友1号位首回合大量出牌 → 陈阿娇发动技能把牌还给队友，实现"0弃牌"且保障队友回合外防御力和下回合续航 |
| **第二种** | 陈阿娇2号位，对面1号位是爆发型（如陆逊、申不害） | 陈阿娇自己牌被打空后，把仅有的烂牌交给敌方 → 获得敌方本回合大量出牌的复制，"嫖牌"能力极强 |

**重要规则提醒：**
> 名将杀中"交出所有牌/所有手牌"的技能，底层逻辑是 **不能交出0张牌**，至少需要有一张牌才能发动。陈阿娇的两个技能都必须至少交一张牌，不能空手"嫖"。

---


## 三、总结

| 维度 | 要点 |
|------|------|
| **定位** | 军八强势辅助，菜刀爆发放大器 |
| **核心配合** | 卫青/黄盖/张辽等出杀收益型武将 |
| **技能一（金屋藏椒）** | 回血 + 加出杀次数 + 帮菜刀管牌 + 装备双重收益 |
| **技能二（千金买赋）** | 限定技，1-4号位保护队友 / 2-3号位偷敌方牌 |
| **关键规则** | 交牌技能至少交1张，不能交0张 |
| **常见失误** | 不要滥用"加出杀次数"，可能浪费队友其他收益 |
