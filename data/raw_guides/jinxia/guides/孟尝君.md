# 《名将杀》孟尝君武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 3 技能**——**非常脆**
- **讲者胜率**："会玩的话是很强的"
- **讲者定性**：技能次数多、机制丰富，但实际玩起来有些尴尬——**太脆了**，容易被一波带走

---

## 二、技能详解

### 技能一：狡兔三窟（给牌 + 替罪羊 + 增强 · 出牌阶段限三次）

**技能描述：**
- 出牌阶段限 **3 次**
- 可交给一名其他角色**一张牌**
- 当其手中有**因此获得的牌**时：
  - 你可令其**代替你成为杀或战法牌的目标**
  - 并**随机增强其中一张牌**

**四种玩法（讲者盘点）：**

| 玩法 | 对象 | 效果 |
|------|------|------|
| **① 陷害敌方** | **上家**（军八）/ **1 号位敌人**（2v2 坐 2 号位） | 交给上家天雷地火（他回合开始前打不出去）→ 后续有人杀你 / 放烽火狼烟 / 箭雨齐射 → 全部转移给上家 → 你**不受任何伤害** |
| **② 仁德给牌** | 甘宁（给 3 张黑桃 → 拆对面 3 张）、甄宓（给 3 张黑桃 → 额外摸 3 张）等 | 起到辅助给牌作用 |
| **③ 找人扛伤（辅助）** | 卖血将（郭嘉、荀彧、蒙恬、蒙毅等） | 敌方打你 → 转移给队友 → 触发队友摸牌 / 弃牌效果 + 后时增强 1 张 |
| **④ 刷装备双收益** | 队友 | 装盗骊 → 再给队友 → 队友再装 → 摸牌；丈八蛇矛同理 |

---

### 技能二：焚券市义（回合开始时收回 / 强制交牌 · 核心续航）

**技能描述：**
- 回合开始时，可以**收回其他角色获得过你的牌**
- 或令这些角色**在你受到伤害后交给你一张牌**，直到你的下个回合开始

**★ "获得过你的牌"判定：**
> 这张牌**只要曾经在你的手上**，你再给出去 → 不管是主动给还是被顺走 → **只要到了敌方手中且没进弃牌堆**，都属于"获得过你的牌"
>
> 回合开始时这些牌都会触发焚券市义效果

**两个选项：**
| 选项 | 说明 |
|------|------|
| 收回牌 | 大多数情况直接收回 |
| 强制交牌 | 令对方在伤害你后交给你一张牌（持续至下回合开始） |

**★ 与一技能的联动：**
```
一技能把装备（盗骊）给队友
    ↓
二技能回合开始时收回装备
    ↓
你再装一遍盗骊 → 摸牌
    ↓
一技能再给队友
    ↓
【一张盗骊 / 丈八蛇矛让你们两人源源不断刷牌】
```

**额外好处：**
> 给队友扛伤的牌若队友没打出（如藏在手上）→ 收回 → 第二回合可再用狡兔三窟给出去 → **保证有牌可用**

---

### 技能三：鸡鸣狗盗（队友代打战法 · 出牌阶段先一次）

**技能描述：**
- 出牌阶段先一次
- 选择一名其他角色，其可将**任意一张手牌**：
  - **当作先把头筹打出** → 你可选择其中一张牌获得（队友选 1 张，你选 1 张；其他角色随机获得）
  - **当作顺手牵羊打出** → 获得的牌**优先进入队友手牌区** → 再交给你

**★ "顺手牵羊"说明：**
> 专属手牌**顺手牵羊**（典故关联），**效果与夺粮劫营相同**

**使用建议：**
> 优先建议**让队友打顺手牵羊**偷对面一张牌

---

## 三、技能联动总览

```
一技能（狡兔三窟）
    → 给队友装备 / 给上家陷害牌 / 找卖血将扛伤
        ↓
二技能（焚券市义）
    → 回合开始时收回装备 → 你再装 → 再给队友（无限循环）
    → 或让队友在你受伤后交牌
        ↓
三技能（鸡鸣狗盗）
    → 让队友打顺手牵羊偷对面牌
    → 或打先拔头筹互换牌
```

---

## 四、位次策略

| 位置 | 建议 | 说明 |
|------|------|------|
| **1 号位** | ✅ 可考虑 | 与 4 号位队友联动 |
| **2 号位** | ⚠️ 有风险 | 给牌后队友及时用出，但可能被 1 号位爆发一波带走 |
| **3 号位** | ✅ 最推荐 | **位置相对安全**，把牌交给 2 号位队友 → 队友用完装备可还回 → 一技能还能随机增强装备牌 |
| 4 号位 | ❌ 不推荐 | 死得更快 |

---

## 五、三技能联动特殊效果——强化装备循环

> 一技能交给队友装备牌 → 随机增强其中一张 → 若正好增强装备 → 队友用了之后下回合收回 → 你再装 → 再给
>
> **装备牌永远在你们手中交互，不会流出，也不会被别人明显偷走**
>
> **特别推荐强化轩辕剑**（收益极高）

---

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 4 血脆皮辅助 / 控场，靠给牌 + 替罪羊 + 收牌循环 + 战法代打 |
| **一技能（狡兔三窟）** | 出牌阶段限 3 次给 1 张牌；持牌者可替你成为杀 / 战法目标 + 随机增强 1 张 |
| **二技能（焚券市义）** | 回合开始时收回别人获得过的牌 / 或强制他们在你受伤后交牌 |
| **三技能（鸡鸣狗盗）** | 出牌阶段先一次，让队友把手牌当先拔头筹 / 顺手牵羊打出 |
| **四种玩法** | ①陷害上家 ②仁德给牌 ③找人扛伤 ④刷装备双收益 |
| **核心联动** | 一技能给装备 → 二技能收回 → 一再给（无限循环） |
| **位次推荐** | 3 号位最安全，2 号位需谨慎，4 号位不推荐 |
| **讲者自评** | 会玩很强；技能复杂、太脆易暴毙；值得多练手法 |
