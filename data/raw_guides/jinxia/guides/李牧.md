# 《名将杀》李牧武将解析（大将军系列）

---

## 一、武将背景与定位

- **身份**：本赛季大将军系列武将
- **版本意义**：大将军系列自卫青以后**强度沉寂了好几个赛季**，李牧是**强度回暖 + 实战搭配特别多**的强势武将
- **讲者说明**：目前不少玩家尚未拿到此武将，但攻略可提前食用，吃透即可彻底看懂其强度所在
- **核心机制**：**卖血叠层 + 出杀叠加 + 强化杀**体系

---

## 二、技能详解

### 技能一：雁门纵牧（被杀叠层 · 核心引擎）

**前半段效果：**
- 当你成为其他角色杀的目标时：
  - 对方这张杀**不消耗出杀次数**
  - 同时**你下一个出牌阶段的出杀次数 +1**
- **命中一次即可叠 2 层**（出杀次数 +1 + 触发受伤计数）
- 只需受击 **2 次** → 触发一次一技能后续觉醒效果

**后半段效果（累计受伤 / 应战达到 3 次）：**
- 手牌上限 +1
- **摸牌至手牌上限**
- **立即打出一张牌**

**★ 致命短板——不动白风险：**
> 只要敌方**全程不主动打你**，李牧技能就完全没用 → 配合阵容时**核心思路是找能主动对李牧出杀的队友**

**关键搭配铁律：**
> ⚠️ 队友杀李牧**必须有自身额外收益**——不能随便配普通菜刀硬叠次数，单纯叠 buff 整体收益划不来

---

### 技能二：击牛飨士（弃牌强化杀）

**技能描述：**
- 应战或出牌阶段限一次
- 可以弃置一张牌，**强化手中的杀**

**与一技能形成互补：**
> 李牧只要触发应战 → 拿到**一二技能双重收益**

**应对敌方不理李牧：**
> 可搭配**转移攻击目标**的武将，让李牧替队友承伤 → 主动触发应战和受伤效果
>
> 代表武将：**虞姬、孟尝君、赵婕妤**（尤其是赵婕妤——帮自己挡杀叠层，李牧大过牌时赵婕妤还能跟着蹭牌，**双向联动非常舒服**）

---

## 三、一技能组合搭配（两大联动点）

### 联动点一：队友出杀有自身额外收益

| 武将 | 出杀收益 |
|------|---------|
| **钟无艳**（最硬核） | 每次对李牧出杀都获得战法牌 → 反补自己和李牧继续出杀 → 相当于 2v2 里当新法阵用 |
| **申不害 / 赵姬** | 自身可一直扭，但易被卡杀断节奏 → 搭配李牧后**无限出杀、全程丝滑不断节奏** |
| **白起** | 出杀能消牌 + 命中后还能消牌 → 一次出手废掉敌方多张手牌 |
| **张飞** | 攻击李牧叠技能层数 + 万人敌叠出杀次数 → 靠李牧白嫖额外出杀次数 → 反手横扫对面 |
| **秦舞阳** | 出杀额外摸牌 + 增加中毒标记 → 为李牧铺垫中毒印记 → 后续李牧命中 1 刀即可挂多层中毒 |
| 吕布 | 出杀自带额外效果 |
| 赵云 | 出杀自带额外效果 |
| 钟离眜 | 出杀自带额外效果 |
| 左慈 | 出杀可设置敌方为真实目标 |
| 庞统 | 连环多杀，实现频繁出杀刷牌 |

### 联动点二：李牧收伤后队友触发额外收益

| 武将 | 效果 |
|------|------|
| **步练师** | 李牧掉血后触发技能 → 递牌 + 额外摸 1 张装备 |
| **项梁** | 攻击李牧可偷取手牌 → 给自己增加手牌上限 + 帮李牧清空手牌 → 后续触发一技能时吃到全额补牌收益 |
| 宋玉 / 卢莫愁 / 霍去病 / 大乔 | 只要杀命中即可稳定拿额外收益 |
| **郑袖** | 特殊玩法：先给李牧递牌 → 李牧回合内触发掩袖工谗 → 再频繁对李牧出杀 → 强行让李牧回合内应战 + 受伤 → 解锁一技能后续效果 |
| **芈八子** | 杀李牧叠出杀次数 → 给李牧贵牌加持 → 李牧回合内 + 回合外的强化杀都能双倍吃到芈八子增益 → 爆发到对面看不懂 |

### 联动点三（后半段）：配合加手牌上限 / 清空手牌武将

| 武将 | 效果 |
|------|------|
| **荀彧 / 刘备 / 范增** | 给李牧加手牌上限 → 触发一技能时**一波大额过牌** |
| **孙权 / 张角 / 王翦** | 主动帮李牧清空手牌 → 让他稳定吃到一技能的本牌收益 |

---

## 四、搭配禁忌

> ⚠️ **千万不要双卖血！**
>
> 双卖血 = 两个不动白
>
> 名将杀武将环境本就阴间，遇敌方强运营组合 → 对手全程不碰你 → 慢慢运营蓄力 → 最后一刀暴击直接带走 → **完全没有还手余地**
>
> **讲者盘点的搭配中完全不推荐李牧和传统卖血将组队**

---

## 五、★ 冷门但超级阴间神仙组合——李牧 + 扶苏

| 步骤 | 效果 |
|------|------|
| 扶苏回合内用山有扶苏 | 持续给自己和李牧补牌 |
| 补出的大量杀没地方用 | 李牧一技能允许**无限次数对他出杀** → 全部砸李牧 |
| 砸李牧 | 帮李牧快速叠满 3 层印记 |
| 扶苏技能给李牧回血 | 李牧稳定存活 |
| 李牧叠层完成 | 配合二技能强化 → 立即打出强化杀 |
| 频率 | **扶苏每出 2 次刀，李牧反手强化杀对面 1 刀** |
| 结果 | 开局没人能保证全是闪 → 根本扛不住李牧突如其来的强化伤害 → **首回合即可启动，容易在扶苏回合打残甚至带走敌方 2 人** |

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 大将军系列武将，卖血叠层 + 出杀叠加 + 强化杀控制 |
| **一技能（雁门纵牧）** | 被杀目标不消耗出杀次数 + 下次出杀次数+1；累计受伤/应战 3 次 → 上限+1 + 摸至上限 + 立即出牌 |
| **二技能（击牛飨士）** | 弃 1 张牌强化手中杀（与一技能互补） |
| **核心短板** | 敌方不主动打你 → 不动白 → 必须搭配主动出杀队友 |
| **搭配铁律** | 队友杀李牧**必须自身有额外收益**（不能普通菜刀硬叠） |
| **最强联动** | **钟无艳**（战法牌循环）、**李牧 + 扶苏**（阴间神仙组合） |
| **搭配方向 1** | 出杀自带收益：钟无艳 / 白起 / 张飞 / 秦舞阳 / 申不害 / 赵姬 / 左慈 / 庞统 |
| **搭配方向 2** | 收伤后触发队友收益：步练师 / 项梁 / 宋玉 / 卢莫愁 / 霍去病 / 大乔 / 郑袖 / 芈八子 |
| **搭配方向 3** | 加手牌上限 / 清空手牌：荀彧 / 刘备 / 范增 / 孙权 / 张角 / 王翦 |
| **转移攻击** | 虞姬 / 孟尝君 / 赵婕妤（让李牧替队友承伤触发应战） |
| **禁忌** | ❌ 双卖血组合 = 两个不动白，绝对不要选 |
| **讲者评价** | 强度回暖 + 搭配极多，武将图鉴放评论区供参考 |
