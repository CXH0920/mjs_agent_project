# 《名将杀》偃师武将解析

---

## 一、武将背景与定位

- **核心机制**：**傀儡替身体系**——自身不直接登场，而是通过"傀儡代战"，拆解傀儡换取爆发回合，是本作最具代表性的独特机制武将
- **讲者态度**：不讲组合盘点（因组合需视对手将池灵活选择），**重点讲解技能机制与攻势打法**
- **强度评价**：讲者直言"不敢说高（怕被骂）"，但明确表示**强度一定不低**；自己玩偃师"每把都在赢，还没有输过"

---

## 二、技能详解

### 技能一：造化同功（傀儡替身登场）

**技能描述：**
- 在选将阶段，选中偃师时，**额外随机出现 3 名武将**，从中选择一名制作成傀儡
- 傀儡**代替偃师登场，由你控制**
- 傀儡在场时，**其他角色只能查看傀儡的技能**

**信息隐藏机制：**
> 除部分公开选将模式（如巅峰赛）外，**只有偃师玩家自己知道登场的是傀儡**；其他玩家视角下无法得知场上存在偃师
> （队友在选将阶段应该能推断出）

**等效视角：** 选将面板相当于多出 3 个选项框，去掉偃师本身占位 → 该玩家共面对 **5 个选项框**

**傀儡选择三大标准（附补充）：**

| 类别 | 说明 | 推荐武将举例 |
|------|------|-------------|
| **高嘲讽** | 控制型 / 爆发型，敌方必然优先处理 | 控场、爆发类武将 |
| **高血量** | **6 血级以上**，拆解时按剩余体力摸牌，血量越多收益越大 | 6 血以上武将 |
| **有回复能力** | 每次受伤回血，拆解时血量仍较高 | 张角、华佗、君王后 |
| **强联动** | 与场上其余 7 名武将形成高强度联动（有时胜过高血量） | 视对局将池而定 |
| **阴间强势将**（补充） | 白起、嬴政等 | **必选** |

> ⚠️ **避免选择低嘲讽武将**（卖血将如曹丕、荀彧、刘彻等）——敌方不想动你的低嘲讽武将 → 傀儡无法被拆解 → 永远不动白场上无法拆解和后续变身，毫无收益。

---

### 技能二：拆解机器枢（复活 + 强回合爆发）

**技能描述：**
- 当傀儡**重伤**或**累计受到 3 次伤害**时
- 你**代替傀儡登场**，拆解傀儡
- 傀儡每剩余 1 点体力 → 摸 2 张牌
- **立即进行一个出牌阶段**

**本质 = 复活 + 抢回合**

**登场机制详解：**
> 拆解后，傀儡的全部手牌**直接弃置**，然后摸**对应位置的初始手牌**

**位置优势（讲者强烈推荐后置位）：**

| 位置 | 初始手牌数 |
|------|-----------|
| 一号位 | 较少（建议避免） |
| 八号位（军八） | **6 ~ 7 张** |
| 后置位总体 | 比前置位多 2 张 |

**★ 收益计算公式示例：**
> 假设 6 血 5 将，掉 3 次 1 滴血，剩 3 滴血 → 摸 **6 张牌**
>
> 若坐在 4 号位 → 初始手牌 5 张
>
> **合计 = 6 + 5 = 11 张牌**，非常强势

**封禁机制：**
> 敌方封禁的是**傀儡**，而非本体；傀儡拆解后，**偃师本体仍可重新登场**

**状态继承（非常关键）：**
- 拆解傀儡时，本体**继承傀儡的增伤 / 减伤 Buff**
- **继续承担傀儡被执行的动作**
- 例 1：傀儡被挂了一层增伤 Buff → 拆解后本体同样被增伤
- 例 2：敌方诸葛连弩一直杀你 → 拆解后**连弩攻击持续**，不会中断

**抢出牌阶段的意义：**
> 可能直接在此阶段带走敌方，获得**绝杀**

---

### 技能三：木革塑形（限定技 — 第三条命）

**技能描述：**
- 限定技
- 弃置**两张梅花牌**
- 选择并制作**新的傀儡**
- 傀儡代替你登场

**本质 = 第三条命：**

| 命数 | 对应 |
|------|------|
| 第一条命 | 第一个傀儡 |
| 第二条命 | 偃师本体 |
| 第三条命 | 第二个傀儡 |

**★ 继承规则（上线后修改，原爆料不含）：**
> 傀儡再次登场时，**继承偃师本体当前的手牌区、装备区、卜卦区的全部牌**

> 第一天上线时此句不存在（不会继承），讲者因此未做攻略；修改后才推出本攻略

**叠加收益示例：**
- 本体有 10 张牌 → 继承后傀儡拥有这 10 张
- **同时还会重新摸 10 张初始手牌**（Bug 修复前不会摸，现已修复）
- **讲者直言**："目前偃师 Bug 最少，强度是爆料以来最高的版本"

**第二次选傀儡的额外考量：**
> 与初次选傀儡标准一致；同时**关注敌方武将，选择克制类武将**
>
> 例：敌方有过牌武将 → 刷出曹仁 → 立刻选择曹仁予以克制

## 三、攻势打法（讲者四条流程）

| 阶段 | 操作 | 要点 |
|------|------|------|
| **① 选将阶段** | 看到偃师时务必点开，查看随机出现的 3 名武将 | 出现阴间 / 强势 / 组合武将 → **直接锁定**；刷出 6 血武将也可选（偃师可遇不可求） |
| **② 对局前期** | 傀儡优势 → 保住傀儡不受伤，持续收益；傀儡劣势 / 敌方伤害高 → 主动掉血拆解傀儡，抢回合反打 | 视局势灵活选择 |
| **③ 拆解反打阶段** | 若有 2 张梅花 → 直接开启木格塑形重塑傀儡；选傀儡时兼顾强势 / 组合 + **克制敌方**；新傀儡登场后继承手牌，再摸新牌，继续反打 | 第一次拆解通常有 10 张左右手牌可反打 |
| **④ 第二次拆解** | 若还能活到第二个傀儡被拆解 → 继续抢回合反打（此时仅剩 2 张手牌上限） | 若此波反打无法获胜 → 基本无获胜可能 |

## 四、核心总结

| 维度 | 要点 |
|------|------|
| **定位** | 三命傀儡替身型武将，主打信息隐藏 + 拆解爆发 + 状态继承 |
| **三条命** | 傀儡 1 → 本体 → 傀儡 2（限定技刷新） |
| **一技能（造化同功）** | 额外随机 3 选 1 傀儡登场；仅己方知悉偃师存在 |
| **二技能（拆解击书）** | 傀儡重伤 / 受 3 次伤害 → 本体登场 + 每剩 1 体力摸 2 牌 + 立即出牌 |
| **三技能（木格塑形）** | 弃 2 梅花重塑傀儡；继承本体全部牌 + 重新摸初始手牌 |
| **核心优势** | 系统给予 3~4 次翻盘机会；拆解抢回合 = 两回合连续反打；状态继承 Buff / 连弩 |
| **推荐位置** | 后置位（多摸初始手牌，最大化拆解收益） |
| **组合思路** | 高嘲讽傀儡 + 克制敌方 + 联动全场 |
| **关键风险** | 必须让傀儡被攻击（低嘲讽傀儡无效）；连续两次拆解后若无法获胜则败局已定 |
| **讲者评价** | 强度"一定不低"，自己实战全胜；目前版本 Bug 最少、强度最高 |
