# 《名将杀》袁术武将解析

---

## 一、武将背景与定位

- **基础属性**：**5 体力 / 4 手牌上限**，3 个技能
- **讲者定性**：**逆天武将**，比袁绍还强——袁绍手牌多会转化成箭雨齐射（不够秒就乏力），而袁术不会把高质量牌转化，**可以不断囤牌打手牌差**
- **强度评价**：一上线评分极高；坐 1 号位是**毁天灭地**的存在

---

## 二、技能详解

### 技能一：涂高代汉（传国玉玺 · 核心技能）

**前半段——登场获得传国玉玺：**
- 登场时，**添加传国玉玺**到手牌
- 出牌阶段限一次，若你**没有传国玉玺**：
  - 可弃置至少一张牌 → 获得传国玉玺
  - 若你从其他角色处获得传国玉玺 → 令其获得你弃掉的这些牌

**★ 传国玉玺效果（核心收益）：**

| 效果 | 说明 |
|------|------|
| **无法被销毁或烧毁** | 不可被技能摧毁 |
| **其他角色与你的距离始终为 1** | 不受任何装备 / 技能距离影响，始终能打到你 |
| **弃牌阶段改为摸牌阶段** | 无需弃牌 → 每回合牌越来越多 → 自带蓄爆效果 |
| **连续装备 5 个回合 → 你所在阵营获胜** | 装备后游戏提示 5→4→3→2→1，到达 1 即获胜（含队友一起获胜） |

**其他角色获取 / 移除传国玉玺的途径：**
| 方式 | 效果 |
|------|------|
| 调兵遣将 / 夺粮劫营 | 拿过来 |
| 破阵卸甲 | 拆掉（5 回合计数**重新计算**） |
| **张郃（加强后）** | 藏进军阵 → 移出场外 |
| **华佗** | 刮骨将玉玺在手中时移出场外 → 若华佗阵亡则玉玺**永久存在于场外** |

> 讲者提醒：5 回合获胜"大家不用太在意"——大部分情况下到不了 5 回合就被处理了，**重点是前面的"弃牌阶段改摸牌阶段"和"距离始终为 1"**

**★ 关键：**
> 即使传国玉玺遗失 / 丢失，出牌阶段仍可弃 1 张找回 → **袁术基本上没有弃牌阶段**
>
> 即使被久旱、霜冻，涂高代汉仍可发动 → 弃 1 张把传国玉玺拿回来

---

### 技能二：四世三公（初始手牌 +3）

**技能描述：**
- 初始手牌加 3，四手牌上限 +3
- 与袁绍的"四世三公"**完全一致**

**★ 开局手牌计算（坐 1 号位）：**
| 来源 | 手牌数 |
|------|--------|
| 1 号位初始手牌 | 3 张 |
| 四世三公 +4 | 7 张 |
| 涂高代汉拿 1 张传国玉玺 | 8 张 |
| 摸牌阶段摸 2 张 | **10 张** |

> 袁术坐 1 号位开局**10 张牌，非常离谱**

---

### 技能三：妄自尊大（距离减手牌上限）

**前半段——与距离为 1 的角色：**
- 与你距离为 1 的其他角色 → 手牌上限 -1
- **只要袁术在场上就永久生效**（袁术阵亡 / 离开则恢复）
- 若袁术装备了传国玉玺（全场距离为 1）→ **全场手牌上限都被减 1**
- 若玉玺被扒掉 → 除挨着的那两个以外，其他恢复原样

**后半段——回合结束时自己手牌上限 -1：**
> ⚠️ **讲者评价：这个技能其实是一个没有意义的技能**

**原因分析：**
> 乍一看以为打到后面袁术手牌上限越来越少 → 但回顾涂高代汉：每回合都能拿到传国玉玺 → **弃牌阶段改摸牌阶段** → 无需弃牌 → 妄自尊大的负面 debuff **没有任何影响**
>
> **唯一生效场景**：传国玉玺被移出场外无法找回 → 此时负面技能才真正伤害袁术 → 敌方可趁机而动

---

## 三、总结

| 维度 | 要点 |
|------|------|
| **定位** | 逆天囤牌型武将，坐 1 号位毁天灭地，越拖越强 |
| **一技能（涂高代汉）** | 登场得传国玉玺；玉玺效果 = 不可毁 / 距离始终 1 / 弃牌阶段改摸牌 / 5 回合获胜 |
| **二技能（四世三公）** | 初始手牌 +4（与袁绍一致） |
| **三技能（妄自尊大）** | 距离 1 的角色手牌上限 -1；自身回合结束上限 -1（因玉玺无需弃牌，实际无意义） |
| **核心机制** | 玉玺弃牌阶段改摸牌阶段 → 每回合牌越来越多 → 无限囤牌 |
| **1 号位开局手牌** | 3 + 4 + 1 + 2 = **10 张** |
| **传国玉玺移除方式** | 破阵卸甲（重置 5 回合计数）、调兵遣将 / 夺粮劫营、张郃军阵、华佗刮骨 |
| **韧性** | 出牌阶段可弃牌找回玉玺；被霜冻仍可发动 → 基本没有弃牌阶段 |
| **5 回合获胜** | 理论上可达，但实战中多数被提前处理 |
| **讲者评价** | 比袁绍更强，逆天武将，值得游戏内体验 |
