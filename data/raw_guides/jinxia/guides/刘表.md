# 《名将杀》刘表武将解析

---

## 一、武将背景与定位

- **基础属性**：**5 体力 / 4 手牌上限**，2 个技能
- **讲者绰号**：**"捡破烂之王"**
- **核心玩法**：靠队友频繁弃牌 → 自己随机捡牌发育 → 下回合爆发

---

## 二、技能详解

### 技能一：自守待时（花色置换刷牌 · 出牌阶段每种花色限一次）

**技能描述：**
- 出牌阶段**每种花色限一次**
- 可弃置**两张同花色**的牌 → 摸两张牌

**本质 = 刷牌技能**（类似西门豹、孙权的过牌）

**花色规则：**
| 花色 | 理论可用次数 | 实际限制 |
|------|------------|---------|
| 黑桃 / 红桃 / 梅花 / 方片 | 各 1 次 | 可用 |
| **土** | 1 次 | 土花色牌仅 2 张，**实际往往无法用** |

> 理论上一回合最多用 **5 次**，实际情况最多 **4 次**

**得力工具：** 丈八蛇矛、盗骊等**一次性装备**可作为刷牌的弃牌素材

**⚠️ 使用提醒：** 不能盲目刷牌——消耗防御力进行无效过牌得不偿失

---

### 技能二：偏安荆襄（捡破烂发育 · 核心技能）

**技能描述：**
- 若你**本回合未造成伤害**，直到你的**下个回合开始**：
  - 当其他角色**弃牌**时 → 你**随机获得其中一张**

**本质 = 捡破烂技能（发育蓄爆型）**

**触发规则：**
| 情况 | 效果 |
|------|------|
| 别人弃 1 张 | 被捡走 → 刘表收入囊中 |
| 别人弃多张 | 系统随机给你 1 张 |

---

## 三、位次策略

**★ 推荐坐 2 号位（讲者最推荐）：**

| 位次 | 优劣 |
|------|------|
| **2 号位**（最佳） | ①5 血身板，1 号位回合内不易暴毙。②快速触发技能，回合结束时立刻生效。③3 号位队友可联动弃牌。 |
| 1 号位 | 若 2、3 号位不弃牌，你拿不了牌；对 4 号位队友造成手牌压力 |
| 3、4 号位 | 太靠后，嫖不到前两轮弃牌 |

> 敌方知道刘表有捡牌技能，会减少弃牌来限制他

---

## 四、组合搭配（讲者整理的 11 位频繁弃牌武将）

| 武将 | 弃牌方式 |
|------|---------|
| **曹植** | 回合内多使梅花 → 多弃牌 |
| **曹仁** | 把对面牌变成"笞" → 对方打牌时弃牌 |
| **甘宁** | 持续弃敌方牌 |
| **大乔** | 弃敌方牌 + 发动一技能时弃对方牌 |
| **李斯** | 弃牌技能限制敌方不断弃牌 |
| **西门豹** | 自己回合内刷牌弃牌 |
| **宋玉** | 类似甘宁，弃敌方牌 |
| **赵姬**（弃牌量最多） | 用一张弃一张，全部被刘表嫖走 |
| **董仲舒** | 角色卜卦后弃 1 张牌 |
| **高渐离** | 不断弃自己和敌方牌 |

**★ 配合弃牌类卡牌：**
> 方天画戟、开山斧、鸣鸿刀、连环、烈火焚城、怒 等牌都可以触发弃牌效果 → 配合刘表触发捡牌

**⚠️ 不推荐——孙权：**
> 虽能一次性大量弃牌，但**只能弃一次** → 不是最佳搭配（刘表需要的是**频繁**弃牌，不是一次性大量弃牌）

---

## 五、打法节奏（敌方视角也需注意）

| 阶段 | 操作 |
|------|------|
| **发育回合** | 刘表不进攻 → 触发偏安荆襄 → 捡队友弃牌 |
| **爆发回合** | 刘表下回合开始进攻（因为技能只持续到下个回合开始） |

**作为敌方应对：**
> ①扛住刘表第二回合的爆发
>
> ②在刘表没有偏安荆襄加持的下个回合 → 集火攻击刘表 → 在第 2 回合结束时把刘表带走

---

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 捡破烂发育型武将，靠队友弃牌捡牌 → 下回合爆发 |
| **一技能（自守待时）** | 弃 2 张同花色牌 → 摸 2 张；每种花色限一次（实际最多 4 次） |
| **二技能（偏安荆襄）** | 本回合未伤害 → 下个回合开始前，其他角色弃牌时随机获得其中 1 张 |
| **核心玩法** | 配合频繁弃牌武将 → 自己捡牌发育 → 下回合爆发 |
| **最佳位置** | 2 号位 |
| **推荐搭配** | 曹植 / 曹仁 / 甘宁 / 大乔 / 李斯 / 西门豹 / 宋玉 / 赵姬 / 董仲舒 / 高渐离 |
| **选将思路** | 看到刘表 → 检查选项框里有没有弃牌武将 → 有就选 → 无则慎重考虑 |
| **讲者评价** | 非常好玩的武将，主要搭配弃牌角色即可，值得体验 |
