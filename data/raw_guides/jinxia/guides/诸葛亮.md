# 《名将杀》诸葛亮武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 5 手牌上限**，2 个技能
- **玩法定性**：**看似脆皮，越到后面强度越高、收益越高**
- **巅峰赛表现**：出场率和胜率都很高——因为巅峰赛强将常被禁，反而给诸葛亮留出了出场空间

---

## 二、技能详解

### 技能一：奇门遁甲（自动发动 · 控顶 + 多效果选择）

**发动时机：** 每回合**开始时自动发动**（可选择不发动，若无合适效果可点取消）

**效果流程：**
1. 为**每名角色**翻开牌堆顶的牌（对应 8 张奇门牌）
2. 选择**一名角色**执行其对应的奇门效果
3. 其他牌按原顺序放回牌堆顶

**8 张奇门牌对应：** 开门 / 惊门 / 景门 / 伤门 / 杜门 / 休门 / 生门 / 死门（具体效果游戏内显示，无需记忆）

**★ 结算细节：**
| 要点 | 说明 |
|------|------|
| 翻开顺序 | 从诸葛亮自己开始**逆时针**排列 |
| 发动后 | 对应角色的奇门牌被**弃置**；其余牌**被诸葛亮拿走**作为摸牌阶段的牌 + 牌堆顶的牌 |
| 控顶能力 | 可控制自己的延时锦囊、下家的延时锦囊、自己摸牌阶段的牌 |
| 摸牌来源 | 选择"摸两张牌" → 先把未触发的奇门牌放回牌堆顶 → **再从展示的牌开始摸**（与嬴政"秦弩齐射"不同） |

---

### 技能二：锦囊妙计（出牌阶段开始 / 结束均可发动 · 开创性技能）

**技能描述：**
- **出牌阶段开始时** 或 **出牌阶段结束时**
- 选择一张**专属战法牌**
- **添加**到一名角色的手牌（**可以交给队友**）

**★ 两个发动时机的差异：**
| 时机 | 特点 |
|------|------|
| **出牌阶段开始时** | 无论是否被久旱霜冻都能发动 |
| **出牌阶段结束时** | 此时还未弃牌 → 若手牌超上限需弃牌 → 建议提前打出多余牌或交给队友 |

**★ 选择机制：** 不是从 8 张里选，而是**随机给你摸 3 张，三选一**（可能重复，如开始选舌战群儒、结束又选舌战群儒）

**★ 专属战法牌强度排序（讲者排序）：**

---

### 8 张专属战法牌详解

---

#### 1. 舌战群儒（★ 第一梯队 · 最强）

| 效果 | 打出后，本回合再次打出战法牌时 → 摸 1 张牌 |
|------|------|
| 可被识破 | 若被识破则后续效果失效 |
| **可叠加** | 出牌阶段开始 + 结束 + 下回合开始 → 摸 3 张舌战群儒 → 回合内实现**用一摸三** |
| 可给队友 | 出牌阶段结束时交给队友 → 队友回合内用一摸一 / 用一摸二 |

---

#### 2. 七擒七纵（第一梯队 · 极高收益）

| 效果 | 即将造成伤害时 → 防止此伤害 → **获得目标区域内 2 张牌** |
|------|------|
| 收益分析 | 获得牌的收益有时比敌方掉血收益更高；前期**手牌压制 > 血量压制**；可拿装备区牌 |
| 典型用法 | 首回合拿一张打对面 → 命中即可拿走对方 2 张关键牌 |

---

#### 3. 草船借箭（第一梯队 · 回合外防御）

| 效果 | 即将受到来自**牌**造成的伤害时 → 防止此伤害 → 获得此牌 |
|------|------|
| 适用范围 | 只能免疫牌的伤害（如天雷地火）；**角色技能伤害不可免疫** |
| 关键优势 | 通过**牌**去免疫而非通过诸葛亮技能 → **即使被封禁也可使用** |
| 典型用法 | 出牌阶段结束时捡一张到手 → 回合外免疫一次伤害 |

---

#### 4. 上方用火 + 七星祭风（第二梯队 · 火焰伤害联动）

| 牌 | 效果 |
|----|------|
| **上方用火** | 令一名角色卜卦；若花色不是黑桃（水属性）→ 造成 1 点火焰伤害 |
| **七星祭风** | 直到你下个回合开始 → 全场火焰伤害 +1（可叠加） |

**联动：** 打一张七星祭风 + 上方用火 → 打出 **1 刀 2 滴血**的火焰伤害

**注意：**
> 若打出者在下个回合开始前阵亡 → 效果**持续到游戏结束**

---

#### 5. 智取华容（第二梯队 · 激火集火）

| 效果 | 标记一名角色，直到你下个回合开始 → 当其受伤后，攻击范围内包含该角色的其他角色可**立即对其打出一张杀** |
|------|------|
| 用法 | 标记敌方 → 敌方受伤 → 队友一起集火打杀 |
| 持久性 | 若打出者下回合开始前阵亡 → 效果持续到游戏结束 |

---

#### 6. 空城计（第三梯队 · 苛刻条件）

| 效果 | 标记一名角色，直到你下个回合开始 → 当其**没有手牌**时 → 无法被选为手牌或技能的目标 |
|------|------|
| 条件 | 苛刻——需目标无手牌 |
| 防御力 | 发动后防御较强 |
| 特殊性 | 若诸葛亮阵亡 → **空城计效果当轮清除** |

---

#### 7. 借尸还魂（第三梯队 · 后期残局）

| 效果 | 选择获得一名阵亡角色的技能，直到你下个回合开始 |
|------|------|
| 悖论 | 想借强制技能 → 那个角色必然是强势的 → 怎么会阵亡？ |
| 适用时机 | 后期残局，有可发动的翻盘机会 |

---

### ★ 额外机制细节

**专属战法牌固定点数和花色：**
> 其他角色通过技能转换这些牌时，**仍基于原牌的花色和点数**进行转化

| 转化场景 | 结果 |
|----------|------|
| 对君王后用**上方用火**（红桃） | 转化为 **火杀**（红桃杀） |
| 对君王后用**智取华容**（点数 4，非红桃） | 转化为 **雷杀**（点数 4 非红桃杀） |

> 这解释了为何藤甲并非无敌——有战法牌可转化为雷杀 / 火杀

## 三、组合搭配

| 武将 | 联动效果 |
|------|----------|
| **芈八子** | 让战法牌生效两次 → 打舌战群儒直接吃两次收益 |
| **春申君** | 同上，战法牌生效两次 |
| 其他能复制 / 放大战法牌效果的武将 | 均可联动 |

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 越打越强的控顶型辅助 / 控制武将 |
| **一技能（奇门遁甲）** | 回合开始自动翻奇门牌；选一角色执行效果；有控顶能力；摸牌从展示牌开始 |
| **二技能（锦囊妙计）** | 出牌阶段开始 / 结束均可发动；随机 3 选 1 专属战法牌；可交给队友 |
| **核心牌强度排序** | 舌战群儒 > 七擒七纵 > 草船借箭 > 上方用火+七星祭风 > 智取华容 > 空城计 / 借尸还魂 |
| **最强玩法** | 叠 3 张舌战群儒 → 回合内用一摸三；交给队友实现用一摸一 / 二 |
| **回合外防御** | 草船借箭——可免疫天雷地火等牌伤害，封禁状态也可用 |
| **巅峰赛优势** | 强将被禁 → 诸葛亮出场率高 + 胜率高的良性循环 |
| **推荐搭配** | 芈八子、春申君（战法牌生效两次） |
| **讲者评价** | 强度高；看似脆皮实则后期收益极高，值得多试 |
