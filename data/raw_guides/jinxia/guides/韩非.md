# 《名将杀》韩非武将解析

---

## 一、武将背景与定位

- **讲者定性**：**比左慈还离谱**——每个回合都能变技能的武将
- **玩法核心**：靠不期修古无限换技能，根据牌局选择最合适的技能，**上限特别高**

---

## 二、技能详解（讲者倒序解读）

### 技能三：不期修古（每回合限一次 · 换技能核心）

**技能描述：**
- 每个回合限一次
- 当你发动**其他技能后**，可**失去该技能**
- **抽取 3 张武将牌，选择获得其中一名武将的一个技能**

**详情补充：**
| 要点 | 说明 |
|------|------|
| 可获得的技能类型 | 限定技、主动技能、被动技能**都可以** |

**本质：** 韩非发动其他技能时可以失去那个技能 → 再抽一个新技能 → **每回合都能变技能**

---

### 技能一：法不阿贵（每回合所有发动过技能的弃牌 · 出牌阶段限一次）

**技能描述：**
- 出牌阶段限一次
- 令所有角色"上一轮"每**发动过一次技能** → 随机弃置一张牌
- 若有角色因此弃置**所有牌** → 失去 1 点体力

**★ 关键规则——"上一轮"的含义：**
> 第一轮发动法不阿贵 → **收益为零**（因为第一轮没有上一轮）
>
> 必须在**第二轮**才能产生收益

**计数范围：** 所有发动过的**主动技能和被动技能**都计入

**克制对象：** 用技能多的角色，如**吕雉、申不害**（用一摸一 / 用一弃一类型）

---

### 技能二：事异备变（改法不阿贵效果 · 回合结束时可重复发动）

**技能描述：**
- 回合结束时，可将法不阿贵中**"随机弃一张牌"**的效果改为：
  - **"摸一张牌"**，或
  - 恢复为**"随机弃一张牌"**
- **此技能可重复发动**

---

## 三、★ 核心 Bug 组合——韩非 + 申不害

**原理：**
> 申不害的"以术驭国"（被动技）——可以查看牌堆顶那张牌
>
> 只要有人打出牌堆顶那张牌 → 申不害就视为**发动了一次被动技能**
>
> 法不阿贵让所有发动过技能的弃牌/摸牌 → 申不害每次摸牌都算发动 → **无限触发弃牌/摸牌**

**条件：** 若没有法不阿贵 → 事异备变就没啥用了

---

## 四、★ 关键规则——不要第一个换掉法不阿贵

> 所以最佳打法：**首次不期修古不应失去法不阿贵，而应失去事异备变**

**讲者完整示范流程：**

```
① 开局正常打牌 → 发动法不阿贵（用与不用都行）
   → 系统提示是否失去法不阿贵并发动不期修古
   → ❌ 千万不要（选了会出事）→ 点取消

② 回合结束时发动事异备变 → 把法不阿贵的效果改为：
   - 选"摸一张牌"（这辈子都摸牌了，基调定清楚）

③ 发动不期修古 → 失去事异备变 → 换一个别的技能

④ 之后每回合：
   - 法不阿贵持续生效（摸牌模式）
   - 每次发动某技能 → 触不期修古 → 换技能
   - 根据自身牌局选择最合适技能
```

---

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 韩势力武将，每回合无限换技能的左慈升级版，上限极高 |
| **一技能（法不阿贵）** | 出牌阶段限一次，上轮每发动技能弃 1 张；弃光掉 1 血；第 1 轮无效 |
| **二技能（事异备变）** | 回合结束改法不阿贵为"摸牌"或"弃牌"，可重复发动 |
| **三技能（不期修古）** | 每回合限一次，发动技能后失去该技能抽 3 张武将牌换技能 |
| **核心规则** | **不要第一个换掉法不阿贵**|
| **最佳打法** | 先换事异备变 → 保留法不阿贵持续摸牌 → 每次用技能后不换技能 |
| **单挑强度** | 一杀摸二起死回生，靠换技能组合打出爆发，逆风可翻盘 |
| **克制对象** | 吕雉、申不害等频繁发动技能的武将 |
| **讲者评价** | 比左慈还离谱，上限特别高，值得深入体验 |
