# 《名将杀》尉缭武将解析

---

## 一、武将背景与定位

- **技能数量**：3 个技能，均相对简单，但联动空间极大
- **讲者评价**：本期新武将**既有趣又有强度**，组合搭配丰富；本期攻略重点放在"判定 / 强化 / 卖血"三大体系的盘点联动

---

## 二、技能详解

### 技能一：挟义而战（关键卖血技）

**技能描述：**
- 当有角色受到伤害后，你可以查看并选择**增强其一张手牌**
**机制要点：**
> **自己卖血、队友卖血都能触发**，敌人打我方时会陷入"打谁收益大"的犹豫

**三方向应用：**

| 目标 | 效果 |
|------|------|
| **自己 / 队友** | 增强我方手牌，提升牌质量 |
| **敌人** | 查看其手牌 → **必须**增强一张（不能只看不增）；可随便增强一张烂牌 |

**战术意义：** 让敌方攻击前必须权衡"打谁让我方收益更小"，是典型的**卖血威慑型技能**。

---

### 技能二：天官兵谈（无法被挂 / 判定收益）

**技能描述：**
- **你无法卜卦**（即不受八卦盾、的卢等判定装备影响）
- 其他角色被挂后，你获得一张**梅花牌**（从牌堆摸取，非添加）

**机制详解：**

1. **八卦盾彻底无用**——自己无法卜卦，自然没有收益。
2. **的卢等**虽加一马仍在，但后续受伤判定不可能实现，卜卦后判定类装备，尉缭无法受益。

**★ 最关键的"梅花牌"玩法：**

> 尉缭**只能从牌堆摸取**梅花牌；若牌堆梅花被摸光，就再摸不到梅花牌

**由此衍生两大用途：**

| 用途 | 说明 |
|------|------|
| **己方收益** | 配合频繁卜卦角色，持续获得梅花（桃、怒、酒、马匹等收益牌为主） |
| **克制敌方** | 把牌堆里的桃 / 怒 / 马匹等梅花牌摸光 → **敌方再也摸不到梅花**；对靠梅花输出的曹植等角色产生**资源封锁**效果 |

**最佳搭配方向：** 搭配判定 / 卜卦类角色，尽早把牌堆梅花牌摸光。

---

### 技能三：战威攻权（打出强化牌弃牌）

**技能描述：**
- 当你打出强化牌时，可以弃置一名其他角色**区域内任意一张牌**
- 可弃：**手牌区、装备区、被挂区**

**联动核心：**
- 配合**一技能给己方增强手牌** → 打出强化牌 → 弃对面任意一张牌
- 配合**其他能给自己增强牌的角色**联动

---

## 三、组合搭配体系（讲者三大分类）

### 一、判定 / 卜卦类（8 个武将）

通过频繁触发被挂，让尉缭持续获取梅花牌，并尽早摸空牌堆梅花：

| 武将 | 卜卦 / 判定次数 |
|------|----------------|
| **左慈** | 开局 +2 + 每局再 2 次（实际共 4 次） |
| **周瑜** | 每回合 2 次 |
| **董仲舒** | 发动"霸出百战"后，每回合都会转天雷地火；尉缭自己不受其害 |
| **燕昭王** | 可"修筑金牌"进行判定（注：尉缭无法卜卦，所以**吃不到**燕昭王后续"强化牌"收益，但仍可获益） |
| **郭嘉** | 判定 |
| **赵威后** | 判定 |
| **暴鸢** | 出杀判定 |

> 讲者推荐：左慈、周瑜、董仲舒、郭嘉、暴鸢因判定次数多，搭配效果更明显。

---

### 二、强化手牌类

让尉缭打出强化牌，触发战威全攻弃对面牌：

| 武将 | 搭配逻辑 |
|------|----------|
| **苏秦** | 把尉缭所有牌都强化 → 尉缭打出即弃对面牌 |
| **孟尝君** | ①强化手牌型：把牌交给尉缭 → 尉缭增强打出 → 弃牌②卖血型：孟尝君让尉缭成为目标 → 尉缭受伤触发挟义而战 → 双重互补 |

---

### 三、卖血双收益类

尉缭受伤后可增强手牌，配合**受伤本身就有收益**的角色，形成"一血双吃"：

| 武将 | 联动效果 |
|------|----------|
| **夏侯惇** | 夏侯惇掉血 → 先发动反伤弹一滴 → 尉缭再增强其一张牌（如把杀强化）→ 打回去可打出 2 滴伤害 → 叠加反伤，**首次受伤可反伤 3 滴血** |
| **郑袖** | 郑袖给尉缭牌 → 尉缭打出 → 触发"掩袖工谗"让尉缭受伤 → **郑袖摸 2 牌 + 尉缭强化一张**（骚操作组合） |
| **大乔** | 敌方杀大乔 → 大乔转给尉缭 → 尉缭受伤触发大乔拆牌 → 自己再出强化牌继续拆 → **双向拆牌，敌方难打** |
| 其他卖血角色 | 曹操、曹丕、郭嘉、荀彧等|

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 判定资源垄断 + 强化牌弃置 + 卖血强化的多功能辅助 / 控制型武将 |
| **一技能（挟义而战）** | 受伤触发，可看可增强，敌我通吃；卖血威慑型 |
| **二技能（天官兵谈）** | 自身无法卜卦；队友被挂得梅花；**通过摸空牌堆梅花封锁敌方资源** |
| **三技能（战威攻权）** | 打出强化牌弃对方任意区域一张牌（手牌 / 装备 / 卜卦） |
| **核心玩法** | ①搭配卜卦角色摸空梅花 ②配合强化手牌角色持续弃牌 ③配合卖血角色双收益 |
| **最强搭配方向** | 左慈 / 周瑜（高判定）+ 苏秦（全强化）+ 夏侯惇 / 郑袖 / 大乔（卖血联动） |
| **特点标签** | 资源封锁、判断博弈、体系组合型 |
| **讲者推荐** | 既有娱乐性（整活组合），又有竞技强度（体系压制） |
