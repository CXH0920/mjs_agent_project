# 《名将杀》曹仁武将解析

---

## 一、武将背景与定位

- **外号**：**"大便超人曹仁"**——因其二技能把别人牌转化为废牌"笞"而得名
- **基础属性**：**6 体力 / 3 手牌上限**，3 个技能
- **版本强度来源**：随着法正 / 赵姬 / 申不害 / 吕雉 / 陆逊等**回合内大过牌武将**崛起，曹仁的克制地位被再次拉高
- **讲者定性**：**见到曹仁就选，不管位置**——"不逮住不亏，逮住血赚"
- **核心作用**：**克制回合内大过牌武将** + **保人回血**

---

## 二、技能详解

### 技能一：誓盟据守（1 血时万能闪 + 回合外反击回血）

**技能描述：**
- 当你的体力值 **= 1** 时，你可以将**任意一张牌当作闪打出**（包括装备区）
- 在**回合外每累计打出 3 张牌**时，你**回复 1 点体力**

**机制要点：**
- 从游戏开始累计计算回合外打出牌的次数，累计到 3 张即回 1 血
- 体力到 1 血之前很难在回合外打出牌，但可以提前叠层：
  - 响应烽火狼烟
  - 响应别人的战法打出识破（提前叠 1~2 层）
- 到 1 血时出 1 张杀 → 立刻回血

---

### 技能二：奉法行令（塞"笞"牌 · 核心克制技能）

**技能描述：**
- 其他角色在**自己回合内的非摸牌阶段获得战法牌**时
- 你可以将其中**一张随机转化为"笞"**

**触发条件分析：**
> "非摸牌阶段获得战法牌" = 要求该角色在**出牌阶段内有额外的过牌能力**
>
> 用一摸一、用一摸二的武将大概率能刷到战法牌 → **就是被曹仁克制的对象**

**"笞"牌的效果：**

| 操作 | 结果 |
|------|------|
| **打出笞** | 随机弃置一张牌（**持牌者**弃，非曹仁） |
| **直接弃置笞** | 持牌者**流失 1 点体力** |
| 推荐 | **打出笞**，避免自己掉血 |

> "笞"是一张**没有任何效果**的废牌，打出只能换一次随机弃牌。

**后半段——非弃牌阶段弃牌时造成伤害：**
- 其他角色在**非弃牌阶段弃牌**时，若其手牌中存在"笞"：
  - 你可以对其造成 **1 点伤害**

**触发"非弃牌阶段弃牌"的情况（远比想象中多）：**
| 场景 | 是否触发 |
|------|----------|
| 烈火焚城弃牌 | ✅ |
| 重铸铁锁连环弃牌 | ✅ |
| 曹仁用破阵卸甲拆牌 | ✅ |
| 弃牌阶段正常弃牌 | ❌ **不触发** |

**关键细节补充：**

> ⚠️ ① 初始手牌**不会**触发转化"笞"的效果
>
> ⚠️ ② 只有手牌中存在"笞"的角色**在非弃牌阶段弃牌**时才会触发询问

**转化"笞"的规避技巧（对方玩家）：**
> 如果能把"笞"转化成别的牌打出 → **不会随机弃牌**
>
> - 真福：拿一张黑桃笞 → 转化为识破打出 → 不随机弃牌
> - 关羽：转化为杀打出 → 不随机弃牌

---

### 技能三：天人将军（保命技能 · 救队友）

**技能描述：**
- 其他角色**体力值首次变为 1** 时，你可以失去体力至 1
- 你每因此失去 1 点体力，就令其**恢复 1 点体力**

**核心规则：**

| 规则 | 说明 |
|------|------|
| 仅限**首次**变 1 | 若首次变 1 时未使用，之后再次变 1 系统不再提示 |
| 敌我均触发 | 军八需注意，**2v2 千万别手快给敌方回血** |
| 不是加体力上限 | 若目标体力上限本就为 1（如左慈），**无法恢复**，自己反而崩成 1 血 |

**基本打法闭环：**
> 队友残血 → 天人将军回血（自己变 1 血）→ 一技能累计打出牌 → 回合外回血

## 三、克制与被克制关系

### 曹仁强力克制的武将（回合内大过牌）：

| 武将 | 备注 |
|------|------|
| **法正** | 近期阴间过牌将 |
| **赵姬** | 大过牌 |
| **申不害** | 回合内过牌 |
| **吕雉** | 大过牌 |
| **陆逊** | 刷牌量大 |
| **其他用一摸二型** | 均适用 |

### 如何打曹仁：

| 策略 | 说明 |
|------|------|
| **选菜刀将** | 只要回合内无额外过牌 → 奉法行令对你无效 |
| **双压打法** | 曹仁与队友同时在场上时，**两人一起打**，让曹仁来不及给队友回血 |
| **先干掉曹仁** | 曹仁一死，队友爆发也来不及 |
| **朴实无华最好打** | 越花哨 / 过牌量越多 → 越难打曹仁 |

## 四、实战组合——曹仁 + 扶苏

| 角色 | 作用 |
|------|------|
| **扶苏** | 体力流失易流到 1 血，可被天人将军"补牌 + 补命"救回满血 |
| **曹仁** | 扶苏"山有扶苏"摸牌 + 梅花回血，同时克制敌方过牌将 |

**实战要点：**
- ⚠️ 队友摸牌时**不要手滑把队友的战法牌变成"笞"**
- 扶苏坐 2 号位 + 曹仁坐 3 号位 → 曹仁把血变完 → 扶苏补牌补血（梅花回血）
- 曹仁对陆逊等大过牌武将**天然克制**，能反复塞"笞"使其弃牌掉血

**讲者实战直播案例：**
> 直播中，曹仁对陆逊连续塞"笞" → 陆逊不断弃牌掉血 → 最后被封死 → 完美展示克制效果

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 大过牌武将天然克星 + 保命回血辅助 |
| **一技能（誓盟据守）** | 1 血时全牌当闪；回合外打出 3 牌回 1 血 |
| **二技能（奉法行令）** | 其他角色回合内非摸牌阶段获战法 → 转 1 张为"笞"；持有"笞"时非弃牌阶段弃牌 → 笞 1 伤 |
| **三技能（天人将军）** | 队友首次变 1 血时自己掉血为其回血（仅限首次；敌方也触发，需谨慎） |
| **核心克制** | 法阵、赵姬、申不害、吕雉、陆逊等回合内大过牌武将 |
| **核心打法** | 给过牌将塞"笞"→ 对方被迫弃牌掉血 → 保队友回血 → 自己 1 血反弹 |
| **被克制对策** | 选菜刀将（无过牌）；双压曹仁 + 队友 |
| **推荐搭配** | 扶苏（补命补牌）、保人输出将（被保护） |
| **讲者建议** | **见到曹仁就选**——不逮住不亏，逮住血赚 |
