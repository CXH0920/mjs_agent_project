# 《名将杀》卢莫愁武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 4 手牌上限**，**女性**武将
- **讲者定性**：**典型的必须搭配合适组合的武将——单出 / 单挑基本无用**；配合不好用处也不大

---

## 二、技能详解

### 技能一：阳春白雪（未响应 / 抵消 → 给牌 + 强命）

**技能描述：**
- **每回合每种牌限一次**
- 当你以其他角色为目标打出牌后，若**此牌没有被其他角色响应或抵消**：
  - 你可以**将此牌交给一名其他角色**
- 此牌**再次被打出时，无法被抵消和响应**（即强命 / 必中效果）

**★ "没有响应或抵消"的判定：**
| 情况 | 判定 |
|------|------|
| 杀过去对方没闪 | ✅ 符合 |
| 战法过去对方没识破 | ✅ 符合 |
| 与宋玉技能描述相同 | 同概念 |

**⚠️ 与宋玉的关键区别：**
| 武将 | 后续效果 |
|------|----------|
| **宋玉** | 拆对面的牌（天雷、地火、霜冻、久旱都可以拆） |
| **卢莫愁** | **将此牌交给其他角色** |

**⚠️ 延时战法牌（天雷、地火、霜冻、久旱）无法交给别人：**
> 天雷地火放到别人卜卦区，**未进弃牌堆** → 不符合"已被响应或抵消"条件 → **不能交延时战法牌**
>
> 能交的：命中的杀、未被识破的战法牌

---

### 技能二：清音忘忧（交牌 → 弃卜卦区 → 印牌）

**技能描述：**
- 当你**交给其他角色牌后**（符合一技能条件）：
  - 随机**弃置其卜卦区一张牌**
- 若其卜卦区**没有牌**：
  - **每回合限一次**，可选择并**添加任意一张牌**到其手牌

**★ 关键机制——"添加"而非"摸"：**
> - **从场外添加**，非从牌堆摸
> - 即使牌堆里**已无此牌**，仍可添加
> - 但只能添加**初始牌中存在的牌**
> - **不能添加角色专属战法牌**

**一 + 二技能联动流程：**
```
一技能打出夺粮劫营（命中未响应）
    ↓
交给队友这张夺粮劫营
    ↓
触发二技能 → 弃队友卜卦区一张
    ↓
队友卜卦区无牌 → 添加任意一张牌到手牌（印牌）
```

**二技能也可与其他给牌机制联动：**
> 蔺相如、孙权等武将获得卢莫愁交出的牌时，同样可触发二技能效果

---

## 三、组合搭配（三大类）

### 第一类：互相递牌类（双向循环）

**原理：** 卢莫愁需要印牌（类似卫子夫），只要有打得出去的战法牌就能不断印牌。配合能递给卢莫愁牌的角色 → 卢莫愁打出 → 还给你 → 形成双向递牌循环。

| 武将 | 说明 |
|------|------|
| 孟尝君 | 互相递牌 |
| 郭嘉 | 互相递牌 |
| **芈八子** | 互相递牌（讲者实战验证过的组合） |
| 刘备 | 互相递牌 |
| 吕不韦 | 互相递牌 |
| 范雎 | 互相递牌 |
| 刘邦 | 互相递牌 |
| 子婴 | 互相递牌 |
| 张骞 | 互相递牌 |
| 郑袖 | 互相递牌 |
| 萧何 | 互相递牌 |
| 夏侯惇 | 互相递牌 |
| 孙权 | 互相递牌 |
| 卫子夫 | 互相递牌 |

**特殊联动：**

| 武将 | 效果 |
|------|------|
| **钟无艳** | 给队友新增出牌阶段（只能用钟无艳手牌）；若钟无艳手牌全是战法牌 → 收益不错 |
| **张仪** | 复制卢莫愁技能 → 实现互相给牌（每人一个阳春白雪） |

---

### 第二类：定向找牌类（"印"刚需装备 / 武器）

**原理：** 卢莫愁可以定向"印"（添加）给队友刚需的武器 / 装备牌

| 武将 | 刚需牌 | 效果 |
|------|--------|------|
| **赵云 / 霍去病** | **诸葛连弩** | 用一张杀摸一张杀 → 不断摸牌 |
| **项梁** | **惊羽弓 / 轩辕剑** | 印惊羽弓 → 每回合可打强命杀；再印轩辕剑 → 对面**永远无法用技能** |
| **吕布** | **方天画戟** | 不再"牢"，可 AOE；卢莫愁给战法牌 → 吕布可转化为杀，增加出杀机会和次数 |

---

### 第三类：战法收益类（多重吃收益）

**原理：** 卢莫愁靠战法吃收益，再配合其他战法吃收益的武将 → 形成多重收益

| 武将 | 联动效果 |
|------|----------|
| **宋玉** | 战法用出去 → 递给宋玉 → 宋玉用 → 拆对面牌 |
| **春申君** | 摸不到好战法 → 春申君转化为夺粮劫营 → 递给春申君 → 一张变三张 |
| **张良** | 一张战法用两遍 → 提前让张良觉醒 |
| **诸葛亮** | 估计也可配合战法收益 |

---

## 四、细节补充——没好牌时的对策

> 卢莫愁没摸到好战法牌，只有杀时：
>
> **直接杀队友一刀** → 命中 → 触发阳春白雪递杀给队友 → 再印一张关键刚需武器牌 → 队友回合内二次爆发
>
> **核心逻辑：只要能印牌，就不是废物**

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 组合型武将，靠给牌 + 硬牌 + 定向印装备的多面手 |
| **一技能（阳春白雪）** | 命中未响应 / 抵消 → 给牌 + 再打出时强命；每回合每种牌限一次 |
| **二技能（清音忘忧）** | 交牌 → 弃卜卦区 → 无卜卦则添加任意一张牌（场外印牌，非专属战法） |
| **核心联动** | 一技能给牌触发二技能硬牌；可与其他给牌机制联动 |
| **组合方向 1** | 互相递牌：孟尝君 / 郭嘉 / 芈八子 / 刘备 / 孙权等 14 将 + 钟无艳 / 张仪 |
| **组合方向 2** | 定向印装备：赵云 / 霍去病（连弩）、项梁（惊羽弓 / 轩辕剑）、吕布（方天画戟） |
| **组合方向 3** | 战法收益：宋玉（拆牌）、春申君（转化翻倍）、张良（觉醒加速）、诸葛亮 |
| **关键禁忌** | 单出 / 单挑无用；延时战法牌无法交给别人 |
