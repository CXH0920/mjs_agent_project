

# 《名将杀》韩安国武将深度解析 + "失去最后手牌"联动盘点

---

## 一、武将定位

韩安国是一名**高收益刷牌型武将**，与游戏中所有"能在一瞬间失去最后手牌（空城）"的角色紧密绑定。讲者通过对数十位武将的盘点，证明"失去最后手牌"在游戏里其实非常容易触发，韩安国因此拥有极其丰富的组合搭配空间。

---

## 二、技能详解

### 技能二：死灰复燃

> **每个回合限一次，当韩安国失去最后的手牌时，可以摸牌到手牌上限。**

- 韩安国基础手牌上限为 **3**，失去最后手牌后补回至上限
- **补牌的额外判定：**
  - 补到 **红桃** → 手牌上限 **+1**（后续补牌更多）
  - 补到 **黑桃** → 手牌上限 **-1**
  - 讲者认为黑桃判定大概率"判不出来"，可以乐观期待红桃

**配合思路：**
- 搭配能让自己"主动失去全部手牌"的武将（如 **孙权**，把牌全交给孙权即触发空城）
- 搭配能增加手牌上限的武将（如 **荀彧、范增、张仪**等）

### 技能一：强弩之末

> **当一名其他角色失去最后的手牌时，你可以选择以下一项：**
> 1. **陷害类（对敌方）：** 令其下一次受到的伤害 +1，且下回合手牌上限 -1
> 2. **辅助类（对队友）：** 每个回合限一次，交给其至少一张牌

**关键限制说明：**
- "每个回合限一次"是后续新增的限制，防止**无限刷牌**（如刘备↔韩安国互相喂牌形成死循环），属于必要平衡

**配合逻辑（核心链路）：**
> 队友空城 → 韩安国发动强弩之末，把牌全部交给队友 → 韩安国自身失去最后手牌 → 触发死灰复燃，补牌至手牌上限 → 形成一次完整刷牌循环

## 三、"失去最后手牌"联动武将大盘点

讲者将所有能触发韩安国技能的武将分为 **四大类**：

### 第一类：一排空城（队友交牌给韩安国时自身空城）

即队友通过把牌全部交给韩安国，在交完的瞬间自己空城，触发韩安国的强弩之末。

| 武将 | 说明 |
|------|------|
| 郭嘉 | 空城给牌 |
| 萧何 | 同上 |
| 夏侯惇 | 同上 |
| 芈八子 | 同上 |
| 孟尝君 | 同上 |
| 郑袖 | 同上 |
| 刘备 | 仁德全部交牌 |
| 郑国 | 开局4张牌全转化为"渠"并分给场上四人时，存在零牌瞬间 |
| 吕不韦 | 同上 |

**连锁效果：** 队友空城 → 韩安国强弩之末把牌交回队友 → 韩安国自己空城 → 死灰复燃补3张牌

### 第二类：刷牌空城（自身刷牌过程中瞬间空城）

这类武将自身有刷牌技能，在刷新过程的中途会有一瞬间零张牌，可触发韩安国技能。

| 西门豹 | 扭牌结束后大概率空城瞬间 → 韩安国把黑桃牌全给西门豹 → 西门豹可再扭第二遍 |
| 张骞 | 换牌过程空城 |

即通过队友的技能把韩安国的牌全部喂走，令韩安国自身空城。

| 主父偃 | 同上 |



## 四、核心总结

| 维度 | 要点 |
|------|------|
| **定位** | 刷牌型核心，通过"空城瞬间"触发连锁补牌 |
| **技能一（强弩之末）** | 对敌：加伤害+扣上限；对友：喂牌辅助 |
| **技能二（死灰复燃）** | 自身空城后补牌至上限，红桃判定还能加上限 |
| **核心链路** | 队友空城 → 喂牌 → 自己空城 → 补牌，一回合内完成刷牌 |
| **联动广度** | 四大类、数十位武将可触发，组合极其丰富 |
| **玩法建议** | 军八和2v2中都应围绕"能空城"的武将构建阵容 |

> 讲者强调：本期盘点的意义**不仅在于韩安国本身**，更在于为未来游戏中可能出现更多"失去最后手牌"类武将做准备，帮助玩家理解这套联动体系的全貌。
