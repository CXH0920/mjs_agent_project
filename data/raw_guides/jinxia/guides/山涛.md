

# 《名将杀》山涛武将解析

---

## 一、武将背景与定位

- **身份**：本期新武将之一
- **讲者视角**：以 **2v2 玩家** 角度评价——喜欢山涛的技能组，能与队友联动配合
- **讲者态度**：
  > 武将评分不可尽信，要有自己的判断；
  >
  > 2v2 中不存在"嘴牌"问题（就是联动），"队友死了就白板"的武将层出不穷（如蔺相如），不必纠结单挑能力

---

## 二、技能详解

### 一技能：八斗方醉（看顶选牌 + 点数≤8 白嫖酒）

**前半段——队友查看牌堆顶：**
- 其他角色**出牌阶段限一次**，可以查看牌堆顶的**2 张牌**
- 然后**让你（山涛）选择**：
  - **获得这 2 张牌**，或
  - **获得该角色的 2 张手牌**
- **山涛能看到牌堆顶的点数**

**后半段——被动判定（核心收益）：**
- 当你获得 **> 1 张牌**时：
  - 若这些牌的**总点数 ≤ 8**：
    - **加一张酒到手牌**
    - **此技能发动次数 +1**（仅限本回合，不影响全局）
  - **否则**：
    - **弃置本回合所有因此技能获得的牌**

**核心思路：**
> 队友先查看牌堆顶 2 张牌（点数已知，可告知山涛）
>
> 山涛快速计算：
> - 点数和 **≤ 8** → 直接获得 + 白嫖 1 张酒 + 次数 +1（收益 = **至少拉 3 牌差**）
> - 点数和 **> 8** → 弃牌（尽量避开）

**两种操作选择：**
| 情况 | 选择 |
|------|------|
| 山涛急需酒 或队友急需给牌 | 选择获得**队友的 2 张手牌**，选 2 张小点牌 + 添 1 张酒 |
| 队友牌不好 / 不需要给 | 选择获得**牌堆顶的 2 张牌** |

**★ 概率说明：**
> 名将杀牌堆共 **162 张**，点数均摊到 1~8
>
> 讲者请 AI 计算：连续翻出 2 张牌，**点数之和 ≤ 8 的概率约 43%**
>
> 即**有近一半可能**白嫖 2 张牌 + 1 张酒

---

### 二技能：悬丝积尘（展示牌过滤 + 抵消防御）

**前半段——获得牌前过滤（一技能兜底）：**
- 当你**即将获得 > 1 张牌前**，可以改为**展示这些牌**：
  - **点数 > 4 的牌** → 放入专属牌区"**阁**"
  - **其余牌** → **随机放回牌堆**（随机插入，**不放到牌堆顶**，**不具备控顶效果**）

**★ 兜底机制：**
> 当一技能队友给你的牌点数和 > 8 → 本会触发弃牌负面效果
>
> 但在获得**之前**发动二技能展示 → 点数 > 4 的进"阁"，其余随机回堆
>
> 因为牌**不会全部进入弃牌堆**（只去"阁"中和随机插入）→ 不会触发一技能的"弃置本回合因此技能获得的牌"（因为你本回合没有因八斗方醉获得过牌）

---

**后半段——抵消、防御：**
- 每回合限一次
- 当你成为其他角色**打出的牌的目标**时：
  - 可以**弃置"阁"中的一张牌**，**抵消此牌**

> 类似主父偃的防御技能——"阁"中有牌即可抵消杀等攻击

---

## 三、组合搭配

### 控顶 / 看顶辅助类

| 武将 | 作用 |
|------|------|
| **申不害** | 自己看牌堆顶 1 张牌的点数 → 若点数 **< 4** 可建议队友发动一技能（容易 ≤8）；若 > 4 不建议 |
| **主父偃** | 让小点牌放到牌堆顶，提高点数 ≤ 8 的概率 |
| **嬴政** | 查看牌堆顶的牌 |
| **卓文君** | 查看牌堆顶的牌 |

### 给牌类

| 类型 | 说明 |
|------|------|
| **一次性给 2 张小点牌** | 山涛获得后 → 点数 ≤ 8 → 加酒 + 次数 +1 |
| 配合思路 | 找能给山涛 2 张小点牌（如 2+3=5、3+3=6）的武将 |

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 2v2 联动型武将，靠队友查看牌堆顶 + 点数运算白嫖酒 + 次数 |
| **一技能（八斗方醉）** | 队友看牌堆顶 2 张 → 山涛选获得堆牌或队友手牌；点数和 ≤ 8 则加酒 + 次数 +1；否则弃本回合获得的所有牌 |
| **二技能（悬丝积尘）** | 获牌前展示 → 点数 > 4 入"阁"，其余随机回堆（不控顶）；每回合限一次弃"阁"中牌抵消对手打出的牌 |
| **核心收益** | 点数 ≤ 8 时白嫖 2 张 + 1 张酒 + 次数 +1，至少拉 3 牌差 |
| **概率基础** | 点数和 ≤ 8 概率约 **43%**，近一半能嫖牌 |
| **兜底机制** | 二技能在获得前过滤 → 避免一技能"否则弃牌"的负面效果 |
| **推荐搭配** | 申不害（看顶判定点数）、主父偃（控小点牌上堆顶）、嬴政 / 卓文君（看牌堆顶）、一次性给 2 张小点牌的武将 |
| **讲者评价** | 2v2 玩家视角友好；不纠结单挑和"嘴牌"，看重与队友的联动配合 |
