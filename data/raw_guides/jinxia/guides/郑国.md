# 《名将杀》郑国武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 5 手牌上限**，3 个技能
- **核心机制**：**"渠"牌体系**——把对手手牌全变废牌，自己还能白嫖资源
- **讲者定性**：机制特别绕，但三个技能形成**完美控制闭环**，主打控制流

---

## 二、技能详解

### 技能一：作注溉渠（每轮开局塞垃圾）

**触发时机：** 每轮**开始时**（1 号位还没动时）发动，第一轮 / 第二轮 / 第三轮……每轮都能开一次

**效果：**
- 你手中有多少废牌，就可以把它们**全部变成渠**
- 分给场上**不同的人**（一人最多 1 张，不能分给同一人）
- **再摸同样数量的新牌**
- **你手里的渠不进入手牌上限**（放多少张都没事）

**"渠"是什么？**
> 游戏中**最恶心的垃圾牌**——打不出去、扔不掉，还**永久占对方手牌上限**
>
> 比曹仁的"笞"还要恶心

**2v2 实战举例：**
> 场上 4 人 → 把 4 张废牌变成分给 4 人各 1 张 → 自己摸 4 张新牌
>
> = 用 4 张垃圾换 4 张好牌 + 给全场套永久 Debuff → **血赚不亏**

---

### 技能二：疲秦之计（垃圾换好牌）

**触发条件：**
- 别人拿了你的任何一张牌（主动给的、被夺粮劫营 / 调兵遣将抢走的都算）
- **且他手中有渠**
- 每名角色每个回合**限 2 次**（官方后加的平衡限制，防止军八无限传牌 Bug）

**效果：**
- 选择一个**方向**（顺时针 / 逆时针）
- 让他**随机将一张牌传给下一个手中有渠的人**
- 下一个人再传……**一直传到你手中才停止**
- 方向一旦定了不能改

**收益本质：用一张垃圾的渠，换对手一张有用牌**

| 轮次 | 操作 | 收益 |
|------|------|------|
| 第 1 轮 | 给下家塞 1 张渠 | 他手中有渠了，但尚未触发 |
| 第 2 轮 | 再给下家塞 1 张渠 → 他手中有渠 → **触发技能** | 他随机传 1 张牌给你 → 只要不是渠 = **稳赚 2 牌差** |

**额外收益：**
- 对面手中多留 1 张渠 → 继续被卡手牌上限（**一直存在**）
- 2v2 中每回合限 2 次完全够用（除你外只有 3 人，死了还剩 2 人）

**★ 魔鬼性质——首轮无法联动：**
> 第一轮给下家塞渠时，他手中**没有渠** → **触发不了二技能**
>
> 一二技能联动**必须等到第二轮**才能实现

**应对传回"渠"：**
> 你手里的渠不算手牌上限 → 放手里即可；对方抢你牌正好把烂渠再塞回去

---

### 技能三：关中沃野（清理队友的渠 · 免费换牌）

**效果：**
- 出牌阶段限一次
- 给**有渠的人**一张牌 → 销毁他手中一张渠 → 你再摸一张牌

**核心用途：**
- **清队友手中的渠**（传牌难免误伤队友）→ 队友恢复正常留牌
- 给 1 张摸 1 张 = **免费换 1 张牌**，一点都不亏

---

## 三、技能联动闭环

```
一技能（塞垃圾） → 给对手塞渠，永久占手牌上限
    ↓
二技能（用垃圾换好牌） → 对手手中有渠被抢 → 强制传牌 → 换好牌
    ↓
三技能（帮队友擦屁股） → 清队友的渠 + 免费换牌
```

---

## 四、组合搭配（四大类）

### 第一类：传牌刷牌流

**核心思路：** 利用二技能的传牌，触发队友"获得牌就有收益"的技能

| 组合 | 效果 |
|------|------|
| **郑国 + 陈宫** | 传牌故意经过陈宫 → 成功拿到牌再传给你 = 免费出牌机会 |
| **郑国 + 卢莫愁** | 卢莫愁传回来触发阳春白雪印牌 |
| **郑国 + 张骞**（黑科技） | 张骞坐 1 号位 + 郑国坐 4 号位 → 开局 5 张变 4 张渠 + 自己剩 1 张 → 摸 4 张 = 6 张牌 → 给张骞 1 张 → 张骞有夺粮劫营首回合直接刷新他的"丝绸之路" |
| **郑国 + 甘宁** | 渠默认是**黑桃牌** → 帮甘宁快速过黑桃 |

---

### 第二类：陷害塞渠流

**核心思路：** 把渠给队友 → 队友转手塞给对面 → 几轮下来对手全是垃圾

| 武将 | 特点 |
|------|------|
| 如姬 | 拿到渠还能传给别人 |
| 孟尝君 | 同上 |
| 郑袖 | 同上 |
| 吕不韦 | 同上 |
| 西门豹 | 同上 |

> 两轮下来对手全是渠 → 想留桃留闪都留不住 → **回合外就是活靶子**

---

### 第三类：防御蹭牌流

**核心思路：** 郑国每轮多过 3~4 张牌 → 配合蹭牌武将

| 组合 | 效果 |
|------|------|
| **郑国 + 赵婕妤** | 把玉钩绑在郑国身上 → 郑国每轮转渠摸 4 张 → 赵婕妤同步复制 4 张 → **团队每轮白嫖 4 张** |
| **郑国 + 周勃 / 英布** | 郑国首轮 6 张牌 → 每轮额外摸牌 = 全场最高 → 周勃 / 英布摸到和郑国一样多 |
| **郑国 + 步练师** | 郑国手牌永远比步练师多 → 步练师每回合稳定摸牌 |

---

### 第四类：加速控制流 + 抢牌组合

**加速控制：**
| 武将 | 效果 |
|------|------|
| 张仪 / 平阳公主 | 复制郑国一技能 → 每轮开始时**两人一起**给对面塞渠 |

**抢牌组合——桑弘羊：**
> "疲秦之计"传牌过程中，每次有角色获得牌 → 桑弘羊抢 1 张
>
> 传牌**不会因为被抢而停** → 被抢的人还得再拿 1 张继续传
>
> 最终：**对手损失 2 张 + 桑弘羊抢 1 张 + 郑国赚 1 张 = 稳定 4 牌差**

---

## 五、致命短板

> **郑国没有任何防御技能**——遇到爆发武将，可能两回合就被秒
>
> 与纯防御类武将联动又不够 → 建议优先按上面盘点的组合把控制手拉满

> **"自己爽不如别人不爽，别人不爽也就是自己爽"**

---

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 控制流武将，靠"渠"牌永久废牌 + 换牌 + 误伤队友 |
| **一技能（作注溉渠）** | 每轮开始把手中废牌变成分发全场，再摸等量牌；自己渠不占手牌上限 |
| **二技能（疲秦之计）** | 对手手中有渠被抢牌时触发强制传牌（限 2 次）→ 用渠换好牌 |
| **三技能（关中沃野）** | 给有渠的人 1 张牌 → 销毁其渠 + 摸 1 张牌 |
| **核心闭环** | 塞垃圾 → 换好牌 → 清队友渠 |
| **魔鬼性质** | 一二技能联动必须等第 2 轮（第 1 轮下家没渠） |
| **区牌特性** | 打不出 / 扔不掉 / 永久占手牌上限 / 默认黑桃 |
| **组合方向** | 传牌刷牌（陈宫 / 卢莫愁 / 张骞 / 甘宁）、陷害塞渠（孟尝君等）、蹭牌（赵婕妤 / 步练师）、加速控制（张仪 / 平阳公主）+ 抢牌（桑弘羊） |
| **讲者建议** | 优先拉满控制手，不必追求防御联动 |
