# 《名将杀》信陵君武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 3 技能  / 5 手牌**
- **核心定位**：控牌 + 流血 + 获取牌的**恶心型控制武将**，三个技能形成强力联动

---

## 二、技能详解

### 技能一：食客三千（每轮查牌 + 标记获取）

**技能描述：**
- 每轮开始时，你**查看其他所有角色各一张手牌**
- 当你**查看过的牌被打出**后 → **你获得此牌**

**关键机制：**

| 要点 | 说明 |
|------|------|
| 人越多越强 | 看的人的牌越多越强（但 2v2 轮次过得快，也很强） |
| 看牌操作**仅自己清楚** | 其他角色看不到你看了哪张牌 |
| 被标记的牌**只能被打出后**才能被获得 | 被弃置 / 给其他角色 → **不会**被获得 |
| 给其他角色了**也会保留标记** | 只要最终被打出来 → **永远**会被信陵君获得 |
| **永久累计标记** | 多轮次标记的牌持续生效（到后期标的牌越标越多） |

**实战举例：**
> 第一轮查看到对手一张桃（未打出）→ 第二轮又查看到对手一张闪 → 这两张牌都被系统自动标记 → 之后桃和闪只要被打出 → 都可被信陵君获得

**★ 防标记唯一办法：弃掉这张牌**

---

### 技能二：盗符刺将（装备牌挂流血 + 流血增伤）

**前半段——流血增伤：**
- 当你选择杀的目标时，若**目标有流血状态** → **杀对其伤害 +1**

**后半段——获得装备牌挂流血：**
- 当你**获得其他角色的装备牌**时 → 可令另一名其他角色**增加一层流血**

**⚠️ 关键规则：**
> "获得其他角色的装备牌"必须是**从其他角色处直接获得**，而非从牌堆中摸取
>
> - ✅ 通过夺粮劫营获得 → 算
> - ✅ 通过食客三千获得 → 算
> - ✅ 队友给牌给你一张装备牌 → 算
> - ❌ 步练师让你从牌堆摸一张装备牌 → **不算**

**"流血"负面状态说明：**
- 回合结束时**直接失去 1 点体力**并清除一层流血
- **流血层数可叠加**
- 挂流血**没有任何负面代价**——纯收益

---

### 技能三：魏死士（标记牌堆顶 · 控手牌 · 核心控制）

**技能描述：**
- 回合结束时，查看**牌堆顶 3 张牌**
- **标记其中一张牌**
- 将所有牌**按顺序放回牌堆顶**

**★ 关键规则——"按顺序放回"不会被改变：**
> 无论你怎么调换牌的顺序，**判定结果不会改变**——仍然是原来对应位置的牌被判定


**被标记的牌（"死士"牌）的两种结算：**

| 情况 | 效果 |
|------|------|
| 被标记的牌**被其他角色打出**时 | 令其**增加一层流血** + **销毁此牌**（打出无效） |
| 被标记的牌**被弃置**时 | **你获得此牌** |

**显示规则：**
> 所有人都能看到**谁手上有多少张死士牌**，但**不会显示具体哪张牌是死士**

**核心恶心之处：**
> 信陵君通过查看牌堆顶 → 猜测下家会打出哪张牌 → 标记它 → 下家打出即流血 + 无效，弃掉则被信陵君获得 → **完美控手牌**

**⚠️ 无控顶效果：**
> 只是查看了牌堆顶，**不能改变牌的顺序**

---

## 三、★ 三技能联动闭环

```
一技能（食客三千）
    → 每轮查看全场各 1 张手牌 → 被打出即获得
        ↓
二技能（盗符刺将）
    → 若获得的牌是装备牌 → 给任意角色挂 1 层流血
        ↓
三技能（魏死士）
    → 标记牌堆顶 → 下家打出死士 → 加 1 层流血 + 销毁
    → 下家弃掉死士 → 信陵君获得
        ↓
【控牌 + 流血 + 获取 完美联动】
```

## 四、位次策略

| 位置 | 是否推荐 | 原因 |
|------|----------|------|
| **1 号位** | ✅ 推荐 | 看 2 号位（敌方）的牌 |
| **3 号位** | ✅ 推荐 | 看 4 号位（敌方）的牌 |
| 2 号位 | ❌ 不推荐 | 下家是队友 → 很尴尬 |
| 4 号位 | ❌ 不推荐 | 下家是队友 → 很尴尬 |

> **信陵君只能坐 1、3 号位**——因为看的是下家的摸牌阶段摸的牌，下家必须是敌方

## 五、组合搭配

| 武将 | 联动效果 |
|------|----------|
| **张良**（讲者推荐） | 张良给队友一张武器牌并让其装备 → 信陵君获得装备 → 触发盗符刺将挂流血 → 联动起来 |

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 控手牌 + 流血增伤 + 永久获取牌的恶心型控制武将 |
| **一技能（食客三千）** | 每轮查看全场各 1 张手牌 → 被标记牌被打出即获得（不可弃牌规避，永久累计） |
| **二技能（盗符刺将）** | 目标有流血 → 强杀 +1 伤害；获得其他角色装备牌 → 给任意人挂 1 层流血（无代价） |
| **三技能（魏死士）** | 回合结束标记牌堆顶 1 张 → 下家打出死士则加流血 + 销毁；下家弃掉则信陵君获得 |
| **核心联动** | 食客三千拿装备 → 盗符刺将挂流血 → 魏死士控下家手牌 → 三技能闭环 |
| **关键规则** | 盗符刺将只能获得"其他角色的装备牌"（非牌堆摸取）；魏死士无控顶效果；调换顺序无效 |
| **位次铁律** | **只能坐 1、3 号位**（下家必须是敌方） |
| **推荐搭配** | 张良（给武器牌触发盗符刺将） |
| **讲者评价** | 评分高，技能强制，控制恶心程度极高，值得体验 |
