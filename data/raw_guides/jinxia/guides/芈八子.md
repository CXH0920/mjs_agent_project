# 《名将杀》芈八子武将解析

---

## 一、武将背景与定位

- **基础属性**：**5 体力上限 / 4 手牌上限**，秦国女性武将
- **核心定位**：**从下水道"不动白"和弱辅助 → 直接晋升为强辅助**

---

## 二、技能详解

### 技能一：楚姝入秦（不再依赖受伤觉醒 · 完美解决不动白）

**技能描述：**
- 登场时**将势力改为楚**
- **受伤或回合开始时**，你可以：
  - 令自己的**体力上限 +1**
  - **回复所有体力**
  - 将势力改为秦
  - 获得技能**易鼎鸣凤**和**权御四贵**
  - 并失去此技能


> 杀牌游戏中卖血技能看似强大，但遇到会玩的对手 → 卖血将往往成为**不动白**（别人不碰你，你就没收益）

**★ 觉醒前白嫖受伤小技巧：**
> 首回合前，**不要急于觉醒**——在觉醒之前可先在回合外吸收敌方伤害：
>
> 敌方首次造成伤害 → 先别觉醒 → 多吸收一点伤害 → **进入自己回合再觉醒 → 一口气把血回满**
>
> 否则敌方第一刀打过来你就觉醒，他再打第二刀 → 白白觉醒还多掉一点血

---

### 觉醒技能一：易鼎鸣凤（势力选择 + 附加目标）

**技能描述：**
- 出牌阶段限一次
- 选择**一名其他角色**，令其**选择**：
  - **将势力改为与你相同**，或
  - **弃置 2 张手牌**（只能弃手牌，非装备区）

**★ 与嬴政 / 张仪 / 平原君的霸道方式不同：**
| 武将 | 修改势力方式 |
|------|-------------|
| 嬴政 / 张仪 / 平原君 | **直接修改**，不给选择 |
| **芈八子** | **给选择**——要么同势力，要么弃 2 张手牌 |

**策略应用：**
| 目标 | 策略 |
|------|------|
| **队友** | 优先选队友作为目标 → 让队友势力相同 → 触发衍生二技能 |
| **敌方** | 后续回合选敌方 → 对方往往选择同势力（而非弃 2 张手牌）→ 触发后续效果 |

**后续效果——附加目标：**
> 势力与芈八子相同的其他角色，以你为目标打出牌时，你可**为此牌增加另一名其他角色为目标**

**实战举例：**
> 秦国队友放烽火狼烟（以芈八子为目标） → 芈八子可为此牌增加新目标 → **让另一个角色额外成为此牌目标**（变成 2 次烽火狼烟目标）

**无势力情况的处理：**
| 情况 | 效果 |
|------|------|
| **芈八子为无势力**（被嬴政移除） | 技能仍可发动，但目标**只能选择弃牌**（无法选择同势力） |
| **目标为无势力** | 无法选择同势力，**只能选择弃 2 张牌** |

---

### 觉醒技能二：权御四贵（可反复发动的强辅助给牌）

**技能描述：**
- 出牌阶段，可交给一名与你**势力相同**的其他角色**一张牌**
- 当其**拥有此牌**时，其**每回合打出的前两张牌** → **生效两次**


**实际效果：**
> - 可以对队友 A 一张一张给牌
> - 也可以对队友 B 一张一张给牌
> - **无次数限制**

**"贵牌"效果详解：**

| 情况 | 效果 |
|------|------|
| 每回合前两次出牌 | 效果**翻倍** |
| 持有多个贵牌时 | 使用其中一张贵牌仍翻倍 |
| 回合外向敌方出杀 | 结算**两次** |
| 回合内打出怒 | 结算**两次**且**不弃牌** |
| 回合外队友濒死打桃 | 结算**两次** → **回 2 滴血** |

## 三、组合搭配

### 芈八子 + 刘邦（辅助配辅助 · 讲者实盘演示）

**核心逻辑：**
> 刘邦同样擅长给牌 → 两人形成"给牌交换"羁绊：
>
> - 可以不断给牌 / 交换牌
> - 保证芈八子手中**一直有牌**
> - 避免为了辅助队友而送光手牌的尴尬

**实战亮点（讲者直播解说）：**
- 留 1 张 5（梅花）在手上不换 → 直接变势力
- 给牌过程中刷牌到只剩 1 张（防止陆逊连起来）
- 通过给牌 + 贵牌翻倍 → 实现强爆发
- 刘邦"大风歌"的给牌与芈八子贵牌翻倍形成联动
- 桃翻倍回 2 血、杀翻倍打 2 次等效果充分展示

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 强辅助武将（增强后），非不动白；可给队友无限贵牌 + 势力联动 |
| **一技能（楚姝入秦）** | 登场改楚势力；受伤或回合开始时觉醒：上限+1、回满血、改秦势力、获双技能 |
| **觉醒一（易鼎鸣凤）** | 目标选择：同势力 或 弃 2 手牌；同势力者对你用牌可加 1 个新目标 |
| **觉醒二（权御四贵）** | 给同势力队友一张牌 → 其每回合前 2 次出牌翻倍（可反复发动，无次数限制） |
| **觉醒小技巧** | 首回合前吸收敌方伤害再觉醒 → 一口气回满血 |
| **强力搭配** | 刘邦（辅助配辅助，给牌交换）、其他给牌武将 |
| **贵牌翻倍效应** | 杀双结算、怒双结算不弃牌、桃双回 2 血 |
| **讲者评价** | 强辅助，组合搭配非常多，值得游戏内多体验 |
