# 《名将杀》赵威后武将解析（新版加强版）

---

## 一、武将背景与定位

- **加强争议**：虽有争议，但**官方定性为加强**，讲者按加强来分析
- **核心变化**：**二技能"质子为兵"从防御不动牌技能 → 主动进攻控制技能**，出场率和胜率预期大幅飞跃（原胜率约 **40%**）

---

## 二、技能详解

### 技能一：无民何有君（不变 · 触发判定掉血）

**触发条件（只要目标满足其一即可）：**
| 情况 | 典型武将 |
|------|----------|
| **跳过摸牌阶段** | 被久旱 |
| **失去最后手牌**（被打空 / 被拆空） | 各种攻击 / 拆牌 |
| **手牌被烧毁** | 烈火焚城、陆逊、吕雉、刘邦 |
| **手牌被移除** | 徐盛、王翦 |

**效果：** 令其判定，若**不为梅花** → 失去 **1 点体力**

**搭配对象（能销毁对方牌的武将）：**
| 类型 | 武将 |
|------|------|
| 销毁牌 | 白起、刘彻、平原君 |
| 烧毁 | 陆逊、徐晃 |
| 移除 | 王翦、徐盛 |

**★ 冷知识——克制燕昭王：**
> 將牌放入特殊牌区也算移除例如：燕昭王、韩信、张郃等 = 移除牌
>
> 赵威后**非常克制燕昭王**，也克制想嫖燕昭王黄金牌的角色

---

### 技能二：质子为兵（★ 新版加强 · 核心控制技能）

**原版**：防御不动牌（被动挨打）
**新版**：**主动进攻控制技能**——出牌阶段限一次

**技能流程：**

```
另一名其他角色获得你区域内的一张牌（装备区/手牌区）
        ↓
该角色必须交给你至少一张牌
        ↓
你受到的下一次伤害 -1
        ↓
当你打出因此获得的牌时 → 弃置另一名其他角色一张牌
```

**核心逻辑：**
> 队友给牌越多 → 能打出去的牌越多 → 拆对面牌越多
>
> 赵威后**坐 1 号位 + 配 4 号位袁术 / 子婴** → 把所有能打出的牌全交给赵威后 → 用出去后把对面两个人**全部扒光**，还能通过无民何有君令其判定 → **压制力极大**

---

## 三、组合搭配（三类）

### 一、给牌组合（刷牌型 · 类比蔺相如的"将相和"）

**原理**：蔺相如的"将相和"也是流失体力后找角色拿任意一张牌强化打出；赵威后逻辑相似——**凡能与蔺相如搭配的，都能与赵威后搭配**

| 武将 | 效果 |
|------|------|
| **陈阿娇 / 季布 / 孙权 / 刘彻 / 陈平** | 给大量手牌获得额外收益；先将牌给他们，他们反应我们的牌时，赵威后可把对面扒光 |
| **荆轲 / 李牧 / 廉颇 / 陆机** | 手牌数量越低 → 触发技能越频繁 → 给牌后手牌变少反而更容易发动技能 |
| **袁术 / 子婴 / 章邯** | 把所有能打出的牌全交给赵威后 → 扒光对面 |
| **羊祜** | 回合外也易有大量牌，可能出不完 → 给赵威后出正好 |
| **卫青** | 主动交武刚车给赵威后 |
| **赵婕妤** | 蹭第一波给赵威后的牌，形成刷牌组合（非常强大） |
| **太子丹** | 给完牌只剩 1 张 → 赵威后主动将其拆光 → 触发太子丹技能 |

---

### 二、拆牌组合（双管齐下扒光）

| 武将 | 效果 |
|------|------|
| **大乔** | 赵威后拆一个 + 大乔拆一个 |
| **甘宁 / 高渐离** | 配合拆牌（但这两将较缺牌） |
| **刘表** | 捡场上的弃牌 |
| **魏咎** | 标记一个人去获得他的弃牌 |

> 刘表 / 魏咎与赵威后搭配是"天作之合"

---

### 三、蹭牌组合

| 武将 | 效果 |
|------|------|
| **步练师** | 把牌给过来后牌变少 → 每回合可以多蹭 1 张 → 一轮多蹭 4 张 |
| **尉缭** | 赵威后把别人扒光后 → 令其判定 → 尉缭蹭一张梅花 |

**★ 扒光后的连锁压制：**
> 只要第一波把对面扒光 → 对手后续只能摸 2 张牌 → 用完了又光 → 光了你又让他判定 → 判定完再扒光
>
> 如果他自己不用光 → 再次扒光也很轻松

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 1 号位主动控制型武将，通过给牌 → 打出 → 拆牌的循环扒光对手 |
| **一技能（无民何有君）** | 对方跳过摸牌 / 失去最后牌 / 牌被烧毁 / 牌被移除 → 令判定非梅花掉 1 血 |
| **二技能（质子为兵）** | 队友拿你区域内牌 → 必须交你至少 1 张 → 你下一次受到伤害 -1；打出获得牌 → 弃对方 1 张 |
| **核心打法** | 赵威后坐 1 号位，4 号位配袁术 / 子婴给牌 → 用出全部扒光 + 触发判定 |
| **最强搭配** | 陈阿娇 / 季布 / 孙权 / 羊祜；刘表 / 魏咎（拆牌伙伴）；赵婕妤（刷牌）；太子丹（触发连锁） |
| **克制对象** | 燕昭王（黄金牌 = 移除）；所有销毁 / 烧毁 / 移除牌型武将 |
| **讲者评价** | 1 号位控制稳定性甚至**超过甘宁和高渐离**；新版可开发程度非常高，值得深入体验 |
