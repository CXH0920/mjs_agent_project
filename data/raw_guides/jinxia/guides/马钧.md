# 《名将杀》马钧武将解析

---

## 一、武将背景与定位

- **讲者态度**：
  > 不理解很多玩家说“马钧太垃圾了、马钧砍废了”——**自己削弱后胜率甚至觉得是加强了**
  > 削弱前因为太强被放逐 → 削弱后才能放出来玩到 → **“马钧越弱，马钧越强”**
- **核心观点**：马钧其实**非常强**，很多玩家还在用**削弱前的思维**，陷入了误区
- 技能数量：3 个技能（**全部是出牌阶段限一次**）

---

## 二、技能详解

### 技能一：水转百戏
**技能描述：**
- 出牌阶段限一次，将至少一张**黑桃牌**弃置到牌堆，选一名角色（**可选择自己**），依次翻开等量牌并对其自动打出，你获得其中无法打出的牌。
- 自动打出由**牌堆**执行，**非马钧对其打出**。
- 目标阵亡后，剩余翻出的牌全部成为“无法打出”，归马钧收入。
- 弃黑桃越多 → 翻牌越多；对敌方发动可能资敌，但**伤害牌 > 非伤害牌**，总体收益为正。

| 场景 | 说明 |
|------|------|
| **① 牌少就不用**（最关键） | 很多时候都不用——**避免自敌或坑队友** |
| **② 收割残血敌人** | 用水转百戏把敌人打死后 → 后续翻出的牌**都归马钧** |
| **③ 对卖血 / 被杀有收益的武将使用** | 非常舒服，如郭嘉、赵云、杜预 |
| **④ 留夺粮劫营 + 破阵卸甲** | 用完后用夺粮劫营把装备拿回来继续扭；剩下装备用破阵卸甲拆掉 |

可搭配**申不害、嬴政、主父偃**等控顶武将，保证翻开牌堆顶有稳定收益。
---

### 技能二：龙骨汲流
**技能描述：**
- 出牌阶段限一次，将一张**梅花牌**转化为一张**装备牌**。
- 当你打出装备牌后：
  - 将**弃牌堆中的黑桃牌洗回牌堆**
  - **装备区每存在一张梅花牌就获得一张黑桃牌**

注意要点：
- 装备转化是**半定向**——系统刷出 3 张装备任选 1 张。
- 装备区中**仅梅花花色装备**计入摸牌，其余花色不计。
- 期望摸黑桃数（按♣装备占比 8/26 ≈ 33.3% 的概率期望计算）：

- 黑桃牌内容：不仅有防御牌，还有**夺粮劫营、破阵卸甲、霜冻**等控制 / 输出战法。

---

### 技能三：巧思绝世

**技能描述：**
- 出牌阶段限一次，可将一名角色的**一张牌的花色改为你选择的任意一种花色**。
- 用途：
  - 把原有装备的花色**转换为梅花**（稳定）。
  - 改自己的牌为梅花 → 确保触发二技能转装备
  - 配合刚需花色武将：司马相如（刚需黑桃）、孟获（刚需土花色）

---

## 三、削弱内容解析

| 维度 | 削弱前 | 削弱后 |
|------|--------|--------|
| 龙骨汲流发动条件 | 装备区每存在一张牌（**任意花色**） | 装备区每存在一张**梅花牌**（**仅梅花**） |

> 削弱**只增加了一个限定符号——“梅花”**——仅此而已

---

## 四、梅花装备的两个稳定产出方式

| 方式 | 说明 | 概率 |
|------|------|------|
| **① 龙骨汲流** | 无脑选择梅花装备 | **有概率不出梅花** |
| **② 巧思绝世** | 把原有装备的花色**转换为梅花** | **稳定** |

> 只要掌握这两点，马钧的过牌量和削弱前**不会差太多**

---

## 五、★ 削弱后公式化打法

```
第一步：优先发动龙骨汲流
    → 把一张梅花牌转成装备
    → 优先选择梅花装备

第二步：先上梅花装备
    → 再上其他花色装备
    → 上其他花色装备前，先用巧思绝世把装备颜色转换为梅花
    → 让龙骨汲流的摸牌收益最大化

【过牌量和削弱前不会差太多】
```

## 六、技能联动与搭配

### 技能联动闭环

三技能造梅花 → 二技能刷梅花装备摸黑桃 → 一技能弃黑桃打出伤害牌。

### 最大化爆发：配合吴国太

吴国太给马钧上 3 个装备 → 摸 6 张黑桃 → 卸下装备 → 回合内再装上 → 又摸 6 张 → 再装其他装备 → **一回合摸多张黑桃牌**。

| 吴国太 | 给装备 + 可下装备反复装（强力联动） |
| 侯嬴 | 给装备牌 |
| 傅玄 | 给装备牌 |
| 刘禅 | 给装备牌 |

| 钟无艳 | 给装备牌 |
| 刘备 / 子婴 | 定向给牌 |
| 黄月英 | 较牵强（复制别人牌 + 刷黑桃） |

#### 黑桃牌联动类

| 武将 | 作用 |
|------|------|
| 郑国 | 黑桃武将 |

#### 控顶类（保证翻开牌堆顶有稳定收益）

| 武将 | 作用 |
|------|------|
| 申不害 | 控顶 |
| 嬴政 | 控顶 |
| **主父偃**（推荐） | 把杀全放到牌堆顶 → 一翻全是杀 |

#### 多倍技能类

| 武将 | 作用 |
|------|------|
| **王元姬** | 马钧三个技能全是出牌阶段限一次 → 配合后变为**限两次** → 能用 6 次技能（多用一倍） |
| **太子丹** | 马钧把黑桃放到牌堆顶可清空手牌 → 触发太子丹改弃牌阶段为出牌阶段（需注意排序） |

## 七、总结

| 维度 | 要点 |
|------|------|
| **定位** | 削弱后依然非常强，关键是用对公式化打法；免费联动武将，打装备刷黑桃 → 弃黑桃爆发的滚雪球型 |
| **削弱内容** | 龙骨汲流发动条件增加“梅花”限定 |
| **梅花产出** | ①龙骨汲流选梅花装备（有概率） ②巧思绝世转梅花（稳定） |
| **公式化** | 龙骨汲流转梅花装备 → 先上梅花装备 → 巧思绝世转其他花色为梅花 → 最大化龙骨汲流收益 |
| **水转百戏** | 牌少不用（避免自敌）；收割残血；对卖血武将使用；配合夺粮劫营 / 破阵卸甲循环 |
| **技能联动** | 巧思造梅花 → 龙骨转装备摸黑桃 → 水转百戏弃黑桃打伤害；可搭配吴国太、主父偃、王元姬等 |
| **注意事项** | 对敌方一技能发动可能资敌（需保证翻牌中伤害牌 > 收益牌） |
| **讲者胜率态度** | 削弱后自己反而觉得加强了——因为能放出来玩了 |
