# 《名将杀》司马炎武将解析

---

## 一、武将背景与定位

- **身份**：第六赛季战令武将，3 个技能
- **讲者定性**：**"非常阴间的轮椅武将"**（轮椅 = 单人可玩）
- **核心机制**：**用一摸一 / 用一摸多无限连**，清场怪
- **官方平衡考量**：为防其成为第二个赵姬，二技能对"怒"做了前期限制
- **组合搭配**：自身已够强，**不一定需要组合也能赢**

---

## 二、技能详解

### 技能一：泰始新律（全局削弱 · 核心发动机）

**前半段——削弱全场一种同名牌：**
- 司马炎可选择削弱游戏中**一种所有的同名牌**
- 例：削杀 → 火杀 / 雷杀 / 普通杀全部受影响
- **优先削弱数量最多的牌**以影响更多人：
  - 火杀 27 张
  - 杀共 45 张

**后半段——打出削弱牌后削弱对手：**
- 自己打出削弱牌后，可**削弱一名角色的 2 张牌**
- **关键：可削弱自己的牌**

**首回合爆发玩法（另类打法）：**
> 削弱一种**非杀牌** → 首回合打出此牌 → 削弱自己 2 张 → 这三张牌打出去 → 摸 3 张牌（三技能联动）→ **一直摸一直削，永无止境**

---

### 技能二：容纳谠正（怒的变身 + 免疫削弱）

**效果一——怒只能当战法牌打出：**
- 司马炎的怒只能当作**上一张被打出的战法牌**打出
- 不局限于自己的战法牌（可复制敌方战法牌）
- 例：上家打多多益善 → 司马炎用怒 → 复制多多益善
- 例：司马炎先打夺粮劫营 → 再用怒 → 复制夺粮劫营

**★ 机制限制的原因：**
> 司马炎一、三技能可用一摸一无限连 → 若能喝大量怒打出暴击 → 成为第二个赵姬（阴间）
>
> 官方限制怒只能当战法打出 → **前期无法通过怒打出暴击伤害**
>
> 想打暴击伤害只能通过**开山斧、羽扇**等牌

**效果二——免疫削弱牌负面效果：**
- 司马炎自己打出的牌和装备区的削弱牌，**以普通牌效果生效**
- **注意：只是暂时的**——三技能触发"善始难终"阶段后失效

---

### 技能三：善始难终（用一摸一 · 失去二技能后解锁）

**触发条件：所有角色累计打出 15 张削弱牌后：**
- 司马炎**失去二技能**
- **新增效果**：每回合限一次，**获得牌时削弱这些牌**

**联动机制——用一摸一：**

```
打出削弱牌 → 摸 1 张牌（三技能）
    ↓
削弱自己 2 张牌（一技能）
    ↓
打出这 2 张削弱牌 → 再摸 2 张（三技能）
    ↓
一直摸一直削，无限连 → 清场牛牛怪
```

**★ 失去二技能后的效果变化：**
| 效果 | 变化 |
|------|------|
| 怒恢复原效果 | 可正常打出 |
| 削弱牌回归真身 | 不再是普通牌 |
| 获得牌时削弱 | 摸到削弱牌 → 可打出再摸牌 |

**配合大额给牌武将的收益：**
> 郭嘉在司马炎觉醒后交给他 5 张牌 → 5 张立刻变成削弱牌 → 打出可再摸 5 张 → **子子孙孙无穷尽也**


---

## 三、公式打法

| 步骤 | 操作 | 要点 |
|------|------|------|
| **① 首回合开大** | 削弱一种牌（削杀影响多人 / 削非杀保首回合能打出） | 视情况选择 |
| **② 无限连削牌** | 打出削弱牌 → 削弱自己 2 张 → 打出 → 摸牌 → 再削再摸 | 核心连招 |
| **③ 收尾削弱对手** | 当自己可打出牌不足 2 张时 → 开始削弱对手的牌，降低其后续进攻 | 清场收尾 |
| **④ 恢复自己后再削** | 等有 2 张可出之牌时 → 再来削弱自己（因为削自己 = 额外摸 2 张） | 保持循环 |

> 1 号位直接起飞，打法非常简洁

---

## 四、组合搭配（三类）

### 一、大额给牌类（至少技能能给 ≥ 3 张牌）

| 武将 | 效果 |
|------|------|
| 刘备 | 给大量牌 |
| 郭嘉 | 受伤后给牌 |
| 孙权 | 大额给牌 |
| 郑袖 | 大额给牌 |
| 吕不韦 | 大额给牌 |
| 萧何 | 大额给牌+给出牌阶段 |
| 夏侯惇 | 大额给牌 |

> 牌越多 → 削自己越多 → 用一摸一循环越强

---

### 二、破防暴击流（骚操作）

**核心逻辑：**
> 削弱后的闪**只能抵消杀的普通伤害**，无法抵消**多点伤害**
>
> 把对方所有闪削弱掉 → 再配一个**孙坚**打出七八点暴击 → 削弱闪无法全部免疫 → **形成暴击**

| 武将 | 角色 |
|------|------|
| 司马炎 | 削弱敌方闪 |
| **孙坚、关羽、项羽、张飞、张梁** | 打出多点暴击 |


---

### 三、用一摸多流（用一摸一 → 用一摸二）

| 组合 | 效果 |
|------|------|
| **诸葛亮（舌战群儒）** | 打出战法多摸 1 张 → 打出的是削弱战法 → 三技能再摸 1 张 → **用一摸二** |
| **徐盛** | 司马炎上削弱装备（摸 1）→ 打削弱战法对徐盛出 → 徐盛收回装备（摸 1）→ 打削弱装备（摸 1）→ **司马炎摸 4 张牌** |
| **李牧** | 频繁打出削弱杀 → 频繁摸牌且不进入次数限制 |
| **申不害 / 吕雉** | 特定花色摸牌 → 频繁摸牌 |

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 阴间轮椅武将，用一摸一无限连清场 |
| **一技能（泰始新律）** | 削弱全场一种同名牌；打出削弱牌削对方 2 张（含自己） |
| **二技能（容纳谠正）** | 怒只能当战法牌打出；司马炎削弱牌以普通牌生效（临时） |
| **三技能（善始难终）** | 累计 15 张削弱牌后失去二技能 → 获得牌时削弱 + 打出削弱牌摸 1 张 |
| **核心机制** | 打出削弱牌 → 削自己 2 张 → 再打出 → 再摸 → 无限连 |
| **15 张削弱牌阈值** | 触发觉醒，怒恢复正常，削弱牌回归真身 |
| **最强打法** | 首回合开大削非杀 → 无限连削自己 → 收尾削对手 |
| **推荐组合** | 大额给牌（刘备 / 郭嘉 / 孙权 / 郑袖）、破防暴击（孙坚）、用一摸多（诸葛亮 / 徐盛 / 李牧） |
| **官方平衡考量** | 怒限制只能当战法打出，防止成为第二个赵姬 |
| **讲者评价** | 非常阴间，轮椅武将，一个人也能赢 |
