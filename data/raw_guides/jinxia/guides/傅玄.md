# 《名将杀》傅玄武将解析

---


## 一、技能详解

### 技能一：元气上清（核心 · 定向硬牌 + 无限滚雪球）

**前半段——每回合获得元气（自增）：**
- 每个**自己回合开始时**获得 **1 点元气**
- 之后每个自己回合**获得的元气 +1**
- 注：默认是**自己的回合**（非他人回合）

**元气累计表：**

| 轮次 | 当轮获得元气 | 累计元气 | 可硬牌数（消耗 2 元气 = 1 张） |
|------|------------|---------|-------------------------------|
| 第 1 轮 | 1 | 1 | 0 |
| 第 2 轮 | 2 | 3 | 1 |
| 第 3 轮 | 3 | **6** | **3 张** |
| 第 4 轮 | 4 | **10** | **5 张** |
| … | … | 持续增长 | 越到后期越多 |

**后半段——消耗元气硬牌：**
- 出牌阶段可消耗 **2 点元气**
- 为**任意一名角色**添加**1 张你选择类型的牌**到手牌
- 类型三选一：**行动牌 / 装备牌 / 战法牌**

**本质 = 定向印牌技能**

**用途：**
| 用途 | 说明 |
|------|------|
| **自己打输出 / 防御** | 给自己印关键牌 |
| **辅助队友** | 给需要牌的队友源源不断补牌 |
| **后期爆发** | 越到后期印牌越多，强度越高 |

---

### 技能二：近朱者赤（战法累计触发 · 获取战法 + 元气）

**技能描述：**
- 当**一名其他角色**（不能是自己）在其回合内**累计打出 3 张战法牌**时：
  - 你可令一名与其**距离为 1 的其他角色**获得一张战法牌
  - 若目标角色是**你**，你获得2点元气

**★ 关键细节——"累计"二字：**
> 前面回合打出的战法可以**累计到后续回合触发**
>
> 例：第 1 回合只打 2 张战法 → 无法触发；第 2 回合又打 1 张战法 → 累计 3 张 → 可触发

**★ 关键细节——"与其距离唯一的角色"：**
> 名将杀中此描述**不包含自己**（需加"其他"两字）
>
> 即：只能选距离为 1 的**其他角色**，不可选自己

**2v2 应用逻辑：**
> 2v2 共 4 个位置，敌方 2 人总有 1 人挨着我方角色
>
> 敌方打战法越多 → 能为我方补战法越多 → 敌方无论怎么打都在为我方提供收益

**选择自己 vs 队友的两种收益：**
| 选择对象 | 收益 |
|----------|------|
| **队友** | 队友获得战法 → 输出能力增强 |
| **自己** | 自己获得战法 + **额外获得 2 点元气** |

> 选自己 = 补战法 + 补元气（双重收益）

**与一技能的联动：**
```
二技能（别人战法越多 → 我嫖战法 + 嫖元气）
    ↓
一技能（用元气印牌）
    ↓
形成完美联动闭环
```

---

### 技能三：政在去私（限定技 · 全场洗牌回堆顶）

**技能描述：**
- 傅玄可以选择**一种类型的牌**（行动 / 装备 / 战法）
- 将**场上的所有该类型牌**放回**牌堆顶**

**★ 两个关键词：**
| 关键词 | 含义 |
|--------|------|
| **场上** | 仅包含**角色区域**，不包含弃牌堆（不同于西门豹的"入报河伯"——后者可洗弃牌堆） |
| **放回牌堆顶** | 放到牌堆顶部面，**非洗乱**——放的牌越多，后续几回合摸到的牌越集中 |

**适用场景：**

| 搭配武将 | 战法类型 | 效果 |
|----------|----------|------|
| **孙尚香** | 装备 | 把场上所有装备放回牌堆顶 → 孙尚香可全部摸到手 |
| **赵奢（狭路相逢）** | 装备 / 战法 | 放回牌堆顶 → 狭路相逢直接有实战牌收益 |
| **诸葛亮** | 战法 | 战法放回牌堆顶 → 配合"舌战群儒"大摸牌 |

**★ 破防对手——洗走神装：**
> 对手装了很多装备 → 全部洗回牌堆顶 → 神装变成我方的

**★ 破防对手——强命暴击（配合转化杀武将）：**
> 把**所有行动牌**洗回牌堆顶 → 大家都没防御 → 我方摸到杀即为强命杀 → 配合**韩信、张飞、张梁**（能转化杀 / 添加杀） → 打出强命暴击

| 武将 | 可行性 | 说明 |
|------|--------|------|
| 韩信 | ✅ | 不缺杀，可转化 |
| 张飞 | ✅ | 不缺杀，可转化 |
| 张梁 | ✅ | 可把手上剩余牌转化为杀 |

**★ 后期时机建议：**
> 后期大家手上存的牌多以行动牌为主 → 想嫖装备 / 战法收益不多了 → **建议早点开大**

## 二、组合搭配

### 一、战法收益类

| 类型 | 说明 |
|------|------|
| **能打战法的武将** | 诸葛亮、陈平、张良等，战法越多，傅玄收益越高（二技能触发） |
| **陈宫** | 战法收益来自一技能——为陈宫补战法 → 陈宫转给傅玄 → 傅玄打出 → 陈宫触发额外摸牌 |
| **韩娥** | 特定标记"宫"的时候有收益 |

### 二、双倍发育类（保到后期）

**核心逻辑**：傅玄越到后期越强 → 需要保他活到后期

| 策略 | 武将举例 |
|------|----------|
| 保镖（保护傅玄） | 各种保命型武将 |
| 高嘲讽肉盾（吸引火力） | **章邯、卫子夫、吕蒙**——敌方优先打他们，傅玄存活 |

### 三、洗牌强命类

| 武将 | 效果 |
|------|------|
| 韩信 / 张飞 / 张梁 | 洗走行动牌 → 自己转化杀 → 强命暴击 |

### 四、装备收益类

| 武将 | 效果 |
|------|------|
| 孙尚香 | 洗装备回堆顶 → 装备收益 |

## 三、总结

| 维度 | 要点 |
|------|------|
| **定位** | 定向印牌滚雪球型武将，越到后期越强 |
| **一技能（元气上清）** | 每回合自增元气（第 N 轮获得 N 点）；消耗 2 元气为任意角色定向硬 1 张行动 / 装备 / 战法 |
| **二技能（近朱者赤）** | 其他角色累计打出 3 战法 → 距离为 1 的其他角色获 1 战法；选自己额外获 2 元气 |
| **三技能（政在去私，限定技）** | 选一种类型，将场上所有该类型牌放回牌堆顶（非洗乱）；可破防 / 强命 |
| **核心联动** | 二技能嫖战法 + 嫖元气 → 一技能用元气印牌 → 完美闭环 |
