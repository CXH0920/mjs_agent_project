# 《名将杀》蔺相如武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 3 技能**
- **讲者说明**：之前发过很多蔺相如的视频但都没玩明白，直到有评论交流后才**真正理解其玩法**；本期把这个真正玩法原封不动告诉大家
- **核心机制**：三个技能形成**闭环联动**——不仅和廉颇等赵国武将搭配，还能和**任意过牌量大 / 刷牌武将**形成强势联动

---

## 二、技能详解

### 技能一：完璧归赵（获得牌时增强 / 销毁 · 每回合限一次）

**技能描述：**
- 每回合限一次
- 当有角色**获得其他角色的牌**时：
  - 可令其选择**是否将这些牌增强并交给你**
  - 若其拒绝 → 你可**失去 1 点体力并销毁这些牌**

**发动条件细节：**
| 要点 | 说明 |
|------|------|
| **"获得"的角色未加"其他"** | 即**自己获得牌也会触发**此技能 |
| 自己获得牌 | 直接把它增强一遍（无需对方同意） |
| 其他角色获得其他角色牌 | 可触发两种情况 |

**两种触发场景：**
| 情况 | 说明 |
|------|------|
| **情况一** | 其他角色用调兵遣将 / 夺粮劫营等技能拿到牌（包括我们的牌）→ 发动令其交给你，否则销毁 |
| **情况二（更恶心）** | 敌方**相互刷牌**（如张骞、孙权、刘备等）→ 在递牌过程中 → 敌方完成后立刻发动 → 敌方拒绝 → 你失血销毁这些牌 |

**增强牌机制：**
> 每张牌都有一定增强效果（手牌界面可查看"增强"标识）；讲者之前发过手牌解读视频，可参考

---

### 技能二：渑池之会（交换手牌 + 强制流失体力 · 出牌阶段限一次）

**技能描述：**
- 出牌阶段限一次
- 选择**两名其他角色**
- 令其**依次交给对方一张牌**（双方各交 1 次，仅限一次）
- 否则你与其**各失去 1 点体力**

**骚操作（无手牌时）：**
> 如果敌方没有手牌 → 发动渑池之会 → 直接让他流失 1 点体力（他自己会跟着一起流失）

---

### 技能三：将相和（失去体力后换牌回血 · 每回合限一次）

**技能描述：**
- 每回合限一次
- 当你**失去体力后**（含"完璧归赵"的体力流失，也含其他原因）：
  - 可令另一名其他角色**交给你任意一张牌**
  - **你恢复等量体力**（给 1 张回 1 血、给 2 张回 2 血……）
- **队友给牌不是白给**：队友下个回合会**把给出去的牌补回来**（给几张下回合多摸几张）

**联动逻辑：**
> "完璧归赵"失去体力 → 找队友给牌 → 恢复体力 → 队友下回合补回手牌

**⚠️ 搭配铁律——队友必须是回合外能囤牌的武将：**
> 讲者直播时发现：选 6 血 3 手牌上限的角色 → 回合外只有 3 张牌 → 可能无法给蔺相如牌 → 将相和发动不了 → 技能联动断裂
>
> **必须选回合外能过牌 / 囤牌量大的角色**

---

## 三、★ 核心三技能闭环联动（讲者真正玩法）

```
① 出牌阶段发动渑池之会
    → 先选敌方、再选我方
    → 敌方交不交都无所谓（交了调牌 / 不交则双方各失 1 体力）
    ↓
② 到我方队友时 → 我方队友一定不交牌
    → 我方队友 + 蔺相如各失去 1 点体力
    ↓
③ 触发将相和 → 找队友给所有手牌
    → 把体力回复满
    → 下回合队友补回相应手牌
    ↓
④ 队友给牌这一过程触发"获得其他角色的牌"
    → 发动完璧归赵 → 把这牌全部增强并交给自己
    ↓
【三技能形成完美闭环】
```

**结果：**
> 蔺相如能够在手回合与**任意角色**联动起来，还能逮那些相互递牌的角色（逮住就赚，逮不住也能靠己方换牌 / 刷牌 / 强化手牌打出高爆发）

## 四、位置策略

| 位置 | 搭配 | 说明 |
|------|------|------|
| **2 号位**（推荐） | 3 号位囤牌队友 | 让 3 号位队友给牌 → 下个回合马上到 → 把给掉的牌补回来 → 二次爆发 |
| **4 号位** | 也可行 | 但 4 滴血角色坐 4 号位容易暴毙 |
| **1 号位** | 4 号位搭配卖血将 / 保核角色（如曹丕） | 4 号位没牌时不会暴毙 |

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 换牌强化型控制武将，三技能闭环联动，与任意大过牌武将可联动 |
| **一技能（完璧归赵）** | 获得牌时增强并拿过来；对方拒绝则失血销毁；可毁敌方相互递牌 |
| **二技能（渑池之会）** | 选 2 人依次交对方 1 张牌，否则双方各失 1 体力 |
| **三技能（将相和）** | 失血后找队友给任意牌 → 恢复等量体力 → 队友下回合补回手牌 |
| **核心闭环** | 渑池之会（选敌方 + 我方不交 → 双失血）→ 将相和（队友给牌回血）→ 完璧归赵（增强队友给的牌） |
| **搭配铁律** | 队友必须**回合外能囤牌 / 过牌量大**（尽量不选只有 3 手牌上限的低囤牌武将） |
| **位置推荐** | 2 号位（队友 3 号位）/ 4 号位 / 1 号位（4 号位配卖血将） |
| **讲者评价** | 之前一直玩不明白，现在发现真正玩法后——不仅能和廉颇等赵国武将搭配，还能和任意大过牌 / 刷牌武将强势联动 |
