# 《名将杀》如姬武将解析

---

## 一、武将背景与定位

- **版本情况**：属于讲者解读系列里**最早讲解的一批武将**，但随着版本更迭、新武将接连上线，有必要再做一期深度解析
- **核心机制**：**一技能"窃符救赵"对标扑克牌"炸金花"牌型**——发动时机为**出牌阶段开始时**

---

## 二、技能详解

### 技能一：窃符救赵（炸金花牌型 · 核心技能）

**发动时机：** 出牌阶段**开始时**

**效果流程：**
1. **查看一名其他角色的随机 3 张手牌**
2. **用自身手牌与其交换**
3. **最终凑出一组 3 张牌的组合**
4. **根据牌型触发对应效果**

---

**★ 牌型效果一览（收益随牌型优劣递增，可叠加）：**

| 牌型 | 条件 | 效果 |
|------|------|------|
| **同花顺** | 花色相同 + 点数连续 | 获得 1 枚**魏虎符**，可交给任意角色 |
| **同花** | 三张花色相同 | 获得 1 张**同花色**手牌 |
| **顺子** | 三张点数连续 | 获得 1 张**夺粮劫营** |
| **三张（三同点）** | 三张点数相同 | 摸 **3 张牌** |
| **对子** | 两张点数相同 | 摸 **2 张牌** |

**★ 魏虎符效果：**
- 提升 **1 点装备上限**
- **回合结束时把手牌补至上限**
- 与手牌上限极高的武将搭配效果极佳

**核心要点：**
| 要点 | 说明 |
|------|------|
| **牌型可叠加** | 例：同花顺必然满足同花 + 顺子要求 → **可获得三重收益** |
| **必须和其他角色交互手牌** | 联动队友 → 刷牌拿收益；针对敌方 → 偷取关键防御牌，掌控对方手牌节奏 |

---

### 技能二：衔环誓报（功能性挂件）

**效果：**
- 当有角色进入**重伤状态**时
- 如果该角色**曾经对你造成过伤害**：
  - 你可让**伤害来源**增加 **1 点体力上限**
  - 并**回复 1 点体力**

> 即：有人濒死时，如果他曾打伤过你 → 让打伤你的那个人抬 1 点体力上限 + 回 1 点血
>
> 讲者评价：相对平平无奇，偏向功能性挂件，**核心仍看一技能**

---

## 三、组合搭配（五大类）

### 第一类：交互手牌刷收益类

**原理：** 与队友交换手牌过程中，触发队友的过牌增益技能

| 武将 | 效果 |
|------|------|
| **信陵君** | 交互时给装备牌或魏虎符 → 触发技能 → 给敌方挂流血 |
| **刘邦 / 甘宁 / 甄宓** | 交换时给到武器 / 黑桃牌 → 稳定触发其技能 |
| **张骞** | 靠交换手牌叠凿空西域层数 |
| **吕不韦 / 夏侯惇** | 交换手牌时触发过牌刷牌效果 |

---

### 第二类：拦截陷害联动类

**原理：** 与**敌人**换牌，主打恶心对面

| 武将 | 效果 |
|------|------|
| **桑弘羊 / 蔺相如** | 当其他角色获得其他角色牌时可拦截 → 如姬与敌方换牌 → 他们趁机**嫖 1 张或销毁关键牌** |
| **郑袖** | 把带"掩袖工谗"标记的牌交给郑袖 → 如姬转手塞给对面 → 对面带标记进退两难 |
| **孟尝君** | 把打不出去的"狡兔三窟"牌丢给敌人 → 孟尝君回合原样收回 → 纯恶心人 |

---

### 第三类：囤牌大户配合类

**原理：** 如姬交换手牌很吃手牌量，队友手牌越多 → 越容易凑出好牌型

| 武将 | 效果 |
|------|------|
| **巴清 / 子婴 / 章邯** | 囤牌武将，保证有充足手牌交换 |
| **巴清 / 夏侯惇** 或者（专属牌武将） | 专属牌花色点数高度一致 → 很容易直接凑出**三张同点同花** → 稳定吃高收益 |

---

### 第四类：多出牌阶段爆发类

**原理：** 如姬一技能在**出牌阶段开始时**发动（类似司马相如、卓文君）→ 搭配额外增加出牌阶段的武将 → 一轮多次发动

| 武将 | 效果 |
|------|------|
| **萧何** | 额外出牌阶段 → 一技能多次发动 |
| **钟无艳** | 同上 |
| **太子丹** | 同上 |

> 窃符救赵直接打出**双倍甚至多倍收益**

---

### 第五类：高手牌上限补牌类

**原理：** 这类武将本身手牌上限就很高，拿到魏虎符后能**吃大量过牌收益**（相当于超大号"闭月"）

> 续航和爆发都很舒服

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 靠炸金花牌型吃收益的交互型武将，既联动队友刷牌，又针对敌方控手牌 |
| **一技能（窃符救赵）** | 出牌阶段开始时与一角色交换手牌 → 凑 3 张牌型 → 触发对应效果（牌型可叠加） |
| **二技能（衔环誓报）** | 敌方重伤且曾伤你 → 让伤害来源加 1 体力上限 + 回 1 血（功能性挂件） |
| **牌型最佳** | 同花顺 > 同花 = 顺子 > 三张 > 对子（牌型可叠加，同花顺三重收益） |
| **魏虎符** | 装备上限 +1 + 回合结束时补牌至上限 |
| **组合方向 1** | 交互手牌：信陵君 / 刘邦 / 甘宁 / 甄宓 / 张骞 / 吕不韦 / 夏侯惇 |
| **组合方向 2** | 拦截陷害：桑弘羊 / 蔺相如 / 郑袖 / 孟尝君 |
| **组合方向 3** | 囤牌大户：巴清 / 子婴 / 章邯  |
| **组合方向 4** | 多出牌阶段：萧何 / 钟无艳 / 太子丹 |
| **组合方向 5** | 高手牌上限补牌 |
| **模式推荐** | **巅峰赛全员速将局面下强度更为出类拔萃** |
| **讲者评价** | 好玩又有操作空间，平民娱乐 + 对局上分都合适；抽到皮肤别烂在仓库里 |
