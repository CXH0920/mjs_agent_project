# 《名将杀》羊祜（新版）武将解析

---

## 一、武将背景与定位

- **基调定位**：**新版羊祜与旧版完全不同**
  - 旧版：单出根本玩不了，必须配合特定组合配阵
  - **新版：不需要配阵，单出即可，属于"单出神将"**
- **讲者评价**：技能体系形成完美闭环，攻势打法非常强势，无需任何队友搭配也能独立运营
- **强度定位**：联盟赛若放出可直接使用，**多数情况有一战之力并能拖到后期获胜**；仅面对"双阴间五将"或阴间组合时略吃力

---

## 二、技能详解（讲者倒序解说）

### 技能三：潜谋远计（回合结束削弱敌方一张牌）

**技能描述：**
- **自己回合结束时**（非他人回合），选择一名其他角色
- 若你本回合**未打过一张装备牌**，则随机**削弱其一张牌**

**机制要点：**
- 削弱收益虽不及时也不明显，但是一种**恶心人的控制效果**
- 可能削弱敌方装备区牌（乌骓、绝影、的卢、飒露紫等马匹），导致其属性大幅减少
- **削弱桃**：无法在"重伤"时救人
- **削弱闪**：扛不住暴击伤害（多点伤害）
- 削弱牌的收益会**随局势后期愈发明显**

> ★ 核心需求：回合内**尽可能多打出装备牌** → 才能触发本技能削弱

---

### 技能二：德冠四海（展示点数拿装备）

**技能描述：**
- 出牌阶段限一次
- 令**所有角色展示两张牌**
- 若你展示的手牌**总点数最大**，随机**添加一张装备牌**到你的手牌

**与旧版区别：**
| 版本 | 操作 |
|------|------|
| 旧版 | 展示牌 → 换牌 |
| **新版** | **仅展示牌，无换牌操作** |

**使用要点：**
- 尽可能展示点数最大的牌（如展示 6/7、7/8、8/8）
- 前期需**刷大点数牌**
- 敌人若非囤牌型，羊祜可通过此技能让其"明牌"——使用战法或者配合队友扒光对方牌后对方点数不可能最大，**稳定获得装备牌**
- 注意**别让队友展示点数太大**，否则会抢走收益

---

### 技能一：轻裘缓带（核心技能，改阶段技能）

分为前后两段，是整个体系的枢纽：

**—— 前半段（准备阶段限一次）：**
- 收回自己装备区的牌
- **手牌上限 +1**

> 目前游戏中能收回装备区牌的武将，讲者印象只有吴国太和羊祜两人。

**收回装备牌的收益：**
- 刷 **盗骊、银狮盔、丈八蛇矛** 等装备的**二次收益**
- 手牌上限每次都会加 1，**越到后期越高**，形成发育滚雪球

> 收回后的下一步：重新打出装备 → 触发潜谋远计 → 增加削弱别人牌的次数

---

**—— 后半段（回合结束时）：**

| 条件 | 效果 |
|------|------|
| **装备区牌不是全场最多**（推荐路线） | 装备上限 +1，且**下个回合开始阶段改为摸牌阶段** |
| 装备区牌是全场最多（不推荐） | 下个回合摸牌阶段改为出牌阶段（无牌可摸，极差） |

**"相同最多不算最多" 关键规则：**
> 讲者在直播中向测画确认：**相同 = 不算最多**
> - 全场都不上装备 → 羊祜算全场**最少**（最理想）
> - 必须比别人多一张才算最多（别人 2 你 3、别人 3 你 4）
> - 所以只需保证自己**不是最多**即可，**建议不穿太多装备**

**后半段"开始阶段改为摸牌阶段"的核心好处：**
- 羊祜拥有**两个摸牌阶段** → 每回合摸 4 张牌
- 队友阵亡后摸 6 张
- 到了酣战阶段越摸越多
- 因为跳过了开始回合阶段，**永远不吃霜冻/久旱/地火/天雷**的卜卦效果

---

## 三、完美闭环与公式打法

三个技能形成完整自循环，**不需要任何队友**：

```
每回合摸五效果 = 多摸三张
┌─────────────────────────────────┐
│  两个摸牌阶段 = 摸 4 张          │
│  + 德冠四海再添加 1 张装备 = 5   │
└─────────────────────────────────┘
```

### 公式打法流程：

| 步骤 | 操作 | 目的 |
|------|------|------|
| **开局** | 刷装备牌 + 刷大点数牌 | 为削弱敌方和发动德冠四海做准备 |
| **出牌阶段** | 先打控制类 / 技能牌 | 清场、控场 |
| **德冠四海** | 展示点数最大的两张牌 → 点数最大 → 添加 1 张装备 | 获取装备 |
| **上装备** | 穿上装备 | 满足打出装备牌条件 |
| **轻裘缓带·前半段** | 收回装备 → 手牌上限 +1 | 增加手牌上限 + 刷装备二次收益 |
| **再上装备** | 重新穿装备（保证不是全场最多） | 保持装备数低于最高值 |
| **回合结束** | 装备不是最多 → 下回合双摸牌阶段 + 潜谋远计削弱敌方若干张牌 | 资源滚雪球 + 控制敌方 |
| **下一轮** | 双摸牌阶段，重复以上操作 | 持续滚雪球 |

## 四、组合搭配（讲者抛砖引玉）

新版羊祜自身发育能力极强，**无特定广泛适配组合**，随意搭配给牌武将即可。讲者推荐两个：

| 搭配武将 | 联动效果 |
|----------|----------|
| **王元姬** | 轻裘缓带、德冠四海均为"出牌阶段先一次"，配合王元姬可**让两个技能次数各 +1 甚至 +2** |
| **卢莫愁** | 定向印一个盗骊 → 轻裘缓带每回合都能刷盗骊 → 后期越刷越多 → **一回合刷 3 张盗骊 = 摸 6 张牌** |

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 单出神将，独立运营，无限滚雪球型 |
| **一技能（轻裘缓带）** | 收装备加手牌上限 + 改阶段（非最多→双摸牌阶段） |
| **二技能（德冠四海）** | 展示点数最大拿装备；旧版换牌 → 新版仅展示 |
| **三技能（潜谋远计）** | 未打装备则削弱敌方一张牌；打装备越多越能触发 |
| **核心机制** | 三技能完美闭环 → 每回合摸 5 张 + 手牌上限无限增长 |
| **关键规则** | "相同不算最多"——不穿装备时最安全，触发双摸牌阶段 |
| **最强打法** | 刷装备→德冠四海拿装备→轻裘缓带收装备+上限→再上装备→回合结束削弱→双摸牌循环 |
| **短板** | 面对双阴间五将 / 阴间组合略吃力 |
| **推荐场景** | 联盟赛可单出直接使用，适合拖后期获胜 |
| **讲者评价** | 技能攻势拉满，是改版后质变的强力武将 |
