# 《名将杀》张郃武将解析

---

## 一、武将背景与定位

- **基础属性**：**6 体力 / 3 手牌上限**，男性武将，3 个技能
- **讲者定性**：**不再是不动白 / 摸牌白**——既有卖血又有过牌 
- **核心机制**：军阵存牌 + 出牌阶段替换回手 + 巧变善战转化强命

---

## 二、技能详解

### 技能一：巧变善战（转化未选过的同类牌 · 出牌阶段各限一次）

**技能描述：**
- 出牌阶段各限一次
- 可将一张**行动牌或战法牌**当作本局游戏**未选择过的同类**未选择过的任意同类牌打出

**效果举例：**
| 转化 | 说明 |
|------|------|
| 杀 → 怒 | 可用 |
| 闪 → 桃 | 可用 |
| 天雷 → 多多益善 | 可用 |

**★ 关键限制——本局只限一次：**
> 一旦用杀转化成了怒 → **本局再无法用任何行动牌转化为怒**
>
> 一旦用天雷转化成了多多益善 → **本局再无法用战法牌转化为多多益善**（但可转其他战法牌）

**讲者建议：** **不要节省，每回合都用**——怕未来没命再来用

---

### 技能二：应势布阵（★ 非常强势的核心技能）

**前半段——存入军阵：**
- **受伤或回合结束时**，可摸一张牌，然后将**至少一张牌**放入军阵（可放多张）
- ⚠️ 若选择取消，系统**默认把你摸的那张放进去了**——不能钻这个空子
- **无法被其他角色响应的机制**：从军阵获得的牌，杀会强命、战法无法被识破

**★ 两种打法：**

| 打法 | 场景 | 操作 |
|------|------|------|
| **打法一：刷牌流** | 回合结束时 | 放多张装备（盗骊 / 丈八蛇矛 / 银狮盔等）→ 摸牌 → 反复取出装备 → 拿回军阵 → 多重收益循环 |
| **打法二：回合外爆发流** | 回合外受伤 | **多放几张进去**（存杀 / 怒等）→ 回合内替换出来 → 形成强命爆发 |

**★ 回合外受伤存牌策略：**
> **现在受伤就能放** → 回合外受 1 点伤害 → 把该放的牌全部放进去 → 待会儿替换做强命

**实战位置建议——坐 3 号位：**
> 坐 2 号位 → 1 号位会玩（不动张郃）→ 张郃第一回合爆发不了
>
> 坐 **3 号位** → 让 2 号位队友**主动打张郃一下** → 张郃受伤存牌 → 下回合即可爆发

**★ 敌方不敢打张郃：**
> 只要不动你张郃 → 张郃无法存牌 → 无法爆发 → 敌方的顾虑反而成了张郃爆发的前提

---

### 技能三：虓虎悍将（限定技 · 军阵空则摸牌）

**技能描述：**
- 限定技
- 军阵中**每有一张牌**时，你摸一张牌

**讲者建议——不要拖到后期才发动：**
> 张郃是摸牌阶段只能摸 2 张的摸牌白
>
> 2v2 是快节奏对局 → **早点拿出来早点爆发**

**发动时机建议：**
| 情况 | 建议 |
|------|------|
| 军阵中**约 5 张牌及以上** | 可以发动 |
| **3~4 张牌时** | 若绝境也可发动 |

---

## 三、公式打法

```
① 开局坐 3 号位
② 2 号位队友回合内主动打张郃一下
③ 张郃受伤 → 摸 1 张 → 把 5 张牌全部放入军阵
    （开局 4 张初始手牌 + 摸的 1 张 = 5 张）
④ 张郃回合开始 → 开限定技虓虎悍将 → 摸 5 张
⑤ 配合摸牌阶段 2 张 = 共 7 张牌
⑥ 从应势布阵中替换关键牌（强命杀、锦囊等）
⑦ 巧变善战打出怒 / 高质量战法牌 → 实现战局扭转
```

**若首回合打不过 → 拖一回合：**
> 下个回合虓虎悍将摸的牌约 **7~10 张** → 再来爆发

**进阶爆发（配合武器）：**
> 多张怒 + 开山斧 / 羽扇等加伤武器 + 强命 → **回合内打出 3~4 点血强命爆发**

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 卖血 + 过牌 + 军阵存牌爆发的滚雪球型武将 |
| **一技能（巧变善战）** | 出牌阶段各限一次，将行动牌 / 战法牌转为本局未选过的同类牌（每类本局只限一次） |
| **二技能（应势布阵）** | 受伤或回合结束时摸 1 张 + 至少 1 张入军阵；出牌阶段至少 1 张替换军阵中牌（强命 / 不可识破） |
| **三技能（虓虎悍将）** | 限定技，军阵有牌则摸牌（建议 5 张以上发动） |
| **核心打法** | 坐 3 号位 + 队友主动打你受伤 → 存牌 → 开限定摸 5 张 → 替换军阵爆发 |
| **位置铁律** | **坐 3 号位**，2 号位队友主动受伤触发存牌 |
| **两种玩法** | 刷牌流（装备反复取入军阵）+ 爆发流（存杀 / 怒 → 强命） |
| **巧变善战策略** | 不要节省，每回合都用最好收益的转化 |
| **讲者评价** | 加强后很强，值得游戏内体验；未来开发出更好玩法可能继续上调 |
