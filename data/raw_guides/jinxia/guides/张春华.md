# 《名将杀》张春华武将解析

---

## 一、武将背景与定位

- **身份**：曹魏女性武将，4 体力 / 2 技能
- **核心机制**：**封禁 + 流血 + 体力流失**三合一联动，机制独特且有针对性
- **强度评价**：
  - **2v2 模式**：强度不算顶尖
  - **巅峰赛 BP 模式**：**优先级很高**——很少被禁用，一旦对面出现频繁体力流失武将 → **双方必争**

---

## 二、技能详解

### 技能一：花落绝情（自残封禁 · 稀有封禁效果）

**技能描述：**
- 张春华对其他角色打出牌时，可**主动失去 1 点体力**
- 令目标进入**封禁状态**
- 若打出的牌能指定多名角色 → 可**同时封禁多人**
- **每回合限一次**，不局限于次生回合

**★ 全武将稀有的封禁效果：**
| 自带封禁来源 | 类型 |
|-------------|------|
| 马超 | 武将技能 |
| 卫青 | 武将技能 |
| **张春华** | 武将技能 |
| 轩辕剑 | 神器 |

**封禁效果：** 被封禁目标**本回合内无法使用和触发任何技能** → 对**卖血流武将**有天然压制

**★ 回合外可触发：**
> 回合外如果能对其他角色打出牌 → 同样能触发封禁

---

### 技能二：痛随伤逝（体力流失循环 · 完美兜底）

**技能描述：**
- **任意角色失去体力时**（无触发主体限制），张春华可令**另一名角色**：
  - **流血 +1**
  - 自己**摸一张牌**

**★ 循环收益链：**
```
张春华主动打出牌 → 自损 1 体力 → 触发一技能封禁敌方
    ↓
自身失去体力 → 触发二技能 → 敌方流血 +1 + 摸 1 牌
    ↓
流血叠加 → 敌方回合结束时失去体力 → 再次触发二技能
    ↓
循环收益（持续打真伤压制 + 摸牌过牌）
```

**"流血"负面状态说明：**
- 叠加后目标在**自己回合结束时失去 1 点体力**
- **流血层数可叠加**
- 流血造成的体力流失又能**再次触发二技能**

---

## 三、组合搭配（三大类）

### 第一类：主动体力流失武将

**原理：** 二技能无触发主体限制，只要**有角色失去体力**就能发动

| 武将 | 效果 |
|------|------|
| **扶苏** | 高频失去体力，排位中持续联动，强度爆表 |
| **侯嬴** | 高频失去体力 |
| **龙且** | 高频失去体力 |
| **庞煖** | 高频失去体力 |
| **秦舞阳** | 高频失去体力 |
| 苏秦 | 3 次或少次失去体力，单次触发也能盘活循环 |
| 凌统 | 同上 |
| 廉颇 | 同上 |
| 蔺相如 | 同上 |

> 后四将（苏秦 / 凌统 / 廉颇 / 蔺相如）**既配合张春华又被张春华克制** → 双向克制，**更适合巅峰赛 BP 环境**

---

### 第二类：蹭牌防御流

**原理：** 一技能自损体力，需搭配回血防崩盘 + 蹭牌扩大收益

| 武将 | 效果 |
|------|------|
| **张角 / 小乔** | 续航回血，避免自残过快崩盘 |
| **赵婕妤 / 小乔** | 随张春华摸牌蹭牌 |
| **步练师** | 张春华手牌往往很多 → 步练师让自己手牌小于张春华 → 不断摸牌 |
| **张仪** | 配合复制蹭牌效果 → 双人叠流血刷牌效率翻倍 |

---

### 第三类：回合外触发封禁

**原理：** 利用一技能回合外可触发特性，搭配能让张春华在**非自己回合内出牌**的武将 → 全程封禁

| 武将 | 效果 |
|------|------|
| 曹操 | 回合外出牌触发封禁 |
| 荀彧 | 同上 |
| 姜维 | 同上 |
| 孟尝君 | 同上 |
| 钟无艳 | 同上 |
| 韩娥 | 同上 |

**★ 最强绝配——陈宫：**
> 陈宫能让张春华**额外过牌**
>
> **冷知识**：陈宫在开局获得牌时，让张春华**直接使用牌** → 若敌方拥有登场技能 → **直接被张春华封禁**
>
> **效果**：一整局都无法再次触发登场效果，包括：
> - 左慈登场的"飞升太虚"
> - 大乔 / 小乔 / 虞姬登场的绑定队友技能
>
> **从开局就废掉敌方的关键机制**

---

## 四、巅峰赛 BP 策略

| 策略 | 说明 |
|------|------|
| **禁用优先级高** | 张春华很少被玩家禁用，但一旦被放出来就是大杀器 |
| **抢将思路** | 1 号位先抢张春华 → 再补出体力流失武将 → **BP 阶段直接压制对手阵容** |
| **关键对手** | 面对扶苏 / 侯嬴 / 龙且等频繁体力流失武将时必争 |

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 封禁 + 流血 + 体力流失循环型控制武将 |
| **一技能（花落绝情）** | 主动丢 1 血封禁目标本回合；每回合限一次，回合外可触发 |
| **二技能（痛随伤逝）** | 任意角色失去体力 → 令另一角色流血 +1 + 自己摸 1 牌 |
| **核心循环** | 自损 → 封禁 → 触发二技能 → 流血 → 再触发二技能 → 循环收益 |
| **搭配方向 1** | 主动体力流失武将：扶苏 / 侯嬴 / 龙且 / 庞煖 / 秦舞阳（高频）；苏秦 / 凌统 / 廉颇 / 蔺相如（双向克制） |
| **搭配方向 2** | 蹭牌防御：张角 / 小乔（回血）、赵婕妤（蹭牌）、步练师（无限摸）、张仪（翻倍） |
| **搭配方向 3** | 回合外封禁：曹操 / 荀彧 / 姜维 / 孟尝君 / 钟无艳 / 韩娥；**最强绝配陈宫**（封禁敌方登场技能） |
| **强度场景** | 巅峰赛 BP > 2v2；张春华较少被禁用 |
