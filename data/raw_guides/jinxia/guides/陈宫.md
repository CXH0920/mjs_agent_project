# 《名将杀》陈宫武将解析

---

## 一、武将背景与定位

- **基础属性**：**4 体力 / 5 手牌上限**
- **讲者定性**：**强度爆表**，是兼具"递牌刷牌 + 增伤 + 陷害"的**顶级辅助**
- **核心爽点**：给敌方叠多层印记后 → **一刀 999 秒杀**
- **讲者说明**：本期带来全网最详细的陈宫玩法攻略和最全搭配组合

---

## 二、技能详解

### 技能一：弃官投义（非摸牌阶段递牌 + 强制出牌）

**技能描述：**
- 陈宫在**非摸牌阶段获得牌**时，可将其中一张牌交给一名其他角色
- 令其**对你指定的另外一名角色打出此牌**
- 且**下个摸牌阶段摸牌数 +1**
- 若该角色**无法打出或选择不打出** → 你受到 **1 点伤害**


**★ 关键规则：**
> 游戏开局获得的**初始手牌也算非摸牌阶段获得牌**——与吕不韦、夏侯惇、甘宁、甄宓等开局可触发技能的武将机制一致

**使用策略：**
| 情况 | 效果 |
|------|------|
| 给队友能顺利打出的牌 | 队友多一次及时出牌收益 |
| 给队友无法打出的牌（如闪） | 陈宫掉血（可触发二技能） |
| **无论队友是否打出** | 陈宫都能叠加**摸牌数量**（下回合多摸） |

---

### 技能二：增伤标记（核心增伤 · 阴间所在）

**技能描述：**
- 陈宫只要**受伤**，就能令一名其他角色**下次受到的伤害 +1**
- 被标记目标**下次受伤时**，陈宫还能**获得一张战法牌**

**核心机制：**
| 要点 | 说明 |
|------|------|
| **用自身掉血换一次暴击机会** | 机制类似英雄杀猪八戒 |
| **获得战法牌** | 属非摸牌阶段得牌 → 又能触发一技能 → 给队友打二次输出 |
| **增伤 Debuff 永久生效** | 不会因陈宫阵亡而消失（目前游戏无净化类技能） → 一直存在直到目标受到增伤效果 |
| **队友灵活选择** | 打出牌拿及时收益；或故意不打出 → 让陈宫掉血 → 给敌方挂增伤 Debuff → **循环收益** |

> 增伤 Debuff **永久生效 + 不随陈宫阵亡消失**，是陈宫阴间的另一核心原因

---

## 三、组合搭配（三大类）

### 第一类：刷牌流组合

**原理：** 搭配能持续给牌的刷牌武将 → 反复触发一技能递牌

| 武将 | 效果 |
|------|------|
| 刘备 | 持续给牌 |
| 扶苏 | 持续给牌 |
| 吕不韦 | 持续给牌 |
| 芈八子 | 持续给牌 |
| 西门豹 | 持续给牌 |
| 卫子夫 | 持续给牌 |

**位置建议：**
> 组合最好在 **2、3 号位**，让 3 号位陈宫能及时吃到额外摸牌收益

**★ 顶配组合——卢莫愁 + 陈宫：**
| 位置 | 武将 |
|------|------|
| 1 号位 | 卢莫愁 |
| 4 号位 | 陈宫 |

**联动流程：**
```
开局陈宫刷出夺粮劫营 / 破阵卸甲
    ↓
交给卢莫愁打出
    ↓
触发卢莫愁阳春白雪 → 牌回到陈宫手中
    ↓
卢莫愁为陈宫印牌
    ↓
印出的牌再次递给卢莫愁打出
    ↓
开局即可把对手扒光 + 增伤效果一波带走
```

---

### 第二类：增伤暴击组合（一刀 999）

**原理：** 以二技能为核心 → 队友稳定误伤陈宫 → 挂增伤 → 配合高爆发武将实现一刀 999

| 支配武将 | 效果 |
|----------|------|
| 吕布 | 强命杀 + 弹射 |
| 袁绍 | 战法误伤 |
| 赵奢 | 技能误伤 |
| 庞统 | 战法误伤 |
| 张宝 | 弃牌触发伤害 |
| 孙尚香 | 装备循环 + 误伤 |

**★ 最强组合——吕布 + 陈宫：**
| 位置 | 武将 |
|------|------|
| 1 号位 | 吕布 |
| 4 号位 | 陈宫 |

**联动流程：**
```
开局陈宫给吕布递战法牌
    ↓
吕布转化为杀攻击 2 号位
    ↓
技能弹射到陈宫 → 陈宫受伤
    ↓
陈宫给敌方挂增伤 Debuff
    ↓
吕布回合内对 2 号位再次出强命杀
    ↓
陈宫触发一技能摸战法牌 → 继续递牌
    ↓
【1 号位吕布即可直接秒杀对面】
```

**其他组合：**

| 组合 | 联动效果 |
|------|----------|
| 袁绍 / 赵奢 / 庞统 | 稳定误伤陈宫 → 轻松给敌方挂增伤标记 |
| **张宝 + 陈宫** | 陈宫开局递牌 → 张宝选择不打出 → 挂增伤 → 张宝开技能打伤害 → **两次增伤 + 开局打出无血暴击** |
| **孙尚香 + 陈宫** | 孙尚香给陈宫递装备牌 → 选择不打出 → 陈宫掉血挂 Debuff + 孙尚香继续刷装备滚收益 |

---

### 第三类：小型永动机阴间组合——步练师 + 陈宫

| 步骤 | 效果 |
|------|------|
| 步练师主动让陈宫掉血 | 触发自身技能 → 给陈宫递牌 + 摸装备 |
| 陈宫先后递回 | 步练师选 1 张打出 + 1 张不打出 |
| 陈宫继续掉血 | 持续触发步练师的共牌 |
| 结算完毕 | 给敌方多人叠满增伤标记 |
| 最终 | 一个连环属性伤害即可**团灭对面** |

> 属于小型永动机阴间组合

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 递牌刷牌 + 增伤陷害的顶级辅助，单出也有强度 |
| **一技能（弃官投义）** | 非摸牌阶段获牌时递牌 → 令目标对另一角色打出；不出则陈宫掉 1 血；下回合多摸 |
| **二技能（增伤标记）** | 陈宫受伤 → 令他人下次受伤害 +1；被标记者下次受伤时陈宫获 1 战法牌（再触发一技能） |
| **阴间核心** | 增伤 Debuff **永久生效 + 不随陈宫阵亡消失** |
| **核心玩法** | 队友误伤陈宫挂增伤 → 支配武将打高爆输出 → 一刀 999 |
| **刷牌组合** | 刘备 / 扶苏 / 吕不韦 / 芈八子 / 西门豹 / 卫子夫（最佳 2、3 号位） |
| **顶配组合** | 卢莫愁 + 陈宫（开局拔光 + 增伤带走） |
| **最强增伤组合** | 吕布 + 陈宫（1 号位秒杀对面） |
| **阴间小组合** | 步练师 + 陈宫（连环属性伤害团灭） |
| **讲者评价** | 陈宫强度爆表；叠多层印记后一刀秒杀爽感拉满 |
