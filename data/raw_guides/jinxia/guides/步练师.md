# 《名将杀》步练师武将解析

---

## 一、武将背景与定位

- **身份**：本期讲解武将，**4 体力 / 3 技能**
- **讲者定性**：**辅助能力非常强的辅助武将**，评价非常高；这两天遇到都拿出来玩
- **核心机制**：通过一技能给受伤队友补装备 → 二技能在回合外不断摸牌 → 三技能亡语爆发，三技能形成联动闭环

---

## 二、技能详解

### 技能一：仁惠抚下（队友受伤时补装备 · 核心辅助）

**技能描述：**
- 当**一名其他角色受到伤害**时：
  - 可以**交给其**1张牌
  - 令其**获得并装备一张装备牌**（从牌堆中随机获得）
- 若其装备区已满 → 需弃置一张装备牌
- **必须将这张装备装备上去**

**⚠️ 关键限制：不能对自己使用，只能对队友使用**

> 讲者观点：不能因此否定这个技能——辅助武将的技能本就不必面面俱到

**由此衍生的两个搭配思路：**

| 思路 | 搭配武将 | 逻辑 |
|------|----------|------|
| **思路一：选辅助保步练师** | 蒙恬蒙毅（把杀转到队友身上）、季布（强行让队友掉血触发技能） | 防止步练师被集火 |
| **思路二：选高爆发武将让敌方不敢打队友** | 赵姬 / 陆逊 / 燕昭王 / 廉颇（脆皮或需发育武将） | 敌方不敢打队友 → 转而打步练师 → 反而给队友提供发育空间 |

> 打步练师组合的优先解法是**先打步练师**——反而给队友腾出空间

---

### 技能二：宠冠后庭（回合外持续摸牌 · 续航核心）

**技能描述：**
- **每个角色的回合结束时**（不只是自己回合）
- 若你的**手牌数不是全场最多** → 摸一张牌

**关键细节：**
| 要点 | 说明 |
|------|------|
| 触发时机 | **每个角色的回合结束** |
| 判定条件 | 手牌数**不是全场最多**——若并列最多则算最多，无法触发 |
| 举例 | 全场最多 5 张，步练师和另一角色都是 5 张 → **步练师算全场最多，无法摸牌** |

**★ 实战策略：**
> 回合内**尽可能多打牌**，把手牌数量压到不是全场最多 → 回合外不断摸牌

**搭配建议：**
> 搭配**手牌上限高的武将** → 队友手牌上限高 → 你只要比队友牌少就能触发

**★ 讲者粉丝提到的妙哉组合——步练师 + 小乔：**
> 小乔手牌上限本来就高
> - 步练师摸 1 张 → 小乔也摸 1 张
> - 小乔手牌数量永远高于步练师
> - 步练师永远触发宠冠后庭
> - **小乔的桃花还能帮步练师补血**
>
> **双向互补，越到后面越强**

---

### 技能三：追册中宫（亡语 · 爆装备）

**技能描述：**
- 亡语：阵亡时，可将**所有手牌**交给一名其他角色
- 然后令其**获得并装备装备牌，直到达到装备上限**

**关键规则：**
| 规则 | 说明 |
|------|------|
| **只能交出手牌** | 不包含其他区域的牌 |
| **手牌为 0 则无法发动** | 阵亡时没有手牌 = 无法发动亡语 |

**收益放大搭配：**

| 武将 | 效果 |
|------|------|
| **田单** | 自带额外装备上限 → 可多拿装备 |
| **孙尚香** | 自带额外装备上限 |
| **孙坚** | 自带额外装备上限 |
| 其他武将 | 最多拿 3 张装备牌，也不错 |

---

## 三、三技能联动闭环

```
回合内多打牌（压低手牌数量）
    ↓
二技能宠冠后庭 → 回合外不断摸牌
    ↓
队友受伤 → 一技能仁惠抚下 → 给队友装备 + 自己弃牌（保持手牌少）
    ↓
若被集火阵亡 → 三技能追册中宫 → 把所有手牌 + 装备给队友
    ↓
【三技能联动闭环】
```

---

## 四、实战演示

### 第一局——步练师 + 赵姬

| 步骤 | 操作 |
|------|------|
| 步练师坐 3 号位保 2 号位赵姬 | 赵姬扛压 |
| 敌方苏秦打残赵姬 | 触发一技能 |
| 赵姬闪掉强化火杀 | 步练师给装备（触发赵姬绝好杀 → 武器换牌） |
| 赵姬回合开始时受强化火伤 | 掉 1 血 → 步练师再给 1 张牌 |
| 联动 | 赵姬和步练师两个技能联动起来 |

### 第二局——步练师 + 田单（配小乔对面）

| 步骤 | 操作 |
|------|------|
| 位次问题 | 1、4 号位不理想（2、3 号位更好）；步练师必须坐前置位 |
| 开局 | 把能打出去的牌全部打出 → 不留手牌 → 回合外不断摸牌 |
| 徐晃打到田单烧 1 张牌 | 步练师发动技能 → 给田单补装备 + 补牌 |
| 火牛阵 | 4 刀火牛阵强命 → 田单装备上限打到 4 |
| 若阵亡 | 亡语技把 4 张手牌交给田单 → 田单直接补 4 张装备 |

---

## 五、位次策略

| 位置 | 建议 | 说明 |
|------|------|------|
| **1 号位** | ✅ 推荐 | 前置位保证回合外手牌数量不是全场最多，可摸牌 |
| 4 号位 | ❌ 不推荐 | 后置位会"饿死"——无法在回合外摸到足够牌 |
| 2、3 号位 | ✅ 最佳 | 与田单等武将搭配时更优 |

---

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 高评价辅助武将，靠补装备 + 回合外摸牌 + 亡语爆装备的三技能联动 |
| **一技能（仁惠抚下）** | 队友受伤时给 1 张装备（从牌堆随机，必须装备）；不可对自己用 |
| **二技能（宠冠后庭）** | 每个角色回合结束时，手牌非全场最多则摸 1 张；回合内多打牌触发 |
| **三技能（追册中宫）** | 亡语：交出手牌给队友 → 队友装备到上限（需手牌 > 0 才能发动） |
| **核心联动** | 回合内多打牌 → 回合外摸牌 → 队友受伤给装备 → 自己弃牌保持少牌 |
| **最佳搭配** | 小乔（手牌上限高 + 桃花补血，双向互补）、田单 / 孙尚香 / 孙坚（亡语装备上限）；蒙恬蒙毅（保步练师） |
| **位次建议** | 前置位（1、2、3 号位），不坐 4 号位 |
| **讲者评价** | 辅助能力强，评价高；搭配思路清晰，值得多玩 |
