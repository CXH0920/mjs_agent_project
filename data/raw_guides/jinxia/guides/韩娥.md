# 《名将杀》韩娥武将解析

---

## 一、武将背景与定位

- **身份**：战国时期韩国女性武将（**普通武将**，不稀有）
- **基础属性**：**4 体力 / 4 手牌上限**
- **讲者定性**：**"万金油"辅助**——是讲者盘点武将组合以来**搭配最多的一个**；强联动武将尚且这么多，若算上小联动则几乎能与**所有武将**打出不错的配合
- **核心机制**：通过一技能给全场挂**余音**Buff，通过二技能将余音**永久继承**至游戏结束

---

## 二、技能详解

### 技能一：千古留音（余音赋予 / 切换 · 核心技能）

**触发条件（两类）：**
| 触发类型 | 说明 |
|----------|------|
| **登场** | 游戏开局触发 1 次 |
| **体力值变化** | 受伤或回复体力均可触发 |

**技能效果：**
- 让一名**未获得余音**的角色获得一种余音
- 或让一名**已获得余音**的角色**切换**为另一种余音

**★ 完全体——全场挂满余音：**
> 需要至少 **3 次体力变化 + 1 次登场 = 4 次触发**，才能给全场 4 名角色挂上余音

**五种余音类型一览：**

| 余音 | 属性 | 核心效果 |
|------|------|----------|
| **宫调** | 正面 | 战法牌添加 |
| **商调** | **负面** | 伤害后弃牌 |
| **角调** | 正面 | 非摸牌阶段获牌时添战法牌 |
| **徵调** | 正面 | 出牌阶段开始时立即出杀 |
| **羽调** | **负面** | 弃牌后体力流失 |

> 策略：**正面 Buff 优先给己方**，**负面 Buff 丢给敌方**

---

### ★ 核心组合——让韩娥早日挂满余音

**原理：** 让韩娥拥有稳定的回复能力或误伤效果，频繁触发体力变化

| 武将 | 效果 |
|------|------|
| 郑袖 | 稳定回血 / 受伤触发 |
| 赵婕妤 | 稳定回血 / 受伤触发 |
| 扶苏 | 稳定回血 / 受伤触发 |
| 华佗 | 稳定回血 / 受伤触发 |
| 张角 | 稳定回血 / 受伤触发 |
| 蔺相如 | 稳定回血 / 受伤触发 |

**开局实操思路：**
```
登场 → 直接给自己挂宫调余音（触发 1）
    ↓
立刻失去 1 点体力 → 触发 2
    ↓
配合回血武将回复 → 触发 3
    ↓
首回合即可挂出 3 个余音 → 快速成型完全体
```

**★ 邪修打法：**
> 配合**张仪** → 让张仪刻写一个技能 → 两人一起快速给对面挂余音

---

### 五种余音详解 + 组合搭配

---

#### 1. 宫调余音（战法牌添加 · 正面）

**效果：** 获得时 或 每个回合**首次打出战法牌时**，随机**添加一张战法牌**到手牌

**★ 回合外额外触发的武将（4 位）：**

| 武将 | 触发方式 |
|------|----------|
| **甄宓** | 频繁打石破 |
| **张良** | 队友打出行动牌时摸战法牌并立即打出 |
| **贾诩** | 回合外打战法牌 |
| **范增** | 回合外打战法牌 |

**其他强联动：**
| 武将 | 联动效果 |
|------|----------|
| **诸葛亮** | 配合舌战群儒刷战法牌 |
| **黄月英** | 战法牌生效两次 |
| **孟尝君** | 韩娥打出顺手牵羊额外多摸战法牌 |

**★ 经典组合——袁绍 + 韩娥：**
> 袁绍坐 **1 号位**，韩娥坐 **4 号位**
>
> 韩娥开局给袁绍挂宫调 → 袁绍先白嫖 1 张战法 → 打出战法再摸 1 张战法 → 袁绍战法误伤韩娥 → 韩娥掉血 → 反过来给对面挂余音 → 阵亡让袁绍获得**双重余音**
>
> **双向联动直接拉板**

---

#### 2. 商调余音（伤害后弃牌 · 负面）

**效果：** 获得时 或 每个回合**首次造成伤害后**，随机**弃置一张牌**

**讲者评价：** 暂时没有特别舒服的搭配；随机弃一张牌不够稳定，回合外很难造成伤害触发频率低

**存在的真正意义（与羽调配合）：**
| 用途 | 说明 |
|------|------|
| 来回切换 | 对方已有羽调时反复切换商调 ↔ 羽调，蹭体力流失 |
| 二技能双 Debuff | 直接把商调 + 羽调两个负面 Buff 挂给敌方一人 → 造成伤害 = 弃牌 + 体力流失，双重折磨 |

---

#### 3. 角调余音（非摸牌阶段获牌添战法牌 · 正面 · ★组合最多）

**效果：** 获得时 或 每个回合**非摸牌阶段首次获得牌后**，随机**添加一张战法牌**到手牌

**讲者评价：** 盘点下来**组合搭配最多的一个余音**；名将杀装备牌收益极高（盗骊、丈八蛇矛等），角调是**泛用式天花板**

**典型组合：**

| 武将 | 联动效果 |
|------|----------|
| **孙权** | 乘马射虎回合外频繁过牌 → 过 1 张触发角调摸装备 → 装备等会直接用或置换 → 续航超强 |
| **孙坚** | 自己回合内额外过牌 → 上装备后弃装备打伤害获 1 装备牌 → 触发角调再摸 1 张装备 → **无限给自己堆装备**，爆发拉满 |

> **所有能额外过牌的角色**都能和韩娥角调搭配（只多过 1 张的忽略不计，盘点的都是每轮至少多过 2~3 张的武将）

---

#### 4. 徵调余音（立即出杀 · 正面）

**效果：** 获得时 或 **出牌阶段开始时**，可以立即打出一张杀（**不消耗出杀次数**）
> ⚠️ 有**距离限制**，非无限距离

**适配武将（不缺杀、靠杀打收益的菜刀）：**

| 武将 | 效果 |
|------|------|
| **关羽**（最强联动） | 每张牌都能当杀；坐 1 号位 → 登场时 1 刀 + 出牌阶段开始时 1 刀 + 出牌阶段内 1 刀 = **稳定 3 刀** |
| 赵云 | 多打一轮输出 |
| 吕布 | 多打一轮输出 |
| 钟无艳 | 多打一轮输出 |
| 白起 | 多打一轮输出 |

**★ 封禁登场技能：**
> 韩娥 1 号位 + 马超 / 卫青 → 开局封禁敌方登场技能，简单粗暴

---

#### 5. 羽调余音（弃牌后体力流失 · 负面）

**效果：** 获得时 或 每个回合**首次弃牌后**，**失去 1 点体力**

**核心联动——张春华：**
> 只要角色体力流失 → 张春华过 1 张牌 + 挂 1 层流血 → 完美联动，滚雪球

**弃牌触发羽调的武将：**
| 武将 | 效果 |
|------|------|
| 甘宁 | 逼对面弃牌触发羽调掉血 |
| 大乔 | 同上 |
| 高渐离 | 同上 |
| 卓文君 | 同上 |
| 鲁仲连 | 同上 |
| **张宝**（重点） | 强行弃牌触发掉血 |

**★ 张宝组合（非常离谱）：**
> 韩娥登场直接给对面核心挂羽调 → 先白嫖 1 点体力流失 → 张宝强行弃他的牌 → 继续触发掉血 → 手牌弃空 → 触发张宝的 36 方 → **一套打对面 4 点血**
>
> 若自己留 1 张雷杀 → 轻松打出 **5 点伤害**

---

### 技能二：余音绕梁（亡语 · 余音永久继承）

**技能描述：**
- 阵亡后，另一名其他角色**获得你的余音**
- **保留当前所有余音效果**，直到**游戏结束**

**两种打法：**

| 打法 | 操作 | 效果 |
|------|------|------|
| **正常打法** | 死前把所有余音调成正面 Buff → 转移给队友 | 队友**白嫖双重余音** |
| **脏套路** | 死前把余音切换成商调 / 羽调 → 甩给对面核心 | 敌方**自带双 Debuff 打到结束**，恶心程度拉满 |

**玩法定调：**
> 韩娥**进可攻、退可守**——挂完余音后直接献祭，哪怕死掉也无伤大雅，余音效果一直保留到游戏结束

---

## 三、进阶冷知识——回合内切换余音

**触发条件：**
> 韩娥活到全场挂满余音 + 继续触发体力变化 → 可在**回合内**切换余音

**收益示例：**
```
队友已触发角调（非摸牌阶段摸装备）
    ↓
韩娥触发体力变化 → 切换为宫调
    ↓
队友获得宫调"获得时"效果 → 白嫖 1 张战法
    ↓
打出战法 → 触发宫调"回合内首次打出战法" → 再摸 1 张战法
    ↓
一个回合内吃满两种余音效果
```

**多次切换：**
> 若能频繁触发体力变化 → 多次切换 → **双倍 / 多倍余音效果**，收益极高

**★ 切换同类余音也能触发：**
> 给对面挂羽调 → 切换成羽调 → 再次触发体力流失 → 相当于韩娥掉 1 血 → 对面立刻流失 1 体力

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 万金油辅助，通过余音 Buff 体系控场 + 增益 |
| **一技能（千古留音）** | 登场 / 体力变化时给他人赋予或切换余音；完全体 = 全场挂满 |
| **二技能（余音绕梁）** | 亡语：余音转移给另一角色，保留效果至游戏结束 |
| **五种余音** | 宫（战法）/ 商（弃牌·负面）/ 角（战法·泛用天花板）/ 徵（杀）/ 羽（体力流失·负面） |
| **核心逻辑** | 频繁触发体力变化 → 早日挂满 → 正面给己方 / 负面给敌方 |
| **回血启动组合** | 郑袖 / 赵婕妤 / 扶苏 / 华佗 / 张角 / 蔺相如 |
| **最强余音组合** | 宫调→袁绍 / 角调→孙权 / 孙坚（泛用）/ 徵调→关羽 / 羽调→张春华 + 张宝 |
| **脏套路** | 二技能死前挂双 Debuff 给敌方核心 |
| **进阶技巧** | 回合内切换余音吃双倍效果 |
| **讲者评价** | 当之无愧的万金油辅助，普通武将但强度出色，看到韩娥直接选即可 |
