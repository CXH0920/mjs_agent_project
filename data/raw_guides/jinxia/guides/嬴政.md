# 《名将杀》嬴政武将解析

---

## 一、武将背景与定位

- **身份**：新赛季战令武将（男性），战国末期秦国之君
- **讲者评价**：**强度非常高，值得拿下**；属于赛季必得武将

---

## 二、技能详解

### 技能一：一统六合（改势力 / 感染型核心技能）

**技能描述：**
- 与**你势力相同**的角色造成伤害后：
  - 可将受伤角色的势力**改为与你相同**
  - 或**移除其势力**（改为无势力）
- 当全场**首次仅存在一种势力**时：
  - 嬴政**回复全部体力**
  - 接下来**本局游戏中**，你每个回合开始时，**随机获得每个无势力角色一张牌**

**核心机制——势力感染：**

| 目标 | 效果 |
|------|------|
| 敌方 | 将其势力改为我方（感染）或移除为无势力 |
| 我方队友 | 同样可改势力，确保势力统一 |

**联动玩法：**
- **最优搭配**：配合能"改势力"的武将（如与嬴政同势力的武将），让所有伤害都不浪费
- 若场上无同势力武将 → 嬴政先对队友造成伤害，改其势力，再进行感染扩散
- 场上只剩一种势力（大概率为我方势力）→ 触发全满血回复 + 每回合拿无势力角色牌的被动

**模式对比：**

| 模式 | 表现 |
|------|------|
| **2v2** | 更容易达成"全场同势力"，优势明显 |
| **军八** | 收益也较高，各有优势 |

**★ 关键限制规则：**

> **嬴政无法对"无势力"角色再次改变势力**
>
> 即使已触发回复体力 / 拿牌的后续效果，对无势力角色造成伤害时：
> - 系统会提示"改为我方 / 改为无势力"
> - 但**无法将无势力角色改为有势力**
>
> 此外：**所有与势力变动相关的技能都无法选择、也无法生效于被移除势力的角色**

**被废掉的技能：**
> 张仪、平原君等能改变势力的技能，因嬴政移除势力后对方变为"不可选"，**实际已被废掉**

---

### 技能二：秦弩齐射（八牌开杀 · 额外输出）

**技能描述：**
- 出牌阶段限一次
- **翻开牌堆顶 8 张牌**
- 为其中**每张杀**，选择一名**不同的其他角色**作为目标
- **依次对目标打出**
- 剩余的牌可选择：
  - 按原顺序放回牌堆顶
  - 弃置

**核心收益：**
- 提供回合内**额外多刀机会**
- 每次出杀都能触发**当前装备效果**（装备对嬴政至关重要）
- 以装备乌骓为例：每次出杀触发乌骓 → 刷多张牌

**剩余牌的处理策略（控下家）：**

| 情况 | 策略 |
|------|------|
| 下家是对手，剩余牌为好牌 | **弃掉**，不让对手摸到 |
| 下家是队友，剩余牌为好牌 | **放回牌堆顶** |
| 下家卜卦区有牌（天雷 / 霜冻/久旱/地火），剩余牌可判死 / 判中 | 放回牌堆顶，控局势 |
| 下家卜卦区有牌，需赌判中 | 弃掉，看后续 8 张是否有好牌 |

**★ 关键机制——乌骓触发时机：**
> 翻开 8 张牌时，乌骓触发的摸牌**不是**这 8 张中剩下的牌，而是**第 9 张牌**（因为翻开的牌尚未放回牌堆顶）
>
> 结算顺序：先打完所有杀 → 结算乌骓摸第 9 张 → **然后**才决定剩余牌放回还是弃置

---

### 技能三：万里长城（控顶断闪 · 保命护队）

**技能描述：**
- **每轮开始时**，对自己翻开牌堆顶 8 张牌
- 将其中**所有闪**自动放入"万里长城"（特殊区域，不可选择）
- 剩余牌可选择放回牌堆顶或弃置
- 每回合限一次，与你**势力相同**的角色需要打出闪时：
  - 你可以**代替其从万里长城中打出闪**

**"对你翻开"的含义：**
> 这 8 张牌**只有嬴政自己能看**，其他角色看不到（与越异技能中的描述一致）

**核心收益：**
- 为同势力队友提供**替代出闪**的保护能力
- 每轮自动从牌堆**抽走所有闪** → 破坏下家闪资源

**剩余牌处理策略（与二技能同理）：**

| 情况 | 策略 |
|------|------|
| 一号位自己吃到霜冻等，牌堆顶非解牌 | 弃掉，赌后续出现解牌 |
| 一号位是对手，剩余为好牌 | 弃掉，不让摸到 |
| 一号位是队友 | 放回牌堆顶 |

**★ 双重控顶效果——断杀断闪：**

> - 二技能（秦弩齐射）消耗牌堆顶的**杀**
> - 三技能（万里长城）消耗牌堆顶的**闪**
>
> 若两种牌都消耗后原封不动放回牌堆顶 → 场上角色**大概率断杀或断闪**
>
> **对菜刀武将的降维打击**：
> - 当嬴政下家是**靠杀输出**的菜刀武将
> - 通过二技能把杀用光 → 菜刀下家**永远摸不到杀**
> - 只要运营得当 → 下家永远断杀

**针对不同武将的策略调整：**
> 若对手是通过"战法牌"打收益的武将（如宋玉等），策略需相应灵活调整

## 三、技能联动精髓

| 联动路径 | 效果 |
|----------|------|
| 一技能改势力 → 队友与我同势力 → 三技能替其出闪 | 团队保命 + 护队 |
| 一技能移除敌方势力 → 触发全满血回复 + 每回合拿无势力牌 | 满血复活 + 无限摸牌 |
| 二技能消耗杀 + 三技能消耗闪 → 下家断资源 | 控顶断杀 / 断闪，降维打击 |
| 二 / 三技能剩余牌策略性放回或弃置 → 控下家牌序 | 控局势、判死 / 判中 |

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 赛季战令武将，势力感染 + 控顶断资源 + 护队多面手 |
| **属性优势** | 体力 + 手牌上限和 = 10，突破常规上限 |
| **一技能（一统六合）** | 感染 / 移除敌方势力；同势力时回复全血 + 每回合拿无势力角色牌 |
| **二技能（秦弩齐射）** | 翻 8 牌出杀多刀；控下家牌序；装备乌骓可刷牌 |
| **三技能（万里长城）** | 每轮抽走闪保护队友；控顶断杀 / 断闪；降维打击菜刀武将 |
| **核心机制** | 控顶（杀 + 闪同时抽走）→ 断资源；势力感染 → 触发被动收益 |
| **推荐搭配** | 2v2（易达成同势力）或军八（收益高） |
| **克制关系** | 对菜刀武将、张仪 / 平原君等改势力武将产生强力克制 |
| **注意事项** | 无法对无势力角色再次改势力；二 / 三技能剩余牌需根据下家灵活处理 |
| **强度评价** | 非常高，赛季必拿，值得冲战令 |
