# 《名将杀》白起武将解析

---

## 一、武将背景与定位

- **基础属性**：**3 手牌上限 / 6 体力上限**——身板硬、技能离谱

---

## 二、技能详解

### 技能一：料敌合变（残血收割 · 无缝补刀）

**技能描述：**
- 当其他角色**失去最后的手牌**后：
  - 你可**立即对其打出一张杀**

**触发条件：**
- ✅ 对手自己用完牌
- ✅ 被我们拆光牌

> 两种情况都可无缝衔接补刀，是**稳定额外输出手段 + 残血收割机**，**专治各种把手牌打空的脆皮角色**

**★ 典型克制对象：**
| 武将 | 特点 |
|------|------|
| **赵姬** | 爱一口气把牌刷光 |
| **张骞** | 爱一口气把牌刷光 |
| **孙权** | 爱一口气把牌刷光 |

> 在白起面前**简直就是活靶子**，克制效果拉满

---

### 技能二：出奇无穷（无损硬牌 · 续航拉满）

**技能描述：**
- 每个回合限用一次
- 当你在**回合外需要打出牌**时，可把**任意一张手牌当作要打出的牌**打出
- 用完之后**额外获得一张杀**

**核心效果：**
| 需求 | 效果 |
|------|------|
| 要闪 | 有闪 |
| 要桃 | 有桃 |
| 额外 | 用完**不亏牌**，回 1 张杀 |

> **回合外无损印牌神技**——既保证回合外发动一技能时**随时有杀可用**，又给超强回合外防御能力

---

### 技能三：歼灭（拆牌控场 · 核心兜底）

**技能描述：**
- 只要**出杀**或**造成杀伤害**：
  - 可**销毁一名其他角色任意区域内的一张牌**
  - 装备、手牌、被挂区**均可**
  - **想销哪张销哪张**
- **任何出杀时机都能触发**

**讲者最爱用法：**
> 出杀之后**立即销毁对面核心装备** → 对手瞬间没输出、没防御 → **直接废掉一半**

---

## 三、三技能联动闭环

```
敌方把手牌打空
    ↓
一技能（料敌合变）→ 立即补刀 1 杀
    ↓
三技能（歼灭）→ 出杀后销毁牌 / 命中再销毁牌
    ↓
敌方留 1~2 张保命 → 白起杀过去 → 销牌 → 命中再销牌
    ↓
敌方手牌再次一空 → 一技能补刀跟上
    ↓
【无解输出闭环】
```

> 三个技能联动效果直接翻倍——敌方**敢把手牌打空就被追着砍，留牌保命就被销毁牌 + 补刀**

---

## 四、总结

| 维度 | 要点 |
|------|------|
| **一技能（料敌合变）** | 对手失去最后手牌 → 立即补刀 1 杀（残血收割 + 额外输出） |
| **二技能（出奇无穷）** | 回合外任意牌当所需牌打出 + 额外回 1 杀（无损印牌神技） |
| **三技能（歼灭）** | 出杀 / 造成杀伤害 → 销毁对手任意区域 1 张牌（装备 / 手牌 / 卜卦区） |
| **核心闭环** | 打空手牌 → 补刀 → 拆牌 → 再打空 → 再补刀（无解循环） |
| **克制对象** | 所有爱一口气刷光牌的角色：赵姬、张骞、孙权等 |
| **讲者最爱打法** | 出杀后立即拆对面核心装备 → 直接废掉对手一半 |
| **讲者评价** | 全世界最爽的六边形战士，强度拉满，建议没入手的赶紧冲一波体验杀神白起的爽局 |
