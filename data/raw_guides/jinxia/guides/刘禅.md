

# 《名将杀》刘禅武将解析 + 组合搭配盘点

---

## 一、武将定位

刘禅是一名**纯辅助型武将**，上线后引发讨论。核心特点：**自身几乎无输出能力，但组合搭配极为丰富**。讲者将其比作"萧何的下位替代"，并认为凭借丰富的联动，出场率和胜率都不会垫底。

> 讲者观点：名将杀很多武将单挑都不强，辅助武将没有单挑能力很正常，关键是看组合搭配的数量和质量。

---

## 二、技能详解

### 技能二：乐不思蜀（负面限制）

**限制效果：**
- 牌**无法选择其他角色为目标**且**生效两次**
- 一般无法打出任何**输出牌**和**控制牌**
- 无法对队友用**桃**

**特例（几乎无输出的唯一例外）：**
- 刘禅配合**韩娥**：韩娥阵亡给对面挂了两层"羽"标记后，刘禅用技能让对面弃牌时可以打掉对面**两滴血**（触发羽标记流血）

**唯一"对自己生效两次"的牌：**
| 牌 | 效果 |
|----|------|
| **桃** | 一口回 2 滴血 |
| **多多益善** | 多摸牌辅助队友 |
| **盗骊** | 多摸牌 |
| **丈八蛇矛** | 多摸牌 |

> 刘禅自身几乎没有任何输出和控制能力，价值全部体现在辅助队友和陷害对手。

### 技能一：素丝守成（核心技能）

**技能描述：** 出牌阶段限 4 次，可以将自己的牌拿给队友打出。
- 队友打出此牌过程中获得的任意牌 → **交给刘禅**
- 若队友无法打出 → **随机弃去一张牌**
- **无论谁打出刘禅的牌，都无法选择刘禅为目标**

**第一层效果：辅助队友（攻击向）**

让队友用刘禅的牌获得额外收益：

| 队友类型 | 代表武将 | 联动效果 |
|----------|----------|----------|
| 出杀有额外收益 | 钟无艳、赵云 | 多打杀额外收益 |
| 杀有额外增伤 | 祝融夫人、李信 | 配合多刀的杀打出暴击伤害 |
| 出牌有收益 | 孙尚香、宋玉、孟姚 | 打出牌多摸牌（摸到的牌归刘禅） |

- **宋玉**特例：打出刘禅的牌且未被响应，可以弃掉对面每人一张牌，收益很高
- 刘禅只要摸到杀，就能盘活菜刀将

**关键结算细节：**
> 队友用刘禅的牌**自己**获得的所有牌都要交给刘禅，包括武将技能摸牌。
> - 赵云用刘禅的杀出了摸的那张牌给刘禅 ✓
> - 队友用刘禅的夺粮劫营偷了一张牌 → 也要还给刘禅 ✓
> - **但**：队友用刘禅的牌打了对面的郭嘉，郭嘉掉血摸的牌 **不算**给队友（没到队友手上），所以不交

**第二层效果：陷害对手（控制向）**

当刘禅手里都是打不出去的牌时，可以直接发动技能让对手**弃牌**：
- 对手无法打出 → 随机弃一张牌
- **刘禅零牌时也能发动**，不需要留一张牌在手
- 发动 4 次 = 扒光对面 4 张牌

**骚操作：卡距离**
> 例：刘禅坐1号位，2号位和3号位是敌方。刘禅只剩杀或距离1的牌，让2号位去用。
> - 由于无法以刘禅为目标，2号位只能对自己队友出杀，或被随机弃牌
> - **两种结果对刘禅都是正面收益**
> - 即：不只是"打不出牌时"才能对对面用，**卡距离**也能形成陷害

## 三、组合搭配（三大类）

### 第一类：出牌有收益的菜刀/武将要

| 武将 | 联动 |
|------|------|
| 张辽、赵云 | 菜刀将，多出杀 |
| 司马相如 | 出牌收益 |
| 宋玉 | 打出牌弃对面各一张 |
| 孙尚香、孟姚 | 出装备/战牌多摸 |
| **赵奢** | 特殊：刘禅不能对他人出杀，若赵奢对刘禅开狭路相逢翻到杀也打不出去，直接弃掉，**变相增强坦度**，避免赵奢翻多张杀被队友强杀的尴尬 |

### 第二类：陷害弃牌型

| 武将 | 联动 |
|------|------|
| **孙权** | 把能打的牌交给孙权，让对面弃大量牌 |
| **张辽** | 同上 |
| **韩娥** | 给对面挂羽标记 → 用2技能让对面弃牌 → 主动触发羽标记流血 |
| **大乔** | 刘禅对某角色用技能让其弃牌，"他弃一张，大乔弃一张"交替进行，运气好可扒光两人 |

### 第三类：双倍效果型

| 武将 | 联动 |
|------|------|
| **张仪**、**平阳公主** | 可刻写/复制"素丝守成"，把能打的牌全打出，再对对面发动弃牌，两人同时让对面弃牌 → 扒光 |
| **卢莫愁** | 用牌不被响应可将牌再交回刘禅，刘禅让她再用一次 → **双倍用牌** |
| **黄月英** | 用牌获得双倍收益，配合刘禅的技能打夺粮劫营、破阵卸甲等牌达成双倍效果 |

---

## 四、核心打法总结

| 维度 | 要点 |
|------|------|
| **定位** | 纯辅助，自身几乎无输出 |
| **技能一（素丝守成）** | 给队友出牌获额外收益 + 让对手弃牌 |
| **技能二（乐不思蜀）** | 限制自身不能出输出/控制牌，桃可回2血 |
| **核心优势** | 组合搭配极为丰富，可攻可守 |
| **攻势** | 配合菜刀暴击、配合出牌收益武将 |
| **守势** | 让对面弃牌削弱防御，变相保护队友和自己 |
| **评价** | 组合多的武将出场率高，胜率不会垫底 |
