# 《名将杀》太子丹武将解析

---

## 一、武将背景与定位

- **讲者说明**：本期**重点讲结算详情 + 组合盘点**
- **联动规模**：讲者盘点出**近 20 多个武将可联动**
- **核心定位**：**万金油辅助武将**——单出尴尬，但搭配合适组合强度非常高

---

## 二、技能详解

### 技能一：恣卿所欲（空手牌触发补牌）

**技能描述：**
- 当有角色**失去最后一张手牌**时：
  - 你可以**失去 1 点体力**，令其**摸 2 张牌**

**关键规则：**
| 规则 | 说明 |
|------|------|
| 可对自己生效 | 回合内 / 回合外均可发动 |
| 一回合可多次使用 | 只要满足条件 |
| **一次性失去多张手牌** | **也属于"失去最后一张手牌"**（经测试确认） |

---

### 技能二：易水促行（弃牌阶段改出牌阶段）

**技能描述：**
- 每个角色**出牌阶段结束时**
- 若你在当前回合内**失去过体力**：
  - 可将当前回合角色的**弃牌阶段改为出牌阶段**
- 当其在此阶段造成伤害时 → **你回复 1 点体力**

---

**★ 结算细节（破除误区）：**
> ❌ **不能"左脚蹬右脚直接上天"**——技能发动后弃牌阶段改为出牌阶段 → 结束进入**回合结束阶段** → 不会有新的弃牌阶段 → 无法再次发动易水促行

**阶段流程：**
```
出牌阶段结束
    ↓
易水促行 → 弃牌阶段改为出牌阶段
    ↓
新出牌阶段
    ↓
回合结束（无弃牌阶段，技能无法再次发动）
```

**★ 多次回血机制：**
> 新出牌阶段中，该角色造成**多次伤害** → 太子丹可**多次回血**

**★ 核心联动闭环（一二技能）：**
```
队友回合内多次把手牌打空
    ↓
一技能恣卿所欲 → 补牌（太子丹失血）
    ↓
二技能易水促行 → 弃牌阶段改出牌阶段
    ↓
队友在新出牌阶段多次造成伤害
    ↓
二技能后半段 → 太子丹多次回血
    ↓
失的血回满，形成循环
```

**★ 重要提醒：**
> 不要把**原本的出牌阶段**里把伤害牌全部打光 → 导致易水促行给的新出牌阶段无牌可出 → 技能白用

## 三、组合搭配（近 20 将盘点）

|------|----------|
| **孙权** | 把牌弃置的瞬间可触发 |

| **刘备** | 给牌给空 |
| **郑袖** | 给牌给空 |
| **芈八子**（加强后） | "权御四贵"出牌阶段无次数限制 → 反复发动 → 反复触发太子丹 |

| **夏侯惇** | 给牌给空 |
| **郭嘉** | 给牌给空 |
| **陆逊** | 自己打牌打空 |
| **高渐离** | 把牌弃置的瞬间可触发 |
| **韩信** | 主动打空 |

## 四、总结

| 维度 | 要点 |
|------|------|
| **定位** | 万金油辅助，靠空手牌触发补牌 + 弃牌阶段改出牌阶段 + 多次回血循环 |
| **一技能（恣卿所欲）** | 角色失去最后一张手牌 → 你失 1 血令其摸 2 张（可对自己；一回合多次；一次性多张也算） |
| **二技能（易水促行）** | 出牌阶段结束时若你失血 → 弃牌阶段改出牌阶段；该角色在新出牌阶段造成伤害时你回血 |
| **核心闭环** | 队友打空 → 补牌（失血）→ 改出牌阶段 → 新出牌阶段多次伤害 → 多次回血 |
| **阶段误区** | 新出牌阶段结束后进入回合结束 → 无弃牌阶段 → 不能再次发动（不能上天） |
| **注意事项** | 别把原出牌阶段伤害牌打光 → 新出牌阶段无牌可出 |
| **联动规模** | 近 20 多个武将可联动 |
| **强力联动** | 芈八子（加强后无限制反复触发）、甘宁 / 孙权（弃牌瞬间）、黄盖（限定技 + 苦肉计）、张角（太平道给自己） |
| **主动流失体力类与燕国势力** | 蔺相如 / 高渐离 / 郭隗 / 乐毅 / 燕昭王 / 荆轲 / 秦舞阳 |
| **讲者评价** | 单出尴尬，组合联动强度不低；万金油辅助，特定组合可打出 1+1>2 效果 |
