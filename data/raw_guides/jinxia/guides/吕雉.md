# 《名将杀》吕雉武将解析

---

## 一、武将背景与定位

- **讲者定性**：**非常简单，但需要理解花色体系**；核心是"给队友摸牌 / 给敌方销牌"
- **核心机制**：通过一技能按花色全局增益 / 破坏 + 二技能平分所有被销毁的牌

---

## 二、技能详解

### 技能一：临朝称制（按花色摸牌 / 销牌 · 核心技能）

**技能描述：**
- **每个角色回合开始时**，你可以选择**一个花色**
- 令所有角色在打出**此花色的牌**后：
  - **摸一张牌**，或
  - **随机销毁一张牌**
- 摸牌 / 销毁需要在一步之内完成

**"销毁"机制：**
> 销毁 = 以销毁方式将卡牌**移除游戏**——在没其他技能影响下，**该牌永久不会再回来**
>
> 例：敌方一张开山斧被销毁 → 本局永久消失（除非有技能能复制 / 召回）

**★ 五种花色与阴阳属性体系（讲者详细总结）：**

| 花色 | 属性 | 阴阳 | 主要牌型 |
|------|------|------|----------|
| **红桃** | 火 | 阳 | 火杀、烈火焚城、烽火狼烟、地火、凤羽盔、玄武盾、羽扇、八卦盾、龙舌弓（**伤害为主**） |
| **梅花** | 木 | 阳 | 桃、酒（怒）、马匹（赤兔除外全梅花）、多多益善、休养生息、先拔头筹、天雷、久旱（**回复 / 增益 / 马匹为主**） |
| **黑桃** | 水 | 阴 | 闪（最多）、识破、无懈可击、夺粮劫营、破阵卸甲、霜冻、云锦袍（**闪 / 控制为主**） |
| **方片** | 金 | 阴 | 武器牌（除羽扇、龙舌弓外全方片）、雷杀、普通杀、箭雨齐射、阵前对决、调兵遣将、连环等（**武器 / 雷电伤害为主**） |
| **土** | 土 | — | **仅 2 张**（易） |

**阴阳属性底层逻辑：**
| 场景 | 所需属性 |
|------|----------|
| **霜冻** | 判出**阳属性**（红桃 / 梅花）才能解开 |
| **久旱** | 判出**阴属性**（黑桃 / 方片）才能解开 |

---

### ★ 一技能选择策略（讲者详细总结）

**给队友 → 摸牌：**
> 队友 / 自己哪种花色牌越多 → 就选那种花色摸牌

**给敌方 → 销牌（由于不知道敌方手牌，需根据状态判断）：**

| 敌方状态 | 销哪种花色 | 理由 |
|----------|-----------|------|
| 依赖梅花（回复 / 增益） | **梅花** | 削其回复 / 增益 |
| 依赖装备 | **方片** | 削其武器牌 |
| 一般情况 | **红桃** | 红桃伤害牌最多，削其输出 |
| 被霜冻 / 状态不好 | **梅花** | 对方无法打出输出牌 |
| **黑桃** | ❌ 一般不削 | 黑桃以闪 / 识破为主，对方回合内打不出；反而可能削掉自己的闪 |

> **一句话总结：削回复削增益 → 削梅花；削输出 → 削红桃或方片；尽可能不削黑桃**（除非已看到敌方手牌有夺粮劫营 / 霜冻）

**土花色：**
> 基本不会去选土，除非队友是**张良**——张良觉醒后摸到的专属战法牌全是土属性（如太公六韬）→ 此时用土为其摸牌增益

---

### 技能二：诸吕为王（限定技 · 平分销毁牌）

**技能描述：**
- 限定技
- 选择至少 **3 名角色**（不足则全部），令其**随机平分本局游戏所有被销毁的牌**

**触发范围：**
> 包括**吕雉自己**用临朝称制销毁的牌 + 其他技能销毁的牌

**★ 其他会销毁牌的技能（例子）：**
| 来源 | 说明 |
|------|------|
| **符水**（张角） | 打出后销毁 |
| **狐鸣**（陈胜） | 打出后销毁 |
| **桃花**（小乔） | 打出后销毁 |

**模式对比：**

| 模式 | 效果 |
|------|------|
| **2v2** | 必选到 1 名敌方 → 可能资敌；但牌局短，可能来不及发动 |
| **军八** | 队友有 3 个 → 可让队友全部分平 → **收益更高** |

## 三、★ 实战组合——吕雉 + 韩非（讲者实战演示）

**核心联动：**
> 吕雉临朝称制每发动一次（回合内 / 回合外都算）→ 韩非的**法不阿贵**触发 → 吕雉摸牌
>
> 实战中吕雉发动了 **14 次**临朝称制 → **韩非直接让摸 14 张牌**

**实战流程要点：**

| 步骤 | 操作 |
|------|------|
| 开局 | 销**方片**（武器牌多）→ 敌方项羽装武器 → 被销 1 张 |
| 后续 | 敌方再装武器 → 又销 1 张 |
| 韩非回合 | 红桃杀最多 → 用 1 摸 1（杀→摸→杀）→ 全是红桃杀 |
| 张角血量见底 | 削**梅花**（削桃、多多益善等打不出的牌）→ 削 3 张 |
| 项羽用轩辕剑 | 销**红桃**（削其输出）；顺便顺走方片武器 |
| 韩非最终 | 法不阿贵触发 **14 次** → 摸 14 张牌 → **轻松拿下** |

**组合优势：**
> ①我方哪个花色多摸哪个
> ②敌方大概率会摸到什么花色 → 我们去销他的主花色

## 四、其他冷门骚操作

| 组合 | 效果 |
|------|------|
| **吕雉 + 陈胜** | 让敌方去拿狐鸣 → 敌方摸到狐鸣 → 全部牌交给陈胜 |
| **吕雉 + 小乔** | 打到一半残血时 → 诸吕为王把小乔所有桃花分回来 → 配合临朝称制打出梅花多摸 1 张 → **大恢复 + 大爆发** |

---

## 五、总结

| 维度 | 要点 |
|------|------|
| **定位** | 按花色全局增益 / 破坏型武将，靠消耗敌方关键牌型 + 限定平分 |
| **一技能（临朝称制）** | 每角色回合开始时选一花色 → 打出该花色摸 1 张 或 随机销 1 张 |
| **二技能（诸吕为王）** | 限定技，选 3 名角色随机平分本局所有被销毁的牌 |
| **核心策略** | 队友花色多 → 摸牌；敌方销牌按状态选花色（削回复削梅花、削输出削红桃 / 方片、不削黑桃） |
| **花色体系** | 红桃=火=阳（伤害）、梅花=木=阳（回复增益）、黑桃=水=阴（闪控制）、方片=金=阴（武器雷电）、土=仅 2 张 |
| **最强搭配** | **韩非**（法不阿贵无限摸牌，实战摸 14 张）；陈胜、小乔（骚操作） |
| **模式推荐** | 军八 > 2v2（军八收益更高，2v2 牌局短可能来不及发动） |
| **讲者评价** | 机制简单但需要理解花色体系；掌握花色后上手即用，值得体验 |
