

# 《名将杀》王元姬武将解析

---

## 一、武将背景与定位

- **身份**：新赛季战令武将，3 个技能
- **讲者定性**：**绝非"低板弱将"**——在辅助队友情况下，强度**甚至比测试版本更强**
- **关键论断**：
  > 王元姬"配阵强 + 配阵多" → 看到就能选，选出来就很强
  >
  > 不像尉缭等武将配阵少导致弱
  >
  > **预测会成为和赵奢一样的"信息差武将"——很强很强**
- **讲者态度**：希望玩家辨证看待其强度；可先体验，若确实强则请为它正名，不要再诋毁

---

## 二、技能详解

### 一技能：烛奸抑势（获取牌 + 限制出牌阶段限一次技能）

**技能描述：**
- 回合开始时：
  - 获得一名其他角色的**一张牌**
- 当其**发动出牌阶段限一次的技能**后：
  - 可获得其**两张牌**，直到你的下个回合开始

**⚠️ 当前实战 ：**
> 理论上应为"可选择获得或不获得"，但目前实战中似乎是**必须获得**

**本质 = 限制一切出牌阶段限一次的技能**

**收益计算：**

| 情况 | 收益 |
|------|------|
| 限制对面 + 对面发动技能 | 偷 1 张 + 再偷 2 张 = **拉 3 牌差 + 6 收益** |
| 对面选择不发动技能 | 变成白板（收益仍高，类似改限定技） |
| 没逮到对面发动 | 相当于**不限距离、不可被识破的夺粮劫营**，稳定偷 1 张 |

**关键机制——交牌由王元姬选择：**
> 敌方发动技能时需交牌，**由王元姬选择**（而非敌方）：
>
> - 可选关键装备
> - 手牌为随机（对方无法专门交烂牌）
>
> 敌方手牌会**急剧变少** → 变相封锁技能

**两种打法方向：**
| 打法 | 目标 |
|------|------|
| 限制对面 | 偷牌 + 封锁技能 |
| 配合队友 | 偷队友牌触发"谦冲接下" → 减少队友弃牌 |

**对比测试版本：**
- **提高下限**：即使对面没有出牌阶段限一次技能，仍有稳定偷牌 + 联动队友的收益
- **理论上下限略降**：看似不能直接废掉技能
- **实际上限不降反升**：对面发动技能就要交牌 → 牌越来越少 → 根本不敢发动 → **比改限定技还恶心**
- 若对面技能组有**多个出牌阶段限一次技能** → 比旧版还强

---

### 二技能：谦冲接下

**技能描述：**
- 每个回合限一次
- 当你获得其他角色的牌时：
  - 可令其与描述中"出牌阶段限一次"的技能，在**下个出牌阶段发动次数 +1**

**联动机制分析：**
- 王元姬"躬执纺绩"本身有"出牌阶段限一次"效果，队友也能拥有 → 即使队友无额外此类技能也能联动
- 增加次数**每回合限一次** → 正常情况队友发动"躬执纺绩" → 2 次
- 但"烛奸抑势"也是"获得其他角色的牌" → 选择队友 → **额外增加 1 次**
- **最终一轮队友可发动 3 次出牌阶段限一次的技能**

> 与很多武将联动起来是**毁灭打击**

---

### 三技能：躬执纺绩（核心技能）

**技能描述：**
- 出牌阶段限一次
- 获得一张**行动牌**（从牌堆里摸牌堆顶最上面那张行动牌）
- 可**将此牌交给一名其他角色**，或**另一名未拥有此技能的其他角色获得此技能**


**为何能延伸出全部收益：**
| 收益 | 来源 |
|------|------|
| **确保"烛奸抑势"稳定发动** | 获得行动牌 → 满足"行动牌最多"条件 |
| **让"谦冲接下"发动次数 +1** | 出牌阶段限一次本身触发"谦冲接下" |
| **让队友也拥有出牌阶段限一次技能** | 把技能交给未拥有的队友 |

**二三技能联动：**
- 王元姬 + 队友各发动两次 → **白嫖 4 张行动牌**
- 加一技能（额外给牌机会）→ 可多次发动

**⚠️ 副作用：**
> 摸的是**行动牌**（杀 / 闪 / 桃），可能把杀闪桃摸光 → **菜刀断杀**；敌方反而可能摸到更多战法和装备（但影响有限）

## 三、克制 / 联动武将清单


### "烛奸抑势"克制（限制出牌阶段限一次）
覆盖**近乎一半**的武将技能，含**大将军武将杜预的技能**

### "谦冲接下"联动（增加发动次数）
大部分出牌阶段限一次的技能都可联动 → 既克制又联动

### 不可联动 / 意义不大的技能（标绿）
| 原因 | 举例 |
|------|------|
| 性别限制 | 孙尚香——王元姬是女性角色，无法发动"刀剑情缘" |
| 技能描述限制 | 其他角色出牌阶段限一次 → 无法吃到额外收益 |
| 增加次数意义不大 | 一般技能不建议配合 |

### 给牌武将清单（回合外给王元姬牌）
| 武将 | 作用 |
|------|------|
| 吕奉先等 | 回合外额外给牌 → 让王元姬多触发一次"谦冲接下" + "躬执纺绩" → 出牌阶段限一次技能**次数 +2** |
| 孙权 | 自身原本就有出牌阶段限一次技能 |
| 其他（文档列出） | "躬执纺绩"交给队友后，队友也拥有此类技能 → 每人发动 3 次 → 一共嫖 6 张 |

## 四、特殊高联动组合

| 组合 | 效果 |
|------|------|
| **王元姬 + 韩非** | 每次给韩非一个额外出牌阶段限一次的"躬执纺绩" → 韩非用完刷掉 → 韩非变成**技能怪** |
| **王元姬 + 赵奢** | 首回合赵奢开 2 次侠入相防；赵奢回合内再给牌 → 开 3 次 → **翻 30 张牌**；每开一次王元姬拿 2 张牌 → 赵奢多牌交给王元姬 → 不用弃牌 |

---

## 五、公式打法

| 位置 | 主打方向 | 打法 |
|------|----------|------|
| **1 号位** | **控制** | 开局首回合"躬执纺绩"摸行动牌并交队友 → "烛奸抑势"限制敌方出牌阶段限一次技能（敢发动就偷 2 张，收益 4） |
| **2 号位** | **辅助** | "躬执纺绩"交队友 → "烛奸抑势"绑队友（赵奢、陆逊等五项爆发将）增加技能次数 |
| **3 号位** | **控制**（需给牌队友） | 搭配一个给王元姬牌的队友（如吕不韦等），提前触发"谦冲接下"增加次数 → 自己回合发动 2 次"躬执纺绩"，给技能 + 限制敌方 |
| **4 号位** | **不建议** | 太容易暴毙 |

> ⚠️ 二、三号位都有可能被敌方压手牌（敌方看到王元姬必优先针对）——**不要纠结二三号位谁更好**，看阵容灵活选择

---

## 六、总结

| 维度 | 要点 |
|------|------|
| **定位** | 辅助 + 控制双修，限制出牌阶段限一次技能 + 增加队友技能次数 |
| **烛奸抑势** | 回合开始时偷 1 张；目标发动出牌阶段限一次技能再偷 2 张；由你选牌 |
| **谦冲接下** | 获得他人牌且手牌非全场最低 → 目标出牌阶段限一次技能次数 +1（每回合限一次） |
| **躬执纺绩** | 出牌阶段限一次摸行动牌 → 交人 或 让队友获得此技能 |
| **核心联动** | 二三技能联动 + "烛奸抑势"辅助 = 队友一轮发动 3 次；"躬执纺绩"交队友让全队共享 |
| **克制对象** | 游戏内近乎一半的出牌阶段限一次技能 |
| **位置建议** | 前置位（1 控制 / 2 辅助 / 3 控制+辅助），不坐 4 |
| **特殊组合** | 韩非（技能怪）、赵奢（翻 30 张牌） |
| **讲者评价** | 配阵多 + 配阵强 = 强将；信息差武将，会像赵奢一样很强；战令 38 可入手 |
