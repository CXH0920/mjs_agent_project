# 《名将杀》孟尝君 + 黄月英 细节三部曲（四曲）

---

## 一、武将背景与定位

- **武将配对**：**孟尝君** + **黄月英**
- **定位**：双武将冷门细节技巧分享——利用双方技能联动，打出**隐藏的爆发操作**
- **讲者态度**：这些操作都是**打了这么多局才测试出来的**，建议大家去游戏里好好体验

---

## 二、孟尝君 & 黄月英 技能基础

| 武将 | 关键能力 |
|------|----------|
| **孟尝君** | 让其他角色**主动将一张牌当作顺手牵羊打出**；成为其他角色牌的目标时，可让**有兔牌标记（狡兔三窟提供）的角色**代替自己成为目标；回合开始时可拿走带兔牌标记的装备 |
| **黄月英** | 战法牌可以**生效两次**（双倍效果）；每回合可以**复制一张手牌或场上装备牌**；包括**AOE 战法** |

> **联动核心：** 孟尝君提供"兔牌"标记 → 黄月英的翻倍和复制 → 双方互换形成收益循环。

---

## 三、★ 孟黄细节三部曲（第四曲为后续补充）

### 第一曲：双倍顺手牵羊

| 机制 | 说明 |
|------|------|
| 黄月英 | 战法牌可以生效两次 |
| 孟尝君 | 可以让黄月英主动将一张牌**当作顺手牵羊打出** |
| 联动效果 | 在孟尝君回合，让黄月英直接用一张牌**顺对面两张牌** → **用一偷二** |
| 评价 | **最表面最简单的组合思路**，多数玩家已知 |

---

### 第二曲：双倍兔牌

| 机制 | 说明 |
|------|------|
| 黄月英复制装备 | 复制一张装备牌（或手牌） |
| 兔牌标记传递 | 如果这张装备牌**本来属于孟尝君**，黄月英复制出来的牌也会带有**兔牌标记** |
| 孟尝君回收 | 装备装上后，孟尝君可以在回合开始时**拿走带兔牌的装备** |
| ★ 关键装备 | **盗骊、银狮盔、丈八蛇矛**等可重复利用的装备牌 |
| **具体操作流程** | ① 孟尝君给黄月英一张"盗骊"（带兔牌标记）② 黄月英装上盗骊 → 摸两张牌 ③ 黄月英复制这张盗骊 → 再摸两张牌 ④ 回合结束时孟尝君收回去（两张带兔牌的盗骊） → **每回合凭空多刷两张牌，收益逐渐递增** |
| 评价 | **隐藏思路**，大多数玩家不了解 |

---

### 第三曲：双倍转移目标

| 机制 | 说明 |
|------|------|
| 孟尝君转移 | 孟尝君成为其他角色牌的目标时，可以让**有兔牌标记的角色**代替自己成为目标 |
| 黄月英战法双倍 | 黄月英的战法牌（AOE 战法）**双倍生效**，包括**烽火狼烟、箭雨齐射**等 |
| **具体操作流程** | ① 孟尝君先给对面一张带兔牌的牌 ② 黄月英打出 AOE 战法（如烽火狼烟）→ 双倍生效 ③ 孟尝君把目标转移到对面（有兔牌标记的角色） → **对面承受四次该群锦囊的伤害** |
| 评价 | **隐藏思路**，连讲者也是打很多局才测试出来 |

---

## 四、★ 第四曲：无限强化霜冻，卡死对面（粉丝补充）

| 来源 | 讲者做视频后，粉丝分享的另一个组合 |
|------|------|
| **前置条件** | 孟尝君需要有一张**霜冻**（一种卡牌） |
| **操作流程** | ① 孟尝君将霜冻递给黄月英 ② 黄月英替孟尝君成为一次牌的目标 → 霜冻被**强化**（变成强化版霜冻） ③ 黄月英每回合复制一张手牌 → **永远手上保存一张强化版霜冻** ④ 每回合只需打出一张强化版霜冻出去，另一张留在手上复制 → **永远卡死对面**——一个人永远出不了牌，只能对自己用牌，直到阵亡 |
| **连环策略** | 对方阵亡一人后，再反复用强化版霜冻贴对面剩下一个人 → **对面毫无游戏体验** |
| 评价 | **极度恶心的控制手段**，讲者特意补充分享 |
