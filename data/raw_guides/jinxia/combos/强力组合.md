

# 《名将杀》强势组合盘点总集（多期合集）

---

## 一、系列说明

- **讲者**：景夏（老夏）
- **形式**：每期盘点 **3 套"选出来基本稳赢"的强势组合**
- **素材来源**：UP主原创 + 评论区 
- **涵盖期数**：共 7 期，每期 3 组，合计 **21 组** 强势 / 阴间组合

---

## 二、第一期组合

| 组合 | 机制 | 效果 |
|------|------|------|
| **张良 + 夏侯惇** | 夏侯惇开局把所有牌交给张良；张良在回合内把一张牌转化为"先拔头筹"；夏侯惇再拿牌再全交 | 张良获得**用不完的杀**，回合内即可觉醒六韬技能，轻松打残甚至直接带走一名对手 |
| **赵姬 + 大乔** | 赵姬被削弱但组合无损；开局大乔与赵姬绑定；赵姬尽情发动"绝好善舞"弃牌刷牌；大乔把对手手牌扒光；赵姬打连环 + 喝怒酒；手牌不够时开限定技 | 一波将对面击败 |
| **西门豹 + 甄宓 / 甘宁** | 西门豹通过技能为队友刷出大量**黑桃牌** | 配甄宓：甄宓获黑桃牌可多摸牌，西门豹回合内攒下**十几张牌**；配甘宁：甘宁获黑桃牌可拆牌，把对手手牌扒光，让对手完全没游戏体验 |

---

## 三、第二期组合

| 组合 | 机制 | 效果 |
|------|------|------|
| **卫子夫 + 孙权** | 卫子夫手牌易卡住、难觉醒，但孙权配合让首回合即可觉醒 | 首回合卫子夫把牌全交给孙权 → 交牌瞬间即觉醒 → 孙权把能打出的牌换回 → 卫子夫不停印牌，**几乎无敌** |
| **卫青 + 陈阿娇** | 卫青"强命"技能刷新需失去武刚车；陈阿娇"金屋藏娇"让卫青任意数量牌交给陈阿娇 | 卫青**每回合**把武刚车交给陈阿娇 → 刷新技能 → 每回合**双刀暴击**，输出爆表 |
| **荀彧 + 吕布** | 荀彧坐 1 号位、吕布坐 4 号位 | 荀彧发动限定技"驱虎吞狼" → 吕布决斗中敌人受伤 → 吕布打出所有杀，每张命中从另一敌方要牌 → 荀彧再交战法转化为 4 张杀 → 二波"二虎竞食"，基本打死一个、打残另一个 |

---

## 四、第三期组合（冷门强将）

| 组合 | 机制 | 效果 |
|------|------|------|
| **左慈 + 春申君** | 春申君的"无妄之灾"能让包含自身战法牌效果翻倍；左慈出牌时可将一名其他角色视为虚拟目标 | 左慈对敌方使用"夺粮劫营" + 春申君当虚拟目标 → 这张战法牌**结算两次**，敌方被偷两次牌（左慈没摸到夺粮时也可让春申君转化出） |
| **赵姬 + 步练师** | 步练师"亡语"把所有手牌交给队友，让队友摸装备并装备到上限；赵姬每打出一张牌可弃一张再摸一张（可弃装备区） | 步练师让赵姬装装备 → 赵姬弃装备再摸 → 装备永远装不满 → **无限循环摸牌直到牌堆无装备牌**，大量爆发 |
| **袁绍 + 陈胜** | 袁绍坐 1 号位放万箭齐发；4 张万箭让陈胜直接掉到 1 血 | 1 血陈胜发动限定技抢回合 → 4 号位陈胜回合结束 → 轮回 1 号位袁绍再打一个回合 → **连续 3 个回合**，首轮即可拿下对手 |

## 五、第四期组合

| 组合 | 机制 | 效果 |
|------|------|------|
| **白起 + 赵威后** | 白起出杀 / 杀命中时销毁敌方区域内任意一张牌；赵威后"无民何有君"在他人牌被销毁时触发判定 | 判非梅花 → 敌方流失 1 体力；**不断销牌 + 判定**，压制力拉满；白起销光对方手牌触发空城 → 赵威后再判定；"质子为兵"还可交互手牌（丈八蛇矛、盗骊等关键牌） |
| **芈八子 + 项梁** | 芈八子觉醒后可将队友划入自身势力，通过"权御四贵"交付贵牌；队友拥有贵牌时每回合前两次打出的牌生效两次；项梁在其他角色回合开始时打出杀 | **双倍杀**直接触发两次伤害；推荐芈八子 2 号位 + 项梁 3 号位 → 首回合即吃到贵牌收益，每个敌方回合开始时双倍杀 → 对方拿不出 2 闪就被命中 + 项梁偷牌，效果**毁天灭地** |
| **乐毅 + 袁术** | 袁术登场得玉玺 + 4 号位初始 5 张 + 4 张 + 1 张 = **10 张牌**；乐毅"报惠王书"每轮开始时复制一名角色全部手牌 | 首回合乐毅复制袁术的 10 张牌 + 自己摸 2 张 = 合计 22 张 + 孤军连克收益 → **开局 24 张牌**，**游戏内开局手牌量断层领先**，前期压制力无解 |

## 六、第五期组合

| 组合 | 机制 | 效果 |
|------|------|------|
| **王异 + 郑袖** | 郑袖坐王异前置位；郑袖回合只留 1 张杀，其余全交给敌方；郑袖杀一刀王异触发"舍子全义"技能 → 拿牌敌方需弃全部手牌再摸至上限 | 弃牌插入结算瞬间触发郑袖"掩袖工谗" → 打出等同于标记数量的杀 → **敌方空城状态吃下全强命杀**，快速清场 + 郑袖疯狂过牌 |
| **诸葛亮 + 黄月英 / 春申君** | 诸葛亮"锦囊妙计"有概率刷出"舌战群儒"；春申君和黄月英都能让打出的舌战群儒生效两次；黄月英还能叠自身复制叠 3 层 | 后续回合**1 张锦囊 = 一摸二甚至一摸三**，回合内超高爆发 ⚠️ 注意不要摸空牌堆（摸空判平局） |
| **赵姬 + 太子丹** | 太子丹：任意角色手牌为 0 时，自身流失 1 体力为该角色补 2 张牌；赵姬频繁打牌 / 弃牌清空手牌 | 完美触发太子丹补牌；太子丹本回合流失体力 → 把目标角色弃牌阶段改为出牌阶段 → 赵姬**双出牌阶段**二次爆发，配合频繁掉血补牌，**一回合可秒 2 名角色** |

## 七、第六期组合（讲者个人最爱）

| 组合 | 机制 | 效果 |
|------|------|------|
| **扶苏 + 虞姬** | 虞姬刷出 1 张桃 / 怒即可启动；虞姬绑定扶苏；扶苏用"山有扶苏"给自己和虞姬卖血补牌 → 扶苏掉到 1 血时对虞姬造成 1 点伤害 → 虞姬替扶苏承受 → 扶苏回血 + 得 1 张决斗 → 再用山有扶苏 + 决斗循环 | **Bug 级无限循环刷牌**，靠技能组联动疯狂刷控制 / 输出战法打出额外伤害；虞姬濒死吃桃 / 怒回满（山有扶苏效果可叠加）⚠️ 短板：摸到基本牌太多就循环不下去 |
| **赵婕妤 + 孙权** | 孙权坐赵婕妤前面，优先打出与玉钩花色 / 点数相同的牌 → 赵婕妤把玉钩交给孙权 → 孙权发动"劝学励士"置换手牌 → 赵婕妤一次性复制 → 赵婕妤回合再通过"劝学励士"把牌交回孙权 → 再复制一遍 | **无限刷牌**；回合外敌方摸 4 张牌时孙权触发"乘马射虎"摸 1 张 + 赵婕妤蹭牌；孙权有"玉钩"不掉时每回合回血，**基本打不死** |
| **董仲舒 + 尉缭** | 两者与"卜卦"机制高度绑定：有人卜卦 → 董仲舒获得卜卦牌复制 + 尉缭获得一张梅花牌；董仲舒把战法牌转天雷地火 → 全场频繁触发卜卦判定 | 两人技能收益拉满，**打运营发育**非常强势；尉缭还有卖血强化手牌机制，防御也不错 |

## 八、第七期组合（评论区征集系列）

| 组合 | 机制 | 效果 |
|------|------|------|
| **郑袖 + 郭嘉 / 徐盛 / 王异 / 大乔** | 郑袖将牌交给卖血将（郭嘉 / 荀彧 / 曹丕等）→ 对方打出郑袖的牌 → 郑袖杀队友触发其卖血 → 过牌 + 卖血双收益 | 徐盛让"不动白"有发挥（类似的还有李牧、项燕）；大乔让"掩袖工谗"杀转移出去 → 敌方卖血为我方补牌（类孟尝君） |
| **平阳公主 + 韩非** | 平阳通过"凤历三春"学习韩非的"不期修古"并立即发动 → 将"凤历三春"替换掉 → 平阳保留不期修古 + 新技能 | 韩非凭"不期修古"不断换技能，两轮内凭空多出**至少 2 个技能**；两次机会用完后可用不期修古移除"荐姝入掖" → 平阳也成拥有额外 2 个技能的技能怪（用张仪替换平阳也可实现） |
| **平阳公主 + 张梁** | 平阳学习张梁的"黄天精勇"召唤小兵 | 我方形成**2 真人 + 2 小兵 vs 2 对手**的**四打二**离谱局面 |
| **乐毅 + 大乔** | 大乔绑定角色只要弃牌或掉血 → 大乔可拆其他角色一张牌；乐毅"废苛顺民"回合外用行动牌时翻看牌底 → 选打或不打 → 剩余弃置（触发大乔弃牌效果）；"报惠王书"也有弃牌 | 打大乔 → 大乔转给乐毅 → 乐毅看牌 + 掉血 → 弃对方 2 张牌；**越打越强、越打越恶心**的控制组合 |
