# 元规则资料整理模板（卡牌游戏规则专家用）

> 用途：这是"规则专家"知识库的骨架。武将/卡牌资料描述"单卡怎么用"，
> 元规则描述"游戏怎么运转"。两者结合，专家才能算清组合结算。
> 填写方式：按章节补充内容，能填多少填多少；每章节的"示例"来自乐广数据。

## 1. 术语表与基础概念

### 1.1 牌的类型
| 类型 | 定义 | 本游戏的具体牌名 |
|---|---|---|
| 基本牌 | 如【杀】【闪】【桃】 | 待填 |
| 战法牌 | 玩家可主动打出的策略牌（技能中出现的特殊类型） | 待填 |
| 装备牌 | 武器/防具/坐骑等 | 待填 |
| 其他 | — | 待填 |

### 1.2 区域定义
| 区域 | 定义 |
|---|---|
| 手牌区 | 角色手中的牌 |
| 装备区 | 已装备的牌 |
| 判定区 | 放置延时类牌的牌 |
| 牌堆 / 弃牌堆 | 抽牌与弃牌的牌 |
| 处理区 | 正在结算中的牌 |

### 1.3 动作定义（技能描述里反复出现的动词）
| 动作 | 定义（何时算触发、何时不算） |
|---|---|
| 获得 | 因摸牌、技能、卡牌效果进入手牌，均算获得？摸牌阶段摸牌算获得吗？ |
| 打出 | 主动使用一张牌（区别于"使用"？） |
| 使用 | 按规则声明并使用一张牌 |
| 弃置 | 主动/被动放入弃牌堆 |
| 交给 | 从一个角色转移到另一个角色 |
| 展示 / 翻面 / 横置 | — |

### 1.4 状态定义
| 状态 | 定义 |
|---|---|
| 濒死 | 体力≤0 时的结算流程 |
| 受伤 | 体力减少的时点 |
| 手牌上限 | 弃牌阶段需弃到几（乐广：max_hand=5） |
| 距离 / 攻击范围 | — |

> 说明：本游戏出现过的特色动词，例如乐广的"获得牌""战法牌"必须在此定义，
> 否则专家无法区分"摸牌"和"获得牌"是否算同一件事。

## 2. 回合流程

### 2.1 标准回合阶段顺序
按顺序列出每个阶段，并注明"该阶段固定做什么 + 可插入的时机"：

1. 回合开始阶段
2. 判定阶段
3. 摸牌阶段（摸几张）
4. 出牌阶段（乐广的"名教乐地"会插入额外的出牌阶段）
5. 弃牌阶段（弃到手牌上限）
6. 回合结束阶段

### 2.2 额外回合 / 额外阶段规则
- 额外回合如何插入？当前回合的剩余阶段如何处理？
- 额外出牌阶段的触发与结算（乐广技能 3 提到"插入的出牌阶段(何以家为)"，须在此定义）

### 2.3 每阶段可插入的时机
| 阶段 | 可插入时机（谁可发动什么） |
|---|---|
| 摸牌阶段 | 技能触发：摸牌前/摸牌后 |
| 出牌阶段 | 使用牌的时机、技能发动时机 |
| 回合结束阶段 | "回合结束时"技能（乐广 3 个技能都涉及回合结束） |

## 3. 时机系统（最重要，最难）

### 3.1 时机优先级表
当多个时机可能同时发生时，按什么顺序结算？先排一版草表：

```
濒死结算 > 造成伤害时 > 受到伤害后 > 获得牌后 > 回合结束时 > ...
```

> 示例：乐广"杯弓蛇影"的时机是"其他角色获得牌后"，
> 需要知道它与"获得牌后"的其他技能同时触发时谁先谁后。

### 3.2 同时触发的处理原则
- 多个技能同一时机触发，按什么顺序？（当前回合角色逆时针？按当前角色决定？）
- 多个目标时逐个结算的顺序

### 3.3 插入结算
- 正在结算一个效果时，能否再插入另一个效果？（如获得牌 → 触发技能 → 技能又摸牌）
- 嵌套触发的上限/规则

### 3.4 时间单位定义
| 单位 | 定义 |
|---|---|
| 本轮 | 从当前角色回合开始到其回合结束？ |
| 本回合 | 当前角色的整个回合 |
| 每个回合 | 所有角色的回合都算？ |

> 乐广"杯弓蛇影"用到"本轮"和"每个回合结束时"，必须精确定义。

### 4.1 技能类型体系
| 类型 | 定义 | 例子 |
|---|---|---|

| 限定技 | 整局只能发动一次 | 待填 |

| 主公技 | 仅主公可用 | 待填 |
| 主动技/触发技/常驻技 | — | 待填 |

### 4.2 技能与卡牌优先级
- 技能效果与卡牌效果冲突时谁优先？
- 技能"无效/封印"的规则（乐广"令此技能对其无效，直到本轮结束"→ 须定义"无效"的完整含义）

### 4.3 伤害结算流程（标准模板）
```
造成伤害 → 伤害结算 → 受伤 → 伤害相关技能触发 → 伤害结算结束
```
每步列出可插入的时机（这是大量技能的共同骨架）。

### 4.4 其他通用流程
- 判定流程
- 距离与攻击范围计算
- 死亡结算（濒死 → 桃/技能 → 死亡 → 奖惩 → 移除）

## 5. 常见裁定原则（FAQ 的元规则）

以下每一条都是一个"通用裁定"，收集得越多，专家越稳：

- [ ] 一个效果同时指定多个目标时的结算顺序
- [ ] 效果持续到"回合结束"时，若插入额外回合如何处理
- [ ] 目标失效（死亡/离开游戏）时效果如何结算
- [ ] 牌被替换/转移后，原技能引用是否仍有效
- [ ] 两个技能互相引用时的死循环处理
- [ ] 锁定技被"无效"时是否计入"发动过技能"（乐广技能 2 涉及"没发动过技能"判断）
- [ ] 服务器官方裁定/FAQ 原文收集（格式：问题→答案→版本）
