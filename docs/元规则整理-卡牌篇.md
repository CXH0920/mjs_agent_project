## 1. 术语表与基础概念

### 1.1 牌的类型
- **行动牌**：包含杀、闪避、蟠桃、怒气、易（来源：惊羽弓）
- **战法牌**：可被"识破"抵消的策略牌（来源：识破/烽火狼烟/休养生息等）
- **装备牌**：含武器、防具、坐骑等；部分有"装备时"触发效果（来源：银狮盔、盗骊、丈八蛇矛）
- **杀的种类**：普通杀（冲杀）、火杀（火焰伤害）、雷杀（雷电伤害）、"易"可当作任意行动牌（含杀）打出（来源：4/48/49）
- **花色/点数规则**：雷杀=点数为4且属性非♥；火杀=火属性（花色原文需核对）；丈八蛇矛随机添加的杀按此规则判定属性（来源：49/48/30）

### 1.2 区域
| 区域 | 依据 |
|---|---|
| 手牌区 | 夺粮劫营/破阵卸甲"选择目标手牌时无法查看手牌的具体信息" |
| 装备区 | 云锦袍/凤羽盔等 |
| 卜卦区 | 天雷/地火/霜冻/久旱"进入下一位玩家的卜卦区""卜卦区的牌按照进入顺序依次卜卦"；夺粮劫营/破阵卸甲/龙舌弓可操作卜卦区的牌 |
| 弃牌堆 | 怒气"随机弃置1张牌"、烈火焚城"弃置" |
| 牌堆 | 先拔头筹"翻开存活玩家数量张牌" |

## 2. 回合流程

### 2.1 阶段顺序（从卡牌可确认的节点）
```
回合开始时  → [卜卦区判定：天雷/地火/霜冻/久旱；赤兔摸1]
出牌阶段开始时 → [重置出杀次数为1]
出牌阶段    → [主动打出杀消耗次数；技能/响应打杀不消耗]
摸牌阶段    → [久旱可跳过；跳过则阶段内其他技能也不触发]
弃牌阶段    → [手牌上限生效（凤羽盔）；回合外装备被弃不立即弃牌]
回合结束时  → [爪黄飞电摸1]
```

### 2.2 出杀次数机制（重点）
1. 出牌阶段开始时重置为 1 次（来源：8）
2. **只有**出牌阶段**主动**打出杀才消耗次数（来源：8）
3. 以下情况**不消耗**次数：响应烽火狼烟/阵前对决/调兵遣将打出的杀、亮银枪应战、干将莫邪效果（来源：1/11/56/33/27）
4. 青龙偃月刀：杀被抵消时出杀次数+1（"抵消杀"才算，纯免伤不算）（来源：29）
5. 诸葛连弩：需要"能打出杀"才能发动（无次数则发动不了）（来源：32）

### 3.2 时机优先级（从卡牌说明推导）
1. **重伤结算优先于受伤效果**：的卢"受伤进入重伤状态，需先脱离重伤，受伤效果才生效"（来源：42）
2. **应战时机在响应打出闪之前**：亮银枪（来源：33）
3. **防具结算顺序**：银狮盔"结算时机是所有防具牌的最后"（来源：39）
4. **同一防具一次伤害只触发1次**：藤甲"同时发生的火属性伤害不会叠加"；双银狮盔一次伤害只生效1个（来源：34/39）
5. **回复效果先于抵消效果**：八卦盾"卜卦为回复时，回复效果先生效"（来源：36）
6. **多人同时响应**：识破"所有角色同时询问，以最先完成操作的角色为准"（来源：55）

### 3.3 插入结算与"错过时机"
- 先拔头筹：某角色获得牌触发新效果时，**后续发牌效果暂停执行**（来源：16）
- 连环：**结算过程中**新进入连环状态的角色错过时机，不参与本次伤害结算（来源：9）
- 连环：每个角色一次伤害只结算1次，中间插入任何效果也只生效优先级最高的一次（来源：9）
- 诸葛连弩"自动打出杀"状态中，**无法发动其他需要主动发动的技能**（来源：32）

### 3.4 时间单位与次数限制
- **本回合**：怒气"本回合打出怒的次数"（来源：50）
- **每回合限1次**：干将莫邪、飒露紫（来源：27/45）
- **下1张/下一张**：怒气"对下1张杀的伤害+1，只对下一张杀有效"（来源：50）
- **当前回合**：怒气"当前回合再次打出此牌时..."（来源：50）
- **直到回合结束**：怒气增伤效果（来源：50）
- **持续到杀效果结束**：贯穿（来源：22）

## 4. 通用规则与结算原则

### 4.1 打出杀 vs 使用杀（本游戏最重要区分）
1. 所有"打出杀"都是打出杀：包括主动打杀、响应烽火狼烟/阵前对决/箭雨齐射等（来源：8/1/11）
2. 响应效果的杀**不造成伤害**（烽火狼烟/阵前对决中打出的杀只用于响应）（来源：8/11）
3. 响应打出的杀**不消耗出杀次数**（来源：11/56/27）
4. 响应打出的杀**正常触发所有"打出杀相关"的技能**（乌骓摸1、诸葛连弩不自动打等）（来源：1/40/32）
5. 打出的杀**必须有目标**才执行伤害效果（来源：8）
6. 诸葛连弩只自动打出"本身是杀"的牌，"易"不算杀（来源：4/32）

### 4.2 伤害类型与伤害流程
```
打出杀 → 指定目标 → 目标响应（闪/防具/技能）→ 造成伤害 → 伤害结算（防具/增伤）→ 伤害结束
```
- 伤害类型：无属性伤害 / 火焰伤害 / 雷电伤害（来源：48/49/34）
- **无伤害来源的伤害**：天雷/地火造成的伤害无来源，羽扇增伤不生效（来源：19/20/31）
- 属性伤害 → 触发连环传导（来源：9）
- 藤甲：防止无属性伤害，火伤+1后烧毁（来源：34）
- 银狮盔：受到>1点伤害时改为1点并销毁（来源：39）

### 4.3 伤害加成/减免的叠加
| 规则 | 来源 |
|---|---|
| 怒气：伤害+1可累计，只对下1张杀有效，持续到回合结束 | 50 |
| 开山斧：伤害+1可累加，多目标每个都+1；结算时若已离场则不生效 | 23 |
| 羽扇：所有火焰伤害+1（无来源伤害不触发） | 31 |
| 藤甲：火伤+1（只触发1次） | 34 |

### 4.4 防具结算
- 防具指"成为杀的目标时"可触发的装备：八卦盾（卜卦抵消/回体）、玄武盾（打杀抵消）、藤甲（免无属性伤害）、银狮盔（减伤）等
- **防具优先级**：银狮盔最后结算（来源：39）
- **强命克制防具**：强命杀指定时，八卦盾卜卦抵消无效（来源：36）
- **抵消杀 vs 抵消伤害不同**：青龙偃月刀只对"抵消杀"触发+1，藤甲免伤不触发（来源：29）
- 被无属性杀指定时仍可响应（藤甲存在也可打闪）（来源：34）

### 4.5 识破与战法牌响应
- 识破目标 = 即将生效的战法牌；全场同时询问，最先完成者生效；识破可被识破抵消（来源：55）
- 多目标战法牌（烽火狼烟/箭雨齐射/休养生息）：从打出者下个座位号开始，逐目标结算，**每个目标前都可打出识破**（来源：1/59/10）

### 4.6 卜卦机制
- 卜卦区：牌进入后按**进入顺序**依次判定（来源：19/20/51/52）
- 判定依据：点数（4=雷伤、1~7/8=的卢）或花色（八卦盾/霜冻/久旱/丈八蛇矛）（来源：19/42/36/51/52/30）
- 卜卦未生效 → 牌进入下一位玩家卜卦区（天雷/地火）（来源：19/20）
- 卜卦区的牌可被夺粮劫营/破阵卸甲/龙舌弓获取或弃置（来源：53/54/26）

### 4.7 目标与距离
- 杀只能指定攻击范围内的其他角色；不可对自己打杀（来源：8）
- 调兵遣将：只能指定"攻击范围内"的目标（来源：56）
- 方天画戟：可指定目标的角色数≥1才可触发多目标（来源：28）
- 多目标杀算"打出1张杀"（来源：28）

### 4.8 装备规则
- 装备上限默认3（已确认，完整版 FAQ 35），云锦袍+2；超上限时弃置最早装备的牌；上限可为负数（来源：35）
- 装备牌离场不影响已发动效果的判定（开山斧结算时已离场则不增伤）（来源：23）
- 装备"应战"类武器（亮银枪）与"防御"类防具的响应顺序（来源：33）
