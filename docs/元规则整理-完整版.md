## 2. 回合流程

### 2.1 标准回合阶段（各阶段事件）
```
回合开始
  ├─ 卜卦区判定：天雷/地火/霜冻/久旱按进入顺序判定（未生效进入下一位卜卦区）
  ├─ 回合开始时技能：赤兔摸1、武将技能（80 处）
  └─ "体力值首次变为1"等首次类检查：描述中的首次情况出现时立即执行（已确认）
出牌阶段
  ├─ 开始时：重置出杀次数为 1
  ├─ 出牌阶段限1次 技能可发动（194 处技能涉及出牌阶段）
  └─ 结束时：出牌阶段结束类技能（王元姬烛奸抑势）
摸牌阶段
  ├─ 可被跳过（久旱）；跳过则该阶段其他技能不触发
  └─ 摸牌数可被修改（郭解"下个摸牌阶段摸牌数-1"）
弃牌阶段
  ├─ 手牌上限在此生效（凤羽盔）
  └─ 回合外改变手牌上限不强制弃牌
回合结束
  ├─ 回合结束时技能（64 处）：爪黄飞电摸1、乐广技能等
  └─ 每轮结束时检查（陆机华亭鹤唳）
```

### 2.2 出杀次数机制（重点）
1. 出牌阶段开始时重置为 1 次（卡牌 8）
2. **只有**出牌阶段**主动**打出杀消耗次数（卡牌 8）
3. **不消耗**的情形：响应烽火狼烟/阵前对决/调兵遣将/箭雨齐射、亮银枪应战、干将莫邪效果（卡牌 1/11/56/33/27）
4. 杀被**抵消**时出杀次数+1（抵消杀才算，纯免伤不算；青龙偃月刀）（卡牌 29）
5. 诸葛连弩需"能打出杀"才能发动（卡牌 32）
6. 出杀次数默认 1 次；**上限无固定值，由技能与装备效果决定**（可永久或临时增加）（已确认）

### 2.3 时间单位
| 单位 | 定义 | 来源 |
|---|---|---|
| 本回合 | 当前角色整个回合 | 怒气/王元姬 |
| 每个回合 | 任意角色的回合 | 干将莫邪/主父偃 |
| 本轮 | **当前轮次尚未结束前**（即本轮次进行中；"轮"=全场各完成一次回合） | 人工确认 |
| 每轮（轮次） | **全场每个玩家都进行过一次回合**（已确认） | 人工确认 |
| 直到你的下个回合开始 | 跨回合持续效果 | 13 处技能 |
| 直到回合结束 | 效果持续时间 | 怒气增伤 |
| 直到杀的效果结束 | 贯穿 | 卡牌 22 |

### 3.4 插入结算与"错过时机"
- 获得牌触发新效果时，**发牌流程暂停**（先拔头筹）（卡牌 16）

## 4. 通用结算原则

### 4.1 打出杀 vs 使用杀（最重要区分）
1. 所有"打出杀"都是打出杀（主动/响应都算）（卡牌 8）
2. 响应效果的杀**不造成伤害**、**不消耗出杀次数**（卡牌 8/11/56）
3. 响应打出的杀**正常触发所有"打出杀相关"技能**（乌骓摸1、青龙偃月刀+1等）（卡牌 1/40/29）
4. 打出的杀**必须有目标**才执行伤害（卡牌 8）
5. 诸葛连弩只自动打出"本身是杀"的牌（"易"不算杀）（卡牌 4/32）
6. 装备效果打出的杀：玄武盾打杀抵消、亮银枪应战**不消耗次数**（卡牌 37/33）

### 4.2 伤害流程与类型
```
打出杀 → 指定目标 → 目标响应（闪/防具/技能）→ 造成伤害 → 伤害结算（防具/增伤/减免）→ 伤害结束
```
- 类型：无属性伤害 / 火焰伤害 / 雷电伤害（卡牌 48/49/34）
- **无来源伤害**：天雷/地火无伤害来源，不吃增伤（羽扇不生效）、不触发依赖来源技能（郭解江湖道敕）（卡牌 19/20/31、武将）
- 属性伤害 → 触发连环传导（卡牌 9）
- 藤甲：免无属性伤害、火伤+1后烧毁（卡牌 34）
- 银狮盔：>1 点伤害改为 1 点并销毁（卡牌 39）
- **多目标杀**：增伤逐目标依次计算；"造成伤害摸牌"类每张牌只结算一次（武将 魏延）

### 4.3 伤害加减成叠加
| 规则 | 来源 |
|---|---|
| 怒气：伤害+1 可累计，只对下 1 张杀有效，持续到回合结束 | 卡牌 50 |
| 开山斧：伤害+1 可累加，多目标每个都+1；结算时已离场则不生效 | 卡牌 23 |
| 羽扇：所有火焰伤害+1（无来源伤害不触发） | 卡牌 31 |
| 藤甲：火伤+1（一次伤害只触发 1 次） | 卡牌 34 |
| 伤害减免到 0 仍算触发 | 武将 主父偃 |

### 4.4 防具结算
- 防具类：八卦盾（卜卦抵消/回体）、玄武盾（打杀抵消）、藤甲（免无属性伤害）、银狮盔（减伤）
- 银狮盔最后结算；强命克制八卦盾；抵消杀≠抵消伤害（卡牌 29/39/36）
- 被无属性杀指定时仍可响应（藤甲存在也可打闪）（卡牌 34）
- 装备上限与超上限弃牌规则（云锦袍）（卡牌 35）

### 4.5 识破与战法牌响应
- 识破目标=即将生效的战法牌；全场同时询问、最先完成者生效；可被识破抵消（卡牌 55）
- 多目标战法牌（烽火狼烟/箭雨齐射/休养生息）：从下个座位号起逐目标结算，每目标前可打识破（卡牌 1/59/10）
- 武将技能与战法牌交互：105 处技能引用战法牌；"上1张被打出的战法牌"为全局客观状态（武将 司马炎）

### 4.6 卜卦机制
- 卜卦区按**进入顺序**依次判定（卡牌 19/20/51/52）
- 判定依据（已确认）：点数——天雷点数4→4点雷伤、地火点数3→3点火伤、的卢点数1~7/8；花色——八卦盾♣→回1体、♠→抵消杀、霜冻♠/♦→禁选目标、久旱♥/♣→跳过摸牌阶段（卡牌 19/20/42/36/51/52）
- 卜卦未生效 → 牌进入下一位卜卦区（天雷/地火）（卡牌 19/20）
- 卜卦区牌可被获取/弃置（夺粮劫营/破阵卸甲/龙舌弓）（卡牌 53/54/26）
- 武将也可卜卦（郭舍人投壶）（武将）

### 4.7 目标与距离
- 杀只能指定攻击范围内其他角色；不可对自己打杀（卡牌 8）
- 调兵遣将只能指定攻击范围内目标（卡牌 56）
- 方天画戟：可指定目标数≥1 才可多目标（卡牌 28）
- 多目标杀算打出 1 张杀（卡牌 28）
- 效果可**强制指定目标**，绕过"不可被指定"类效果（魏延谁敢杀我）（武将）
- 按座位号依次结算（烽火狼烟、主父偃徙豪茂陵）（卡牌 1、武将）

### 4.8 装备规则
- 装备上限默认 **3（已确认）**；云锦袍+2；超上限弃最早装备；可为负数（卡牌 35）
- 装备离场不影响已发动效果判定（开山斧）（卡牌 23）
- 装备时触发效果：银狮盔回1、盗骊摸2、丈八蛇矛加2杀（卡牌 39/47/30）
- 打出装备牌可触发技能（刘禅乐不思蜀）（武将）
- **装备区无类型限制（已确认）**：可全武器/全坐骑/任意组合；**同名装备无数量限制**
- **多件武器（已确认）**：攻击范围**取最大值**（如轩辕剑2 + 方天画戟4 → 范围4）
- **多件坐骑（已确认）**：距离分**攻击距离/防御距离**，同类修正各自相加；-1马影响攻击距离、+1马影响防御距离；例：两匹-1马+一匹+1马 → 攻击距离-2、防御距离+1
- **基础攻击范围（已确认）**：无特殊技能/武器/马匹加持时，只能打到距离为1的玩家
- **坐骑距离修正明细（已提供）**：距离-1（攻击距离）＝赤兔/盗骊/白蹄乌/乌骓；距离+1（防御距离）＝飒露紫/爪黄飞电/绝影/的卢
- **武器攻击范围明细（已提供）**：龙舌弓5/惊羽弓5/方天画戟4/羽扇4/亮银枪3/丈八蛇矛3/青龙偃月刀3/开山斧3/干将莫邪2/鸣鸿刀2/轩辕剑2/诸葛连弩1

### 4.9 技能体系（武将特色）
1. **类型**：不使用"锁定技/觉醒技/主公技"标签；技能频率用**限 X 次**机制表达（见 3.5）；**限定技**以"限定，"前缀显式标注（本局游戏限1次，共31个技能）
2. **技能传递**：获得此技能/失去此技能；新技能是"全新的技能"，不受技能修改影响（武将 王元姬）
3. **按初始限制次数判断增益**（武将 王元姬烛奸抑势）
4. **阵亡后技能效果仍存续**（武将 郭解为侠者众）
5. **跨回合/全体累计计数**：跨回合记录、全体累计达到阈值触发/停止（武将 傅玄/司马炎/主父偃）
6. **技能进化**：累计阈值后增加/失去效果（司马炎善始难终）
7. **技能修改**：仅技能描述中明确提到的效果可修改技能（如韩非"事异备变"、王元姬"谦冲接下"）
8. **元气**：目前仅傅玄技能涉及，不按全局资源建模
9. **限定技**：技能描述以"限定，"开头 = 本局游戏限发动1次（31个技能）；另有"部分效果仅1次"的子效果限次（每种牌限1次/首次类/累计阈值一次性）
7. **技能可被封印/无效**：封禁（卡牌 22）、无效（武将 12 处）

### 4.10 阵亡结算
- 阵亡时与伤害来源同时结算奖惩（郭解权行州里）（武将）
- 阵亡后效果仍存续（郭解为侠者众）（武将）
- 结算过程中角色阵亡 → 多余牌弃置（先拔头筹）（卡牌 16）
- **完整阵亡流程（已确认）**：重伤濒死 → 全场求救 → 体力依然≤0 → **触发亡语技能** → 阵亡移除武将
- **亡语技能（已确认）**：阵亡/死亡后触发的技能的概述（如郭嘉"遗策平辽"、孙坚"魂定江东"、虞姬"霸王别姬"、扶苏"贤闻于民"、郭解"为侠者众"等；不要求独立完整清单）
