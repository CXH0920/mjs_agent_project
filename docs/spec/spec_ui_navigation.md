# UI 导航与页面归属规范

> 本文定义信息架构和功能归属。阶段一、二已建立规范与公共基础，阶段三已实施主窗口应用外壳与导航，阶段四已实施资料库两个二级视图的信息层级改造。

## 一、已实施结构

```text
应用框架
├─ 顶部上下文栏
│  ├─ 当前工作区标题/说明
│  └─ 页面级操作与全局设置入口
├─ 左侧主导航
│  ├─ 资料库
│  │  ├─ 武将资料
│  │  └─ 卡牌图鉴
│  ├─ 选将推荐
│  └─ 对局攻略
├─ 页面内容区（主 QTabWidget 隐藏 TabBar）
└─ 底部状态栏
   ├─ 当前任务/数据状态
   ├─ 模拟器 ADB 状态
   └─ OCR 轮询状态
```

主导航只承载长期稳定的工作区。导入、生成、维护和配置等命令不升级为主导航项，避免业务动作与页面目的混在同一层级。

阶段三使用 `NavigationRail` 承载三个一级工作区，使用 `ContextHeader` 显示当前上下文。主 `QTabWidget` 只隐藏 `TabBar`，不销毁或重建资料库、选将推荐、对局攻略实例；资料库内部继续显示“武将资料 / 卡牌图鉴”二级页签。导航通过 Tab 容器切换页面，Tab 的 `currentChanged` 统一反向同步导航和顶部标题。

阶段四不改变资料库入口、页面实例或业务读写：仅统一“武将资料”和“卡牌图鉴”的主从布局、内容层级、上下文操作和版本状态表达。

## 二、框架尺寸

- 左侧导航展开宽度 156px，紧凑宽度 56px。
- 窗口宽度小于 1040px 时强制使用紧凑导航；回到宽屏后恢复用户本次会话中的展开/折叠选择。
- 960px 基准使用紧凑导航；1100px 和 1440px 基准在用户未主动折叠时展开。
- 顶部上下文栏建议高度 52px，底部状态栏建议高度 28px。
- 主内容区最小有效宽度不得低于 840px；必要时优先折叠导航。
- 导航切换不能销毁页面会话状态，继续复用现有页面实例。

## 三、页面操作归属

### 3.1 资料库

页面级操作：重新加载数据、官方数据导入、武将获取、攻略获取、武将相性生成。

- “重新加载数据”保留 `F5`，同时进入资料库的更多菜单。
- “官方数据导入”位于资料库标题栏的次要操作区。
- 武将、攻略和相性生成属于维护型任务，进入资料库的“生成与维护”菜单。
- 武将资料与卡牌图鉴继续使用弱化的二级切换器，不作为主导航项。
- 武将资料左栏限制为 240–360px，并在筛选区下方显示结果计数；右侧身份头部始终说明当前武将，内容区按武将信息、攻略指南、武将相性分层。
- 武将资料只显示一个与当前内容页对应的“编辑”操作；删除收纳到相邻“更多”菜单并保留二次确认。详情内容允许纵向滚动，不得出现横向滚动。
- 卡牌图鉴以单一基础资料表面呈现官方只读信息；“编辑版本调整”只编辑当前卡牌追加内容，“字段配置”继续位于顶部“更多”菜单。
- 卡牌版本状态以“生效中 / 待核实 / 已失效”文字配合状态色和左侧强调线表达，颜色不得成为唯一线索。

### 3.2 选将推荐

主要操作是“识别当前阵容”，次要操作是“从图片导入”。保存截图与重建推荐指数收纳到更多菜单。推荐指数过期时可在通知条内提供“立即重建”，但不得同时出现两个同权重重建入口。

### 3.3 对局攻略

主要操作是“识别当前阵容”，次要操作是“从图片导入”。保存截图与清空阵容收纳到更多菜单。阵容确认属于页面内容工作流，固定在左侧阵容区，不进入全局标题栏。

### 3.4 全局配置

API 配置、模拟器配置、势力配色和数据管理归入统一设置入口。模拟器和 OCR 状态可点击进入模拟器配置，但状态标签本身不承担普通按钮的视觉权重。

### 3.5 应用级命令

- 退出：保留 `Ctrl+Q` 和系统窗口关闭能力。
- 关于：位于全局设置/帮助菜单。
- 兼容菜单在阶段三继续保留，并与顶部入口共享同一组 QAction；不得重复创建命令或重写业务回调。

### 3.6 底部状态职责

- 当前任务/数据状态：显示数据统计以及采集、生成、截图、OCR 预热等短期进度和结果。
- 模拟器状态：常驻显示 ADB 未配置、连接中、已连接、离线等连接状态，可进入模拟器配置。
- OCR 状态：常驻显示轮询未启用、运行、恢复、冷却或暂停状态，可进入模拟器配置。
- 短期任务消息不得覆盖模拟器和 OCR 两类常驻状态。

## 四、页面模板

所有工作区页面遵循同一纵向结构：

```text
PageHeader：标题 + 状态                         主要操作 / 次要操作 / 更多
NoticeBanner：仅在存在待处理状态时显示
Content：业务主体，占据剩余空间
```

规则：

1. 标题栏同一操作组最多一个主要按钮。
2. 页面空状态可重复展示与下一步直接相关的操作，但标题栏应降低或隐藏重复动作。
3. 页面状态文字只说明当前状态，不承担按钮功能。
4. 内容视图内部的编辑、确认和筛选属于局部操作，不提升到页面标题栏。

## 五、页面状态清单

| 页面/弹窗 | 必须覆盖的状态 |
|---|---|
| 武将资料 | 初始选中、搜索无结果、资料缺失、攻略缺失、相性为空、编辑/删除失败 |
| 卡牌图鉴 | 正常列表、生效中/待核实/已失效、筛选无结果、基础库不可用、字段配置错误、无追加记录、保存失败 |
| 选将推荐 | 未识别、识别中、完整结果、部分未知、重复/待确认、指数过期、截图/OCR 失败 |
| 对局攻略 | 未识别、阵容待确认、阵营冲突、未知武将、已确认、攻略/胜率缺失、重新确认 |
| API 配置 | 正常、字段无效、保存成功、保存失败 |
| 模拟器配置 | 未配置、连接中、已连接、离线、模板缺失、轮询运行/暂停/恢复中 |
| 数据管理 | 无选择、可清空、生成任务占用、确认取消、备份/清空失败、完成 |
| 选择类弹窗 | 初始、筛选、无结果、已选、达到上限、确认不可用 |
| 生成进度 | 等待、运行、取消中、成功、部分完成、失败 |
| ROI 选择 | 正常图片、图片不可用、区域无效、确认/取消 |

## 六、自动导航与状态保持

- OCR 自动跳转继续由现有配置控制，默认不强制切换页面；启用后仍只调用主 `QTabWidget.setCurrentWidget()`。
- 选将命中切换至选将推荐，对局命中切换至对局攻略；两者不得改变资料库的二级页签和选中项。
- 页面切换保留当前搜索条件、滚动位置、已识别阵容和未提交的页面会话状态。
- 打开配置或编辑弹窗不改变主导航位置。

## 七、迁移验收

- 现有菜单中的每项功能都在归属表中有明确入口。
- `Ctrl+Q`、`F5` 及自动 OCR 跳转行为保持不变。
- 三档窗口宽度下导航与内容无重叠，折叠导航后可通过 Tooltip 和 AccessibleName 理解图标。
- 高频操作最多一到两次点击可达；危险操作不得成为默认焦点。
- 阶段三保留原菜单入口作为兼容路径；后续移除前必须确认新入口稳定，且共享 QAction 的快捷键和回调不变。
- 阶段四资料库在三档窗口下均不得出现页面级横向滚动；左栏宽度、结果计数、当前身份和上下文操作保持可见且不重叠。
