# 代码变更简报（2026-09-15 ~ 2026-09-21）

## 变更概览

自文档基线 2026-09-15 以来，项目经历了 16 次重要提交，涉及 OCR 引擎升级、白名单治理、轮询闲置暂停、合规化改造、巅峰赛优化、实战配队增强等多个方向。以下按功能分组列出关键变更，供文档更新参考。

## 1. B2 复核模式（d88fc2f）

**新功能**：对未决识别槽位，使用 PP-OCRv6-small/ONNX 引擎做候选内确认。

**新增文件**：
- `src/ocr/paddle_loader.py` — 新增 `create_rapidocr_ocr()` 构造 v6 复核引擎（RapidOCR/ONNX），`get_recheck_ocr_engine()` 惰性加载+失败熔断。`RapidOcrEngine` 包装层将 RapidOCR 结果翻译为 paddleocr 2.x 风格。设备固定 CPU（GPU 已否决）。det 参数显式 `limit_type=max/limit_side_len=960` 与生产画布同口径。模型缺失直接报错熔断，绝不触发联网下载。frozen 下复制到 %TEMP% 纯 ASCII 路径。
- `tests/test_ocr_recheck.py` — B2 复核模式测试

**修改文件**：
- `src/ocr/recognizer.py` — 集成 B2 复核：未决槽位经 v6 引擎复核确认候选
- `src/config/env.py` — 新增 `MUMU_OCR_RECHECK_ENABLED` 配置参数（默认 true）
- `src/business/recognition/official_data_import_service.py` — 官方导入集成复核引擎
- `config.env.example` — 新增配置参数说明
- `environment.yml` — 新增 rapidocr 依赖
- `mjs_agent.spec` — 打包配置更新

**设计文档**：`docs/design/ocr_engine_upgrade_eval.md` — OCR 引擎升级评估（v6-small/ONNX 路线实测数据与迁移决策）

**修改文件**：

## 3. 轮询闲置自动暂停（bca4092）

**新功能**：整帧指纹判闲、三路交互恢复与阈值校准工具。

**新增文件**：
- `src/ui/app/frame_fingerprint.py` — 整帧降采样指纹（32×18 灰度，576 字节），MAD 阈值 3.0。`compute_fingerprint()` + `frames_match()`。阈值依据 `calibrate_idle_threshold.py` 标定。
- `src/ui/app/poll_coordinator.py` — 轮询流程协调器（QObject）。强类型 `PollOutcome`/`PollTaskResult`/`PollResult`。闲置暂停：连续 5 分钟无画面变化自动暂停，用户交互恢复。`IDLE_PAUSE_MINUTES=5`。
- `src/scripts/calibrate_idle_threshold.py` — 闲置阈值校准工具（对真实截图序列的 MAD 分布标定）
- `tests/test_poll_idle_pause.py`

**修改文件**：
- `src/business/recognition/ocr_service.py` — 新增 `pause_for_idle()`/`is_poll_idle_paused()`/`poll_cancel_event`/`poll_generation`/`begin_poll()`/`complete_poll()`/`due_poll_tasks()` 等方法
- `src/config/env.py` — 新增 `MUMU_OCR_POLL_IDLE_PAUSE` 配置参数（默认 true）
- `src/ui/app/main_window.py` — 闲置暂停状态显示与恢复交互
- `src/ui/app/status_chips.py` — 闲置暂停状态芯片
- `src/ui/configuration/mumu_config_dialog.py` / `mumu_config_sections.py` — 闲置暂停配置项
