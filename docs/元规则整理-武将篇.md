## 2. 技能体系

### 2.1 技能类型（本游戏的特点：不用"锁定技/觉醒技/主公技/转换技"标签）
全库 418 个技能中 **"锁定技""觉醒技""主公技""转换技"出现次数均为 0**；**"限定技"以描述"限定，"开头，共 31 个技能**（如荀彧/曹丕/乐毅/刘邦/项羽/司马懿等，见完整版 3.5 / FAQ 61）。
本游戏用 **"限 X 次"机制** 表达技能频率限制：

| 表达 | 出现次数 | 含义 |
|---|---|---|
| 出牌阶段限1次 | 常见（如王元姬躬执纺绩、张华博物志） | 每个出牌阶段内最多发动 1 次 |
| 每个回合限1次 | 常见（主父偃筑城朔方、刘据博望纳贤） | 任意角色的每个回合内限 1 次 |
| 每轮限1次 / 每轮结束时 | 陆机华亭鹤唳、郭解权行州里 | "轮"= 所有角色各自完成一个回合|
| 每种牌限1次 | 乐广约言析理、陆机华亭鹤唳 | 每种牌名限 1 次 |
| 每回合每种牌限1次 | 乐广约言析理 | 组合限制 |

### 2.2 技能获取 / 转移 / 修改
- **获得此技能**（8 次）：王元姬躬执纺绩、乐广名教乐地等，技能可在角色间传递
- **失去此技能**（9 次）
- 新获得的技能是**"全新的技能"，不受技能修改的影响**（王元姬躬执纺绩结算说明）
- 技能的**初始限制次数**决定其是否受增益影响："只要技能初始限制次数为出牌阶段限1次，就会受到此技能的影响"（王元姬烛奸抑势）
- **阵亡后技能不在场但效果依旧存在**（郭解为侠者众）
- 技能可被**封印/无效**：卡牌篇"封禁"令武将技能失效；武将文本中"无效"12 次

### 2.3 技能相关的全局状态与跨回合记录
- **跨回合累计**："其他角色累计打出战法牌的数量是跨回合记录的"（傅玄近朱者赤）
- **全体累计**："所有角色累计打出15张削弱牌"（司马炎）、"所有角色每累计获得其他角色4张牌"（主父偃献策推恩）
- **全局客观状态**："上1张被打出的战法牌"不依赖技能而客观存在（司马炎容纳谠正）
- **技能进化**：累计达到阈值后技能增加新效果/失去旧效果（司马炎善始难终）
- **元气属性**：独立资源，不随技能转移而转移（傅玄元气上清）

### 3.3 时机细节规则
1. **增益延迟生效**："对目标的增益效果会在其下个出牌阶段开始时才真正生效"（王元姬谦冲接下）
2. **插入阶段不影响先前判断**："并不会因此技能发动后的插入的出牌阶段而导致效果失效"（乐广约言析理）
3. **"体力值首次变为1"**是独立触发时机（2 次）
4. **"非摸牌阶段获得牌"**可被单独区分（说明"获得牌"时机按来源分类）
5. **初始手牌**也属于"获得"：获得初始手牌时技能可触发（主父偃献策推恩）

## 4. 通用结算原则（从结算说明提取）

### 4.1 次数限制与"限次"体系
- 限次技能的**发动次数可以被增益**：+1（王元姬谦冲接下）
- **次数判断按"初始限制次数"**，不看当前状态（王元姬烛奸抑势）
- 技能效果不受"每个回合限1次"限制时会在结算说明中显式声明（司马炎善始难终）
- "只要元气数量足够，一个出牌阶段可以多次发动"（傅玄元气上清）——资源充足可突破默认限次

### 4.2 伤害相关
- **多目标伤害**："此杀会对每个目标依次计算杀的增伤"（魏延反骨逆战）
- **多目标不重复结算**："1张杀对多名角色造成伤害并不会在每次造成伤害时均摸牌"（魏延子午奇谋）——"此杀造成伤害"类技能每张牌只结算一次
- **伤害减免到 0 仍算触发**："即便伤害已经被减免成0点了，也可以正常触发"（主父偃筑城朔方）
- **无来源伤害**：不触发依赖伤害来源的技能（郭解江湖道敕）；与卡牌篇"天雷/地火无来源"呼应

### 4.3 阵亡结算（28 处提及）
- 阵亡时**伤害来源与相关角色同时结算奖惩**："当有一名角色阵亡时，你与伤害来源各失去1点体力"（郭解权行州里）
- **阵亡后效果仍存续**："阵亡后技能不在场但效果依旧存在"（郭解为侠者众）
- 过程中阵亡 → 多余牌弃置（卡牌篇先拔头筹）

### 4.4 目标与选择
- 选择类效果："至多X张可选牌中选择1张"（陆机华亭鹤唳）
- **按座位号依次结算**："按照座位号将牌放回牌堆顶，轮次结束时同样按照座位号重新摸牌"（主父偃徙豪茂陵）
- **效果可强制指定目标**："即便目标有空城计，此技能也会令其他角色可以对其打出杀，因为技能效果中默认选中了目标"（魏延谁敢杀我）
- 同一效果可发动多次的情形："当你与打出此牌的角色均非此牌目标时，此技能可以发动两次"（陆机缘情绮靡）

### 4.5 效果的持续性
- "持续到...结束/消失"类表述常见（10 处"持续"）
- 技能效果与牌效果分离：打出牌后获得的新牌也纳入"此过程中获得的牌"（刘禅素丝守成）
- 效果触发条件以"客观事实"为准，不依赖技能是否存在（司马炎容纳谠正）

## 5. 区域与资源（武将篇补充）

### 5.1 完整区域清单（张华双剑化龙结算说明）
> "任意位置包括所有玩家的**手牌区、装备区、卜卦区以及处理区、摸牌堆和弃牌堆**"

- **处理区**：卡牌结算中的位置（卡牌篇未出现，武将篇确认存在）
- **摸牌堆 / 弃牌堆**：卡牌篇的"牌堆/弃牌堆"在此统一命名
- **朔方**：主父偃专属区域（"将其中1张牌的复制放入朔方"）——独立于公共区域之外
- **牌的复制**：可将牌复制放入其他区域（主父偃筑城朔方、刘据博望纳贤"随机添加其中1张牌的复制至手牌"）

### 5.2 新资源与牌状态
| 资源/状态 | 说明 | 来源 |
|---|---|---|
| 元气 | 属性资源，可获取/消耗，不随技能转移 | 傅玄元气上清 |
| 削弱牌 | 可被"削弱"状态影响的牌（另有"增强牌"） | 司马炎、武圣义绝 |
| 龙泉剑/太阿剑 | 张华专属卡牌（可被销毁） | 张华 |
| 技能转移 | 技能可在角色间获得/失去 | 多处 |
